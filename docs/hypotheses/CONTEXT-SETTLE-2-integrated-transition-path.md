# CONTEXT-SETTLE-2 — 6회 상황 처리의 공용 결합 행동 재검증

상태: 완료 · `CT2I_COMPOSITION_LOSS`
등록일: 2026-08-11
선행 결과: `CONTEXT-SETTLE-1=CT1_MINIMUM_SETTLING_FOUND`

## 질문과 고정 가설

`CONTEXT-SETTLE-1`은 현재 상황을 세 번 처리하면 직전 상황 흔적이 남지만, 여섯 번 처리하면
얼린 상황 주소 변환의 16개 모든 위치가 통과함을 확인했다. 이번 검사는 그 최소값을 공용 기억
호출에 연결했을 때 `CONJUNCTION-2`의 기억 위치 선택과 최종 행동도 회복되는지 확인한다.

가설은 상황 주소를 읽는 시점만 바로잡으면 기존 상황·열쇠 합성 주소와 안정 값 경로가 전체
행동을 회복한다는 것이다. 주소 변환을 다시 맞추거나 새 계산층을 추가하지 않는다.

## 고정 설계

- `CONTEXT-SETTLE-1`, `COMPONENT-2`, `VALUE-2` 결과·판정·체크포인트 지문을 먼저 확인한다.
- `CONJUNCTION-2`와 같은 1,024회차, 원형 시작값 2개와 엔진 시작값 2개의 네 조합을 사용한다.
- 기존 3회 조건과 6회 조건은 같은 사건·같은 시작값으로 짝지어 실행한다.
- 저장할 때의 상황과 질문 상황만 각각 3회 또는 6회 처리한다. 열쇠·값은 3회, 방해 입력과 질문
  전 자체 갱신은 선행 실험과 같게 유지한다.
- `COMPONENT-2`의 결정형 상황·열쇠 변환과 `VALUE-2`의 값 변환은 읽기 전용으로 사용한다.
- 정상 합성 주소, 상황 가림, 열쇠 가림, 정확 주소, 값 맞바꾸기, 변환 복구 비교를 모두 유지한다.
- 상황·열쇠·값 처리 호출 수, 사건 시작값, 셀 수, 유한값, 변환 가중치 불변을 검사한다.
- 결과를 본 뒤 처리 횟수, 자료, 기준 또는 변환을 바꾸지 않는다.

## 유효성 및 판정

기존 3회 재실행은 `COMPONENT-2`의 같은 네 평가 결과와 예측·선택이 완전히 같아야 한다. 3회
정상 선택 정확도는 85% 이하여야 선행 손실이 재현된 것으로 본다. 정확 주소 비교는 최종 행동
90% 이상과 값별 최저 맞힘률 75% 이상이어야 한다. 상황 또는 열쇠를 가린 비교는 35% 이하,
값 맞바꾸기는 5% 이하, 공용 경로와 바깥 계산의 예측·선택 일치는 100%여야 한다.

6회 정상 조건은 네 평가 조합 모두 기억 위치 선택과 최종 행동이 90% 이상, 값별 최저 맞힘률이
75% 이상이어야 통과한다. 각 조합의 선택 정확도는 짝지은 3회보다 최소 15%p 높아야 한다.

- `CT2I_PATH_RECOVERED_NOT_UNIQUE`: 3회 손실을 재현하고 6회 전체 행동과 비교가 모두 통과한다.
- `CT2I_CONTEXT_SETTLING_NOT_CAUSAL`: 3회 손실 또는 등록된 최소 개선 폭이 재현되지 않는다.
- `CT2I_COMPOSITION_LOSS`: 6회 상황 성분은 검증됐지만 공용 합성 주소의 행동이 통과하지 못한다.
- `CT2I0_INVALID`: 자료, 원본 지문, 호출 수, 상태 모양, 고정 변환 또는 수치 검사가 어긋난다.

성공해도 일반 기억 통로가 현재 상황을 읽는 데 필요한 시간을 확보했다는 뜻이며, 의식이나
해마 고유 기능의 증거는 아니다. 실패하면 반복 횟수를 더 늘리지 않고, 상황 상태와 열쇠 상태를
같은 시점에 묶는 방식이 필요한지 별도 검사한다.

결과를 보기 전 이 문서와 README를 커밋하고 그 커밋을 실행 사양의
`preregistration_commit`으로 고정한다.

## 판정과 다음 단계

판정은 `CT2I_COMPOSITION_LOSS`다. 6회 처리는 선택 정확도를 26%p 넘게 올렸으므로 상황 전환
시간 부족은 실제 원인이지만, 네 조합 모두 선택·행동 90% 기준에는 못 미쳤다. 따라서
`CONTEXT-SETTLE-1`의 범주 분류 통과만으로 16개 저장 위치의 가까운 이웃 검색까지 보장되지는
않는다.

현재 상황·열쇠 변환은 같은 범주를 맞히더라도 각 사건을 연속된 32차원 주소로 남긴다. 다음
`ADDRESS-MARGIN-1`은 변환을 다시 학습하지 않고, 같은 범주 안의 주소 퍼짐과 다른 범주까지의
거리를 직접 측정한다. 이어 같은 얼린 변환의 예측 범주를 고정 직교 중심으로 바꾼 비교에서만
검색이 회복되는지 확인한다. 회복되면 범주 안 잔여 흔들림이 원인이고, 회복되지 않으면 상황과
열쇠를 합치는 거리 계산 자체를 분리한다. 결과를 보고 6회보다 반복 횟수를 늘리지는 않는다.
