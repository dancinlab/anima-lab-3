# STATE-1 — 감각 정보는 실행 흐름의 어디까지 살아남는가

## 사전등록

GRAFT 행동 실험은 같은 선택 과제를 일반 기억 장치로는 100% 풀었지만 `QuantumC` 진폭은
23.4%/25.0%, 위상은 35.9%/67.2%에 그쳤다. 다음 변경 대상을 추측하지 않고, 기존 감각 입력부터
언어 게이트까지 같은 상황 정보가 처음 사라지는 위치를 찾는다.

조건의 단일 원장은 `measurement/state_survival_registry.py`다. GRAFT와 같은 네 상황, 방해 단어,
48셀, 감각 3단계, 독립 seed `1337, 7331`을 재사용한다. 학습용과 평가용은 서로 다른 엔진 초기
상태를 사용한다. 지연은 결과 전에 `0, 1, 2, 4, 8, 16, 32`단계로 고정한다.

각 지연에서 원래 감각값, 원형 위상 좌표, 진폭, 위상 변화 속도, 긴장·불일치, 전체 상태, 여러
시점을 합친 위상, `ThalamicBridge`의 셀 평균 전 코드·평균 후 코드·최종 게이트를 읽는다. 엔진과
다리는 바꾸지 않고 읽기 전용 관찰 API만 사용한다. 모든 채널은 같은 선형 ridge 읽기 검사로
평가한다.

- 직접 감각 비교군: 정확도 90% 이상
- 내부 채널: 정확도 75% 이상
- 정답을 뒤섞어 학습한 가짜 검사: 정확도 40% 이하
- 두 seed가 모두 기준을 만족해야 해당 지점에서 정보가 생존한 것으로 인정

판정은 처음 실패한 공용 지점에 따라 고정한다.

- `S0_INVALID`: 직접 감각 비교군·두 seed·지연·채널·기존 GRAFT 결과 중 하나가 유효하지 않음
- `S1_SENSORY_ENCODING_LOSS`: 감각 직후 위상부터 실패
- `S2_TEMPORAL_RETENTION_LOSS`: 감각 직후는 통과하지만 지연 중 위상이 실패
- `S3_STATE_CHANNEL_LOSS`: 위상은 남지만 전체 실행 상태가 안정적으로 읽히지 않음
- `S4_BRIDGE_TRANSFORM_LOSS`: 셀 평균 전 다리 변환에서 실패
- `S5_CELL_POOLING_LOSS`: 셀별 코드는 통과하지만 셀 평균 뒤 실패
- `S6_GATE_TRANSFORM_LOSS`: 평균 뒤 코드는 통과하지만 최종 게이트에서 실패
- `S7_BEHAVIOR_GROUNDING_LOSS`: 게이트까지 통과하지만 기존 GRAFT 행동 판정은 `B3_NOT_CAUSAL`

이 실험은 정보의 존재 위치를 찾을 뿐, 그 정보가 의식이거나 행동의 원인임을 증명하지 않는다.
결과에 맞춰 처음 실패한 공용 지점 하나만 다음 업그레이드 대상으로 삼는다.

## 결과
