# STATE-1 — 감각 정보는 실행 흐름의 어디까지 살아남는가

## 사전등록

GRAFT 행동 실험은 같은 선택 과제를 일반 기억 장치로는 100% 풀었지만 `QuantumC` 진폭은
23.4%/25.0%, 위상은 35.9%/67.2%에 그쳤다. 다음 변경 대상을 추측하지 않고, 기존 감각 입력부터
언어 게이트까지 같은 상황 정보가 처음 사라지는 위치를 찾는다.

조건의 단일 원장은 `measurement/state_survival_registry.py`다. GRAFT와 같은 네 상황, 방해 단어,
48셀, 감각 3단계, 독립 seed `1337, 7331`을 재사용한다. 학습용과 평가용은 서로 다른 엔진 초기
상태를 사용한다. 지연은 결과 전에 `0, 1, 2, 4, 8, 16, 32`단계로 고정한다.

각 지연에서 원래 감각값, 원형 위상 좌표, 진폭, 위상 변화 속도, 긴장·불일치, 전체 상태, 여러
시점을 합친 위상, `ThalamicBridge`의 셀 평균 전 코드·평균 후 코드·최종 게이트를 읽는다. 엔진과
다리는 바꾸지 않고 읽기 전용 관찰 API만 사용한다. 모든 채널은 같은 선형 ridge 읽기 검사로
평가한다.

- 직접 감각 비교군: 정확도 90% 이상
- 내부 채널: 정확도 75% 이상
- 정답을 뒤섞어 학습한 가짜 검사: 정확도 40% 이하
- 두 seed가 모두 기준을 만족해야 해당 지점에서 정보가 생존한 것으로 인정

판정은 처음 실패한 공용 지점에 따라 고정한다.

- `S0_INVALID`: 직접 감각 비교군·두 seed·지연·채널·기존 GRAFT 결과 중 하나가 유효하지 않음
- `S1_SENSORY_ENCODING_LOSS`: 감각 직후 위상부터 실패
- `S2_TEMPORAL_RETENTION_LOSS`: 감각 직후는 통과하지만 지연 중 위상이 실패
- `S3_STATE_CHANNEL_LOSS`: 위상은 남지만 전체 실행 상태가 안정적으로 읽히지 않음
- `S4_BRIDGE_TRANSFORM_LOSS`: 셀 평균 전 다리 변환에서 실패
- `S5_CELL_POOLING_LOSS`: 셀별 코드는 통과하지만 셀 평균 뒤 실패
- `S6_GATE_TRANSFORM_LOSS`: 평균 뒤 코드는 통과하지만 최종 게이트에서 실패
- `S7_BEHAVIOR_GROUNDING_LOSS`: 게이트까지 통과하지만 기존 GRAFT 행동 판정은 `B3_NOT_CAUSAL`

이 실험은 정보의 존재 위치를 찾을 뿐, 그 정보가 의식이거나 행동의 원인임을 증명하지 않는다.
결과에 맞춰 처음 실패한 공용 지점 하나만 다음 업그레이드 대상으로 삼는다.

## 결과

### 1차 — S0_INVALID

정상 읽기에서는 직접 감각과 위상이 대부분 100%였지만, 한 번만 무작위로 정답을 섞은 가짜 검사가
직접 감각 비교군에서 최대 53.1%, 위상에서 최대 67.2%를 기록했다. 같은 감각 벡터가 학습표에서
반복되기 때문에 한 번의 작은 무작위 순열이 일부 벡터에 같은 오답을 여러 번 배정했고, 140개
seed·지연·채널 조합 중 하나라도 40%를 넘으면 무효가 되는 구조에서 우연 변동이 그대로 판정을
지배했다. 사전 규칙에 따라 `S0_INVALID`이며 정상 점수로 정보 소실 위치를 결론내리지 않는다.

1차 원본은 `measurement/state_survival_invalid_results.json`, 판정은
`measurement/state_survival_invalid_verdict.json`으로 보존한다.

### 가짜 검사 안정화 — 사전등록

정상 데이터, 선형 ridge 읽기 검사, 두 seed, 지연, 채널, 정상 합격선은 모두 그대로 둔다. 유일한
변경은 정답 무작위 순열을 한 번이 아니라 32번 독립 실행하고 가짜 정확도의 평균을 기존 40% 기준과
비교하는 것이다. 이는 정상 점수를 높이지 않으며, 가짜 검사의 우연 오차만 줄인다. 보정 결과를 보기
전에 `label_control.method=mean_random_permutation`, `permutations=32`를 코드 원장에 고정한다.

### 보정 결과 — S4_BRIDGE_TRANSFORM_LOSS

32개 정답 순열의 가짜 정확도 평균은 모든 seed·지연·채널에서 19.9~29.7%로 40% 기준 아래였다.
직접 감각 비교군도 전 조건 100%여서 보정 검사는 유효하다.

감각이 직접 들어가는 원형 위상과 위상을 포함한 전체 상태는 두 seed 모두 지연 0~32단계에서
정확도 100%를 유지했다. 여러 시점의 위상을 합친 상태도 전 구간 100%였다. 따라서 감각 입력이나
엔진의 단기 정보 유지가 현재 행동 실패의 첫 원인은 아니다.

진폭은 감각 직후 28.1%/43.8%로 낮았지만 시간이 지나며 높아져 두 seed 모두 4단계부터 87.5%
이상, 8단계부터 100%였다. 반대로 위상 변화 속도는 전 구간 23.4~26.6%였고 긴장·불일치는
대부분 기준에 못 미쳤다. 감각 정보가 모든 내부 숫자에 똑같이 복사되는 것이 아니라 위상에 바로
남고 진폭에는 늦게 나타난다는 뜻이다.

`ThalamicBridge`의 셀 평균 전 코드는 16단계까지 두 seed 모두 85.9% 이상이었지만 32단계에서
64.1%/75.0%로 갈렸다. 사전 규칙은 두 seed의 전체 지연 통과를 요구하므로 최종 판정은
`S4_BRIDGE_TRANSFORM_LOSS`다. 셀 평균 후 코드는 더 일찍 약해져 seed 7331은 4단계 71.9%,
seed 1337은 16단계 71.9%였고 32단계에는 48.4%/59.4%였다. 최종 게이트도 32단계
48.4%/56.2%였다.

따라서 다음 변경 대상은 `QuantumC` 감각·기억 동역학이 아니라 공용 `ThalamicBridge` 읽기
경로다. 구체적으로 96차원 셀 상태를 8차원으로 줄이는 변환과 고정 셀 평균이 정보 손실에 각각
얼마나 기여하는지 같은 조건으로 분리해야 한다. 이 지도는 고정된 seed별 다리 초기화 뒤 선형 읽기
가능성을 잰 것이므로, 실제 GRAFT에서 학습된 다리의 특정 가중치가 원인이라고 단정하지 않는다.

결과 정본은 `measurement/state_survival_results.json`, 판정은
`measurement/state_survival_verdict.json`이다. 이 결과는 의식의 증거가 아니라 다음 엔진
업그레이드 지점을 정한 인과 경로 진단이다.
