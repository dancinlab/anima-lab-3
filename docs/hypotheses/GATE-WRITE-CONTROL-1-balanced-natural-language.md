# GATE-WRITE-CONTROL-1 — 균형 문장 틀·자연 어휘 저장 선택

상태: 완료 — `GWC1_BALANCED_NATURAL_WRITE_VALID`

사전등록 커밋: `e8ae4f593`

## 질문

`GATE-WRITE-MECHANISM-1`에서 약속 문장 실패는 한 자료 묶음의 고정 문장 틀과 뜻 없는 숫자 식별
문자열이 함께 있을 때만 나타났다. 모든 문장 틀을 고르게 사용하고, 학습과 평가가 겹치지 않는
자연스러운 주제·값 표현으로 바꾸면 중요한 장기 사실을 안정적으로 고를 수 있는지 검사한다.

## 변경 전 실제 흐름

- 사실 종류가 네 개이고 문장 틀도 네 개라 기존 `(seed + index) % 4` 선택은 같은 사실 종류에서
  한 문장 틀만 반복했다.
- 주제·값은 `평가핵심주제1337...` 같은 뜻 없는 숫자 문자열이었다.
- 고정 문장 의미 모델, `canonical_ridge`, 선택 문턱 0.5와 검증된 검색은 결정형이다.
- 실제 대화 원문 저장은 아직 모든 문장을 보존하며, 이 실험 결과로 바로 바꾸지 않는다.

## 고정 조건

- 문장 의미 모델 revision, 특징 폭, 4,096개 보정 문장, 회차당 후보 8개, ridge 0.001과 문턱
  0.5를 유지한다.
- 보정 자료는 중요 사실 2,048개와 방해 문장 2,048개로 맞춘다.
- 네 사실 종류의 네 문장 틀을 각각 정확히 128번 보정에 사용한다.
- 평가는 `daily`, `work` 두 자연 어휘 묶음이며 각 1,024회차다. 각 사실 종류·문장 틀 조합을
  묶음마다 정확히 64번 사용하고, 사실 위치 8곳도 균형화한다.
- 보정·두 평가 묶음의 주제와 값 표현은 서로 겹치지 않는다. 기존 숫자 식별 문자열과 ASCII 숫자는
  허용하지 않는다.
- 두 seed는 같은 균형 내용을 서로 다른 순서와 후보 배치로 실행한다.
- 정상 저장 선택과 회차별 저장량이 같은 무작위·가짜 선택을 비교한다.
- 결과를 본 뒤 문턱, 어휘, 문장 틀, 자료 수를 바꾸지 않는다.

## 감사 조건

- 보정 4,096개와 각 평가 후보 8,192개는 묶음 안에서 모두 고유해야 한다.
- 보정과 평가, 두 평가 묶음 사이 원문 겹침은 0이어야 한다.
- 종류·문장 틀·사실 위치 균형, 모델 revision, 자료·선택·점수·체크포인트 지문을 기록한다.
- 정상·가짜·무작위 팔의 회차별 저장 개수는 정확히 같아야 한다.
- 체크포인트 파일이 없거나 지문이 다르면 닫힌 실패인 `GWC0_INVALID`로 처리한다.

## 판정

감사 조건 또는 저장량 일치가 실패하거나, 가짜·무작위의 중요 사실 저장이 50%를 넘거나 정상과의
차이가 25%p 미만이면 `GWC0_INVALID`다.

- `GWC1_BALANCED_NATURAL_WRITE_VALID`: 두 seed와 두 자연 어휘 묶음 모두에서 중요 사실 저장률
  90% 이상, 종류별 최저 90% 이상, 문장 틀별 최저 90% 이상이다. 방해 저장은 전체 25% 이하,
  종류별 50% 이하이고 전체 저장 비중은 50% 이하다.
- `GWC2_WRITE_SELECTION_LOSS`: 비교와 감사는 유효하지만 정상 저장 선택이 위 기준 하나 이상을
  놓친다.

경계값은 통과로 센다. 이 검사는 일반 문장 의미 분류의 안정성 검사이며 Anima 고유 기능이나 의식의
증거가 아니다.

## 다음 단계

`GWC1`이면 같은 선택기를 실제 대화 기본값으로 바로 켜지 않고, 검증된 회차·주제 검색과 다시 합친
통합 회귀 검사를 먼저 한다. `GWC2`이면 결과를 보고 문장을 추가 조정하지 않고 실패한 사실 종류와
문장 틀을 별도 원인 검사로 분리한다.

## 결론

사전 판정은 `GWC1_BALANCED_NATURAL_WRITE_VALID`다. 직전 seed 차이는 일반적인 약속·목표 문장
저장 능력의 불안정이라기보다, 사실 종류마다 문장 틀 하나만 반복하고 뜻 없는 숫자 문자열을 함께
쓴 자료 생성 방식에서 생겼다. 균형 문장 틀과 겹치지 않는 자연 어휘에서는 두 seed와 두 어휘
묶음이 모두 통과했다.

이는 일반 문장 의미 선택의 유효성이지 Anima 고유 기능이나 의식 증거가 아니다. 실제 대화 기본값은
아직 바꾸지 않는다. 다음은 이 저장 선택과 검증된 회차·주제 검색을 다시 합쳐, 원문 전체 보존을
유지하면서 별도 장기 기억 목록만 안전하게 줄이는 통합 회귀 검사다.
