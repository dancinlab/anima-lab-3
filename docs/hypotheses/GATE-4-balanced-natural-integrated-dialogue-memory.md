# GATE-4 — 균형 자연 대화 기억 통합 회귀

상태: 사전등록

사전등록 커밋: `e52b419c5`

## 질문

`GATE-WRITE-CONTROL-1`에서 검증한 균형 문장 틀·자연 어휘 저장 선택과
`GATE-RETRIEVAL-CONTROL-4`에서 검증한 회차·주제 검색을 합쳤을 때, 중요한 사실만 별도 장기 기억
목록에 남기고도 나중 질문에 안정적으로 답할 수 있는지 검사한다.

## 변경 전 실제 흐름

- 실제 대화 원문은 모든 문장을 보존하며 자동 삭제하지 않는다.
- `GATE-3`은 저장 후보를 먼저 고른 뒤, 회차·주제 주소로 같은 주제 후보 둘을 찾고 내용 점수로
  순위를 정했다.
- 검색은 저장된 사실을 두 seed 모두 100% 찾았지만, 한 문장 틀과 뜻 없는 숫자 문자열이 겹친
  자료에서 저장 선택이 흔들렸다.
- `GATE-WRITE-CONTROL-1`은 자료 생성 문제를 제거해 두 seed·두 자연 어휘 묶음에서 중요 사실
  저장 100%를 확인했지만 검색과 다시 합치지는 않았다.

## 고정 조건

- `GATE-WRITE-CONTROL-1`의 보정 자료 4,096개, `daily`·`work` 각 1,024회차, 후보 8개, 네 사실
  종류와 네 문장 틀의 균형을 그대로 쓴다.
- 고정 문장 의미 모델, `canonical_ridge`, ridge 0.001, 문턱 0.5를 유지한다.
- 회차마다 후보 위치 두 개를 회차 주소로 좁히고, 후보에 붙은 내용 점수로 최종 순위를 정한다.
- 정상 선택, 모든 문장 저장, 정답만 저장, 정상과 저장량이 같은 무작위·가짜 선택, 기억 없음을
  같은 자료에서 비교한다.
- 원문 후보 목록은 수정하지 않고, 장기 기억 후보는 별도 위치 목록으로만 만든다.
- 결과를 본 뒤 문턱, 자료, 검색 폭, 문장 틀, 어휘를 바꾸지 않는다.

## 감사 조건

- 보정·평가 원문 고유성, 겹침 없음, 자연 어휘, 종류·문장 틀·사실 위치 균형을 확인한다.
- 정상·무작위·가짜 선택의 회차별 저장량은 정확히 같아야 한다.
- 검색 결과와 주소 후보는 선택된 장기 기억 후보의 부분집합이어야 한다.
- 검색 전후 원문 개수와 원문 SHA-256이 같아야 하며, 장기 기억 위치 목록이 별도로 존재해야 한다.
- 모델 revision, 자료·특징·점수·선택·주소·검색·체크포인트 지문을 기록한다.

## 판정

감사, 원문 보존, 저장량 일치, 모든 문장·정답만 저장 양성 비교, 기억 없음 비교가 하나라도 실패하거나
정상과 가짜·무작위의 최종 정답률 차이가 25%p 미만이면 `G4_0_INVALID`다.

- `G4A_BALANCED_INTEGRATED_MEMORY_VALID_NOT_UNIQUE`: 두 seed·두 어휘 묶음 모두 중요 사실 저장,
  최종 1순위 정답, 종류별·문장 틀별 최저 정답률이 90% 이상이고 저장된 사실 검색이 95% 이상이다.
  방해 저장은 전체 25% 이하, 종류별 50% 이하, 전체 저장 비중 50% 이하다.
- `G4B_WRITE_SELECTION_LOSS`: 검색 양성 비교와 저장된 사실 검색은 유효하지만 저장 선택 기준이
  하나 이상 실패한다.
- `G4C_RETRIEVAL_LOSS`: 저장 선택은 유효하지만 저장된 사실 검색이나 최종 정답 기준이 실패한다.

경계값은 통과로 센다. 성공해도 일반 대화 기억 기능의 유효성일 뿐 Anima 고유 기능이나 의식의
증거가 아니다. 실제 대화 기본값 변경은 이 검사 결과와 별도 배포 검사를 통과한 뒤 결정한다.
