# EPISODE-1 — 한 번 본 관계의 회차별 기억

상태: 사전등록 · 실행 전  
등록일: 2026-08-10  
선행 결과: `CONTROL-3=A1_KEYED_ATTENTION_VALID`

## 질문

`QuantumC`가 한 회차에서 차례로 겪은 두 `열쇠→값` 관계를 기존 `VectorMemory`에 저장하면,
방해 입력 뒤 같은 열쇠가 다시 왔을 때 이번 회차의 값을 복원할 수 있는가?

이번 검사는 새 기억층을 만들지 않는다. `QuantumC.get_phase_states()`의 셀 평균을 기존
`VectorMemory.store/retrieve(top_k=1)`의 열쇠와 내용으로 사용한다. 비교군은 `CONTROL-3`에서
검증된 표준 열쇠 검색, 감각 입력의 직접 위상값을 쓰는 같은 `VectorMemory`, 기억 없음이다.
성공하더라도 의식이나 고유한 기억 능력의 증명이 아니라, 현재 내부 상태가 기존 기억 경로의
주소와 내용으로 실제 사용될 수 있다는 근거다.

## 회차와 실행 흐름

- `CONTROL-3`의 분리된 최종 평가 2,048회차를 그대로 쓴다. 한 회차에는 서로 다른 열쇠 두 개와
  서로 다른 값 두 개가 있고 질문 위치·열쇠·값이 정확히 균형이다.
- 열쇠와 값은 각각 8개 등록 단어에 일대일로 대응하지만, 열쇠→값 관계는 회차마다 바뀐다.
- 한 `QuantumC`를 5단계 준비한 뒤 `열쇠1, 값1, 열쇠2, 값2`를 각각 3단계 감각한다. 각 열쇠와
  값 직후 위상 상태를 저장한다.
- 등록된 방해 단어 두 개를 각각 1단계 감각한 뒤 질문 열쇠를 3단계 다시 감각한다.
- 같은 회차 안에서 만든 `VectorMemory(capacity=2)`에 두 상태 쌍을 저장하고 질문 상태와 코사인
  유사도가 가장 높은 한 항목의 내용을 꺼낸다.
- 내용 상태는 평가와 겹치지 않는 별도 seed에서 값마다 16개 만든 평균 원형과 코사인 유사도로
  읽는다. 원형 생성 뒤와 최종 평가 중에는 가중치 학습이 없다.
- 감각 직접 비교는 같은 시점의 `PureMind.encode_sense()` 전역 위상값을 열쇠·내용으로 사용한다.
  기억 저장·검색과 내용 읽기는 `QuantumC` 팔과 완전히 같다.
- 표준 열쇠 검색은 `CONTROL-3` 체크포인트를 얼려 같은 2,048회차에서 다시 계산한다. 원본
  체크포인트·사양·판정·SHA-256이 하나라도 달라지면 무효다.

## 고정 사양

- seed: `1337 / 7331`
- 열쇠 단어: `붉음 / 푸름 / 초록 / 금빛 / 은빛 / 원형 / 사각 / 삼각`
- 값 단어: `폭풍 / 갈증 / 피로 / 평온 / 위험 / 메마름 / 졸림 / 안전`
- 방해 단어: `아침 / 저녁 / 실내 / 실외 / 가까이 / 멀리 / 조용히 / 빠르게`
- `QuantumC`: 셀 48, 내부 폭 48, 위상 읽기 폭 96
- 준비 5단계, 관계 항목당 감각 3단계, 방해 항목당 1단계, 질문 감각 3단계
- 값 원형: 값마다 16개, 평가 회차와 겹치지 않는 등록 seed
- 장치: 로컬 CPU

모든 단어·seed·단계·문턱은 `measurement/episode_registry.py`를 단일 기준으로 구현한다.

## 비교와 개입

1. `quantum_memory_normal`: `QuantumC` 위상 상태를 열쇠와 내용으로 쓴 기존 `VectorMemory`
2. `quantum_memory_partner_swap`: 두 저장 열쇠의 내용만 서로 맞바꾼 원인 차단
3. `quantum_memory_recovered`: 정상 연결을 새 기억에 다시 저장한 복구
4. `sensory_memory_normal`: 감각 입력의 직접 위상값을 쓰는 같은 기억 경로
5. `sensory_memory_partner_swap`: 직접 위상값의 저장 내용만 맞바꾼 통제
6. `keyed_attention`: `CONTROL-3`의 얼린 표준 열쇠 검색
7. `no_memory`: 회차 저장 없이 균형 자료의 고정 빈도만 쓰는 기준

정상 두 기억 팔은 최종 정확도 외에 올바른 저장 위치 선택률, 올바른 내용 상태의 값 읽기 정확도,
값별 재현율과 혼동표를 따로 저장한다. 복구 예측은 정상 예측과 항목별로 완전히 같아야 한다.

## 무효 조건

- 평가 회차 2,048개의 고유성·분리·열쇠·값·질문 위치 균형이 `CONTROL-3`와 다름
- 두 seed가 등록한 실행 흐름이나 서로 다른 추상 회차를 사용함
- 상태·원형 개수 또는 모양이 등록값과 다르거나 평가 seed와 원형 seed가 겹침
- 표준 열쇠 검색이 90% 미만, 직접 감각 기억이 90% 미만, 직접 감각 내용 맞바꾸기가 25% 초과,
  기억 없음이 25% 초과
- 복구 예측이 정상 예측과 한 항목이라도 다름
- 원본 `CONTROL-3` 판정이 `A1`이 아니거나 사양·체크포인트 지문이 달라짐
- seed·팔·결과·원형 체크포인트가 누락되거나 수치에 NaN·무한값이 있음

## 사전 판정

- `E1_STATE_MEMORY_VALID_NOT_UNIQUE`: 두 seed 모두 `QuantumC` 정상 정확도와 올바른 위치 선택률
  75% 이상, 값별 최저 재현율 60% 이상, 내용 맞바꾸기 25% 이하이며 모든 통제 통과
- `E2_KEY_RETRIEVAL_LOSS`: 올바른 저장 내용 자체는 두 seed 모두 90% 이상 읽히지만, 올바른 위치
  선택률이 한 seed 이상 75% 미만
- `E3_CONTENT_READOUT_LOSS`: 위치 선택률은 두 seed 모두 75% 이상이지만 올바른 내용 읽기가 한
  seed 이상 90% 미만
- `E4_EPISODIC_PATH_LOSS`: 위 두 부분은 각각 통과하지만 최종 정확도나 값별 재현율·맞바꾸기
  기준이 통과하지 못함
- `E0_INVALID`: 자료·양성 비교·직접 기억·복구·사양·파일 지문 조건 중 하나라도 무효

판정 우선순위는 `E0 → E2 → E3 → E1 → E4`다. `E1`이면 현재 기억 경로를 유지하되 일반 직접
기억보다 고유하다고 주장하지 않는다. `E2`이면 다음 후보는 새 해마 모형이 아니라 같은 단어의
상태를 서로 가까이 만드는 최소 열쇠 변환이다. `E3`이면 내용 읽기만 분리해 고친다. 결과를 본 뒤
단어·단계·폭·문턱을 바꾸거나 추가 seed를 고르지 않는다.
