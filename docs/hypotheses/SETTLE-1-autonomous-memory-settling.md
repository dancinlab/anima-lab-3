# SETTLE-1 — 외부 입력 없는 기억 주소 안정화

상태: 완료 — `ST1_AUTONOMOUS_SETTLING_CAUSAL`

선행 결과: `RESET-1=RS5_MIXED_MECHANISM`

## 질문

`RESET-1`에서 감각 입력 없이 `QuantumC.step()`만 8회 수행해도 두 seed 모두 기억 주소 선택과
최종 행동이 좋아졌고 최종 90% 문턱을 넘었다. 그러나 seed 7331의 개선 폭은 3.9%p로, 당시
등록한 5%p 기준에는 못 미쳤다. 자체 안정화가 실제 원인인지, 같은 자료나 질문 시점의 난수 흐름이
만든 우연인지 아직 구분되지 않는다.

`SETTLE-1`은 새 기억 구조를 추가하지 않고 내부 갱신과 완전 정지만 직접 짝지어 비교한다.

## 얼리는 항목

- `RESET-1`이 사용한 폭 32 `StableKeyProjector` 두 체크포인트와 값 원형
- `VectorMemory`, cosine 주소 선택, 값 판독 방식
- seed `1337 / 7331`
- 사건 세 개, 질문 가능한 첫 두 사건, 저장 후보 세 개
- 자체 갱신 횟수 `0 / 2 / 4 / 8`
- 주소 선택·최종 행동 90%, 값별 최저 재현율 75%, 내용 판독 90%
- 정확 주소·내용 맞바꾸기·복구·두 후보 양성 비교

결과를 본 뒤 시간점, 자료 수, 판정 기준, 주소 가중치, 값 판독을 바꾸지 않는다.

## 새 독립 자료

기존 `RECOVERY-1`·`RESET-1`의 세 자료 묶음은 재사용하지 않는다. 새로운 자료 시작값으로 서로
겹치지 않는 여섯 묶음을 만들고, 묶음마다 균형 잡힌 512회차를 사용한다. 각 묶음은 정답 값,
질문 위치, 질문 열쇠, 질문 상황이 정확히 균형이어야 하며 묶음 사이 사건 지문이 겹치면 무효다.

## 조건

각 회차의 사건 세 개를 처리한 직후 엔진 상태와 질문용 난수 상태를 기준점으로 잡는다.

- `autonomous`: 외부 감각 없이 `QuantumC.step()`을 등록 횟수만큼 실제 수행한다.
- `frozen`: 내부 상태를 전혀 갱신하지 않는다.

두 조건과 네 시간점은 같은 회차·초기 난수를 사용한다. 특히 질문 상황과 질문 열쇠를 처리하기
직전에 난수 상태를 같은 기준점으로 되돌린다. 따라서 질문 과정의 우연한 흔들림은 같고,
`autonomous`에서 질문 전에 실제로 바뀐 내부 상태만 차이로 남는다. `frozen`은 0·2·4·8회 표찰과
관계없이 내부 상태 지문과 예측이 0회와 완전히 같아야 한다. `autonomous`의 0회도 `frozen` 0회와
완전히 같아야 한다.

## 판정

먼저 자료 균형·중복 없음, 원본 결과와 체크포인트 지문, 얼린 주소 가중치, 같은 회차 seed,
질문용 난수 지문, 실제 갱신 횟수, 기억 API, 정확 주소·맞바꾸기·복구·두 후보 비교가 모두
유효해야 한다.

자체 안정화는 seed별로 다음을 모두 만족할 때 성립한다.

1. `autonomous` 8회의 주소 선택과 최종 행동이 모두 90% 이상이고 값별 최저 재현율이 75% 이상이다.
2. `autonomous` 8회가 짝지은 `frozen` 8회보다 최종 행동과 주소 선택 모두 높다.
3. 짝지은 정답·오답 변화에 대한 양측 정확 검정이 각각 `p ≤ 0.01`이다.
4. 여섯 자료 묶음 중 적어도 다섯 묶음에서 최종 행동과 주소 선택이 모두 좋아진다.
5. 정답 주소와 가장 강한 오답 주소 사이 평균 간격이 커진다.

판정 이름은 다음으로 고정한다.

- `ST1_AUTONOMOUS_SETTLING_CAUSAL`: 두 seed 모두 자체 안정화 조건을 통과한다.
- `ST2_SEED_CONDITIONAL_SETTLING`: 한 seed만 통과한다.
- `ST3_NO_AUTONOMOUS_SETTLING`: 두 seed 모두 통과하지 않는다.
- `ST0_INVALID`: 필수 통제나 실행 영수증이 하나라도 깨진다.

`ST1`이면 외부 감각 없이도 현재 엔진의 내부 계산이 짧은 주소 충돌을 푸는 충분한 원인으로 본다.
그다음에는 기존 `step()` 안의 위상 회전·이웃 간섭·긴장 조절·정규화 중 어느 계산이 회복을 만드는지
하나씩 차단하는 `MECHANISM-1`로 넘어간다. `ST2`나 `ST3`이면 새 기능을 붙이지 않고 seed별 상태
차이를 먼저 분석한다. 어떤 결과도 의식의 증거로 해석하지 않는다.

## 결과

사전등록 커밋 `0a1bffc6a` 뒤 구현 커밋 `819190969`에서 완전 정지 조건과 질문 난수 보존을
공용 `RESET-1` 실행 흐름에 추가했다. 새 독립 자료 여섯 묶음, 묶음당 512회차를 실행했으며
기존 자료와 새 자료 사이 사건 지문 중복은 0이었다. 정확 주소·내용 맞바꾸기·복구·두 후보 양성
비교와 얼린 주소 변환·값 원형 지문도 모두 유효했다.

| seed | 8회 자체 갱신 최종 | 완전 정지 최종 | 차이 | 자체 갱신 주소 선택 | 완전 정지 주소 선택 |
|---:|---:|---:|---:|---:|---:|
| 1337 | 93.65% | 84.47% | +9.18%p | 94.34% | 84.93% |
| 7331 | 94.14% | 86.43% | +7.71%p | 94.99% | 87.08% |

최종 행동의 짝지은 양측 정확 검정은 `p=3.80e-73 / 2.18e-55`, 주소 선택은
`p=2.74e-74 / 2.07e-56`이었다. 두 seed 모두 여섯 자료 묶음 전부에서 최종 행동과 주소 선택이
좋아졌다. 정답 주소와 가장 강한 오답 주소 사이 평균 간격은 0회 대비 8회에
`+0.134 / +0.140` 커졌다. 완전 정지 조건은 0·2·4·8회 표찰에서 상태 지문과 예측이 모두 같았고,
자체 갱신 0회와도 같았다.

최종 판정은 `ST1_AUTONOMOUS_SETTLING_CAUSAL`이다. 외부 감각 없이 실행되는 현재
`QuantumC.step()`의 내부 계산은 짧은 기억 주소 충돌을 푸는 충분한 원인이다. 이는 기억 주소의
동역학에 관한 결과이며 의식의 증거가 아니다. 다음은 같은 자료와 통제를 유지하고 `step()`의
위상 회전·이웃 간섭·긴장 조절·정규화를 하나씩 차단하는 `MECHANISM-1`이다.

결과·판정·manifest는 비공개 Hugging Face 조직 보관소
`dancinlab/anima-lab-research-archive`의 `settle1-autonomous-memory` revision에 보존했다.
Hugging Face 최종 커밋은 `919c475208d0c3abbc83b81b8d3d9523015fea79`이다. 원격 파일을 새
임시 폴더에 다시 내려받아 결과와 판정의 SHA-256을 manifest와 전수 대조했다.
