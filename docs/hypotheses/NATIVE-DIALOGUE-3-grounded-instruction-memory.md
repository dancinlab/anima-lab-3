# NATIVE-DIALOGUE-3 — 근거 있는 지시·기억 자체 모델

## 목표

`NATIVE-DIALOGUE-2`에서 문장 모양만 좋아지고 질문의 사실 연결은 회복되지 않은 원인을 자료 단계에서
고친다. 외부 사전학습 가중치 없이 한국어·영어 질문에 직접 답하고, 앞선 사실과 정정을 사용할 수 있는
최소 42.997M 양성 모델을 먼저 확보한다.

## 변경 전 근거

- 113,898개 양언어 대화를 12,000회 추가 학습해 답변 검증 오차는 `4.6273 → 2.5641`로 내려갔다.
- 고정 평가는 영어 `3/7`, 한국어 `0/7`로 `NATIVE-DIALOGUE-1`과 같았다.
- 새 답변은 잡담과 역할극 문장처럼 더 자연스러웠지만 얼음·시험 질문의 원인과 행동을 연결하지
  못했다. 영어 기억은 두 번째 질문에서만 부분적으로 맞았고 한국어 기억·정정은 실패했다.
- 따라서 같은 잡담 자료의 양이나 모델 크기를 먼저 늘리지 않는다. 질문과 정답이 명시된 양성 자료와
  가중치 변경 없이 앞 문맥을 복사·정정하는 과제를 분리해 확인한다.

## 고정 자료와 실행

- 표준 양성 자료는 Apache-2.0의 `CohereLabs/aya_collection_language_split` revision
  `a3af2fde4b4cb5b2775830b11244a1a20b5f004f`만 사용한다.
- 영어 첫 파일과 한국어 첫 파일에서 고정 해시가 가장 작은 유효 지시·정답 각 100,000개를 뽑는다.
  기존 16K 바이트 복원형 토크나이저로 전체 대화가 513조각 이내인 행만 허용한다.
- 고정 패널과 가까운 입력·정답은 선별 전에 제거한다. 원본 사용자 대화는 쓰지 않는다.
- 별도 동적 기억 자료는 언어별 20,000개다. 프로젝트 이름·날짜·장소·계절 등 매 행 값이 바뀌며,
  고정 패널의 파란 상자·빨간 열쇠·색상·음료 조합은 사용하지 않는다. 절반은 기억 후 질문, 절반은
  새 값으로 정정 후 질문이다.
- 지시 자료를 언어별 네 파일, 기억 자료를 언어별 한 파일로 나눠 파일을 먼저 같은 확률로 뽑는다.
  따라서 한국어·영어 노출은 같고 기억 과제 비중은 20%다.
- `NATIVE-DIALOGUE-2` 20,000회 실패 체크포인트에서 새 최적화 단계 12,000회를 답변 부분만 학습한다.
  전역 묶음은 32, 학습률과 감소 방식은 기존 정본을 그대로 쓴다.

## 통과·중단 기준

- 고정 평가 영어·한국어 각각 6/7 이상, 두 차례 기억과 정정 최종 질문 모두 통과
- 빈 답변·깨진 UTF-8·역할 표식 누출·과도한 반복 0건
- 실패하면 307M 확대와 런타임 교체를 하지 않고 실패 구간을 다시 분해한다.

  혼합을 포함한다.
- 이 결과는 자체 대화 모델의 양성 경로일 뿐 의식 증거로 해석하지 않는다.
