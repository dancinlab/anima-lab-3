# GATE-1 — 대화 장기 기억 선택

상태: 사전등록
등록일: 2026-08-12

## 질문과 범위

현재 `anima_agent.py`와 `anima_unified.py`는 대화가 끝날 때 사용자 문장과 응답을 모두 장기
검색 목록에 넣는다. 짧은 대화에서는 안전하지만, 오래 실행하면 인사·추임새·일시 상태가 약속·
선호·목표·사용자 정보와 같은 검색 후보가 된다. 질문은 뒤에서 실제로 다시 물을 사실만 검색
목록에 넣는 선택 문이 전체 저장보다 적은 후보로 같은 답을 찾는가다.

이번 검사는 자연 대화 전반이나 주관적 이해를 판정하지 않는다. 통제된 한국어 대화에서 장기
검색 쓰기 선택이 작동하는지만 잰다. 통과해도 일반적인 기억 관리 기능이며 의식 증거가 아니다.

## 고정 자료

- 한 회차는 오래 유지할 사실 한 문장과 방해 문장 일곱 개, 이후 질문 하나로 구성한다.
- 사실 종류는 선호·약속·목표·사용자 정보로 균형화한다.
- 방해 종류는 인사·감사·추임새·현재 날씨·일시 기분·일반 질문·응답 확인으로 균형화한다.
- 보정 자료와 평가 자료의 문장 틀, 사람 이름, 대상, 값은 서로 겹치지 않는다.
- 두 독립 자료 seed `1337`, `7331`에서 각각 보정 4,096문장, 평가 1,024회차를 만든다.
- 각 평가 회차의 문장 순서는 결과와 무관한 고정 난수로 섞는다.

## 고정 선택기와 비교

새 언어 모델이나 외부 문장 임베딩을 추가하지 않는다. 저장소에 이미 있는
`creativity_classifier.text_to_vector()`의 결정형 글자 3개 묶음 벡터를 그대로 쓰고, 고정된
역할 표시를 붙인다. 선택기는 `canonical_ridge` 하나다. 이는 난수 최적화 없이 고정 목표에 대한
정규화 최소제곱 해를 한 번 계산하고 평가 전에 얼린다. 문턱은 보정 자료의 양성·음성 점수 중간값으로
한 번 정하며 평가 정답은 보지 않는다.

비교 조건은 다음으로 고정한다.

- `selective_gate`: 얼린 결정형 선택기로 장기 검색 등록
- `store_all`: 모든 후보를 장기 검색 등록
- `oracle_gate`: 실제 중요 표찰만 등록하는 양성 비교
- `matched_random`: 선택 문과 같은 개수만 정답과 무관하게 등록
- `shuffled_gate`: 보정 표찰을 고정 순열로 뒤섞어 맞춘 가짜 선택기
- `no_memory`: 아무 후보도 등록하지 않는 정보 없음 비교

검색은 기존 코사인 유사도 방식의 상위 3개 후보를 사용한다. 후속 질문의 정답은 저장된 사실의
고유 값이 상위 3개 안에 있는지로 센다. 선택기 결과와 무관하게 모든 원문은 원본 보관소와 최근
대화에 남긴다. 즉 이번 기능은 검색 등록 여부만 바꾸며 원문을 삭제하지 않는다. 사용자가 명시적으로
`memory_save`를 호출한 항목은 이 자동 선택 대상이 아니다.

## 유효성 및 판정

자료 수·균형·중복·분리, 특징 폭, 유한값, 결정형 해, 문턱 출처, 선택 수, 검색 상위 수와 모든
결과 지문을 닫힌 판정기로 확인한다. `oracle_gate`의 중요 사실 저장률과 후속 질문 정답률은 99%
이상이어야 하고 `no_memory` 정답률은 5% 이하여야 한다. `matched_random`과 `shuffled_gate`가
`selective_gate`보다 25%p 이상 낮지 않거나, 전체 저장이 정상 검색을 못 하면 실험을 무효화한다.

두 독립 자료가 모두 아래를 만족할 때만 통과한다.

- 중요 사실 저장률 90% 이상
- 후속 질문 상위 3개 정답률 90% 이상
- 방해 문장 검색 등록률 25% 이하
- `store_all` 대비 검색 목록 크기 50% 이하
- `store_all`보다 후속 질문 정답률이 2%p 넘게 나빠지지 않음

판정은 다음과 같다.

- `G1_SELECTIVE_WRITE_VALID_NOT_UNIQUE`: 두 자료 모두 통과하며 통제도 유효
- `G2_SELECTION_OR_RECALL_LOSS`: 통제는 유효하지만 선택 또는 후속 검색 기준 미달
- `G0_INVALID`: 자료·지문·결정성·양성·가짜·정보 없음 비교 중 하나라도 무효

`G1`이면 원본을 보존하는 `retrievable` 선택을 `MemoryStore`와 `MemoryRAG`의 공용 저장 API에
선택 기능으로 연결한다. 실제 대화 기본값은 켜지 않는다. 통제된 문장 밖의 자료 손실 위험이 있기
때문에 실제 대화 기록으로 `GATE-2`를 통과한 뒤에만 기본값을 바꾼다. `G2`이면 결과를 보고 문턱이나
문장 틀을 조정하지 않고 첫 손실 구간만 후속 검사한다.

결과를 보기 전 이 문서와 README를 먼저 커밋하고, 그 커밋을 실행 사양의
`preregistration_commit`으로 고정한다.
