# TRAINING-1 — 주소 초기값과 학습 순서 분리

상태: 완료 — `TR1_INITIALIZATION_CAUSAL`

선행 결과: `PROJECTOR-1=PD2_TRAINING_RANDOMNESS_CAUSAL`

## 질문

주소 변환의 성공과 실패는 보정 상태 seed가 아니라 `train_projector()`의 학습 seed를 따랐다.
하지만 현재 함수는 같은 seed를 두 위치에 함께 쓴다.

- 선형 가중치와 열쇠 원형의 처음 값
- 매 학습 단계에서 3,072개 상태 중 256개를 뽑는 순서

따라서 나쁜 시작점 때문인지, 학습 예 순서가 만든 경로 때문인지 아직 구분할 수 없다.

## 고정 조건

- 보정 상태는 PROJECTOR-1에서 두 학습 난수에 같은 판정을 준 1337 계열로 고정
- 초기값 seed `1337 / 7331`
- 학습 묶음 순서 seed `1337 / 7331`
- KEY-1의 선형 `96→32` 구조, 열쇠 원형 8개, 손실함수, AdamW, 학습률, 1,000회 학습 유지
- 원래 대각 `(1337,1337)`, `(7331,7331)`은 PROJECTOR-1의 같은 보정 상태 가중치와 텐서 단위로 일치
- 2×2 주소 변환 각각을 값 원형 seed 2개 × 엔진 시작 seed 2개의 사건 4개 평가에 사용
- 사건 1,536회차, 정상 자체 갱신 8회, 정확 주소·내용 맞바꾸기·복구 통제 유지

기존 `train_projector(states, labels, seed, ...)` 호출은 이전과 같은 값을 내야 한다. 새 선택 인자는
명시할 때만 학습 묶음 순서를 분리하며, 행동 정답과 사건 4개 결과는 학습에 사용하지 않는다.

## 판정

네 평가 모두에서 선택·최종 행동 90%, 값별 최저 재현율 75%, 내용 판독 90% 이상이어야 해당 주소
변환을 `ROBUST`로 센다.

- `TR1_INITIALIZATION_CAUSAL`: 같은 초기값 행끼리 판정이 같고 두 행이 서로 다름
- `TR2_BATCH_ORDER_CAUSAL`: 같은 학습 순서 열끼리 판정이 같고 두 열이 서로 다름
- `TR3_EITHER_FACTOR_SUFFICIENT`: 실패 대각에서 어느 한 요소만 바꿔도 둘 다 회복
- `TR4_BOTH_FACTORS_REQUIRED`: 두 요소를 함께 바꿔야만 회복
- `TR5_FACTOR_INTERACTION_OR_MIXED`: 위 모양에 들지 않는 결과
- `TR0_INVALID`: 대각 가중치 재현, 자료·실행 지문, 양성·가짜 통제가 깨짐

초기값이 원인이면 seed 선택이 필요 없는 정식 초기화나 유일해가 있는 표준 학습을, 학습 순서가
원인이면 전체 자료를 쓰는 결정적 학습을 별도 사전등록한다. 결과를 본 뒤 좋은 seed를 기본값으로
고정하지 않는다. 어떤 판정도 의식 증거가 아니다.

## 결과

대각 두 조합은 PROJECTOR-1의 같은 보정 상태 주소 가중치와 모든 텐서가 같았다. 기본
`train_projector()` 호출과 학습 순서를 명시적으로 같은 seed로 준 호출도 비트 단위로 같았다.

| 초기값 seed | 학습 순서 seed | 네 평가 선택 범위 | 네 평가 최종 행동 범위 | 네 평가 최저 값 재현율 | `ROBUST` |
|---:|---:|---:|---:|---:|:---:|
| 1337 | 1337 | 91.54~92.12% | 87.24~88.09% | 71.35~77.08% | 아니오 |
| 1337 | 7331 | 90.49% | 86.13~86.98% | 69.79~76.56% | 아니오 |
| 7331 | 1337 | 97.98~98.18% | 93.16~94.40% | 76.56~83.85% | 예 |
| 7331 | 7331 | 97.20~97.40% | 92.51~93.82% | 76.56~83.85% | 예 |

학습 순서를 바꾸는 것만으로는 어느 초기값에서도 판정이 바뀌지 않았다. 반대로 7331 초기값은 두
학습 순서 모두 통과했고, 1337 초기값은 두 순서 모두 실패했다. 정확 주소·내용 맞바꾸기·복구와
공용 기억 호출 통제는 모든 조합에서 통과했다.

## 판정과 다음 질문

판정은 `TR1_INITIALIZATION_CAUSAL`이다. 열쇠 구분 정확도와 학습 손실이 좋아도, 처음 무작위 주소
기하가 다른 저장 열쇠끼리의 실제 검색 여유를 불안정하게 만들었다. 이는 학습 예 순서나 보정 상태
자료의 문제가 아니다. 다음에는 좋은 7331 초기값을 고정하지 않고, 고정된 직교 열쇠 기준과
정규화된 최소제곱 해처럼 같은 자료에서 항상 하나로 계산되는 표준 주소 변환을 검증한다. 이 결과는
기억 검색 학습의 원인 규명이지 의식 증거가 아니다.
