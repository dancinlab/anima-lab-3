# SEPARATION-2 — 결정형 주소의 닮은 사건 구분 재검사

상태: 사전등록 · 실행 전  
등록일: 2026-08-10  
선행 결과: `SEPARATION-1=S0_INVALID`, `CANONICAL-2=CI1_CANONICAL_DEFAULT_INTEGRATED`

## 질문

난수 없이 계산한 공용 기억 주소와 검증된 자체 안정화 8회를 사용하면, 같은 열쇠를 공유하지만
앞선 상황과 값이 다른 사건 네 개를 질문 상황에 맞게 구분할 수 있는가?

`SEPARATION-1`은 서로 다른 열쇠 네 개 양성 비교가 먼저 실패해 같은 열쇠 결과를 판정하지 않았다.
이후 `CANONICAL-2`는 결정형 주소가 사건 네 개의 서로 다른 열쇠를 네 평가 조합 모두에서 통과함을
확인했다. 이번 검사는 그 공용 주소를 그대로 사용해 보류된 질문만 다시 연다. 새 기억층이나 분리
기능은 추가하지 않는다.

## 고정 흐름

- 새 독립 회차마다 `상황→열쇠→값` 사건 네 개를 차례로 감각한다.
- 정상 사건은 같은 열쇠 하나, 서로 다른 상황 네 개, 서로 다른 값 네 개를 가진다.
- 방해 입력 두 개와 외부 입력 없는 정상 자체 갱신 8회 뒤 `상황→열쇠`를 다시 감각한다.
- `CANONICAL-2`의 합친 결정형 폭 32 주소를 새로 맞추지 않고 얼린 채 사용한다.
- 기존 `VectorMemory(key_transform=...)`, 값 상태 원형, 최종 값 판독을 그대로 사용한다.
- 값 원형 seed `1337 / 7331` × 엔진 시작 seed `1337 / 7331`의 네 조합을 모두 평가한다.
- 각 조합은 2,048회차이며 자료·엔진 시작값은 조합 사이에서 짝을 맞춘다.
- 장치는 CPU다.

## 비교 조건

1. 결정형 주소로 같은 열쇠·다른 상황 검색
2. 주소 변환을 끈 원시 내부 상태로 같은 사건 검색
3. 결정형 주소로 서로 다른 열쇠 네 개 검색하는 양성 비교
4. 정확한 `상황+열쇠` 주소 양성 비교
5. 정확 주소의 저장 내용을 한 칸 돌린 가짜 비교
6. 정상 내용을 새 기억에 다시 저장한 복구 비교
7. 정확 주소에서 상황 부분을 지운 우연 비교

모든 조건에서 저장 위치 선택, 최종 행동, 값별 재현율, 저장 내용 판독, 기억 API와 직접 cosine
선택의 일치, 주소 여유를 기록한다. 주소 가중치, 값 원형, 원본 결과와 판정 파일의 SHA-256 지문도
검사한다.

## 유효 조건과 문턱

- 서로 다른 열쇠 조건: 선택·최종 행동 각각 90% 이상
- 정확한 `상황+열쇠`: 선택 99%, 최종 행동 90%, 값별 최저 재현율 75% 이상
- 상황 제거: 최종 행동 35% 이하
- 내용 한 칸 돌리기: 최종 행동 5% 이하
- 복구 예측과 정상 정확 주소 예측: 100% 일치
- 기억 API와 직접 선택: 100% 일치
- 같은 열쇠 정상 조건: 선택·최종 행동 75%, 값별 최저 재현율 60%, 내용 판독 90% 이상

자료 중복·균형 오류, 네 평가 조합 누락, 원본 지문 변경, 주소 재학습, 가중치 변경, 호출 수·폭·자체
갱신 횟수 변경, 필수 수치 누락이나 유한하지 않은 값이 하나라도 있으면 무효다.

## 사전 판정

- `SP1_SIMILAR_EPISODES_SEPARATED_NOT_UNIQUE`: 네 조합의 결정형 주소가 같은 열쇠 사건 기준 통과
- `SP2_CANONICAL_KEY_COLLISION`: 원시 상태는 네 조합 모두 통과하지만 결정형 주소 선택은 하나 이상 실패
- `SP3_CONTEXT_NOT_IN_KEY_STATE`: 양성 비교는 유효하지만 결정형 주소와 원시 상태가 모두 하나 이상 실패
- `SP4_VALUE_READOUT_LOSS`: 결정형 주소 선택은 모두 통과하지만 값 판독이나 최종 행동이 실패
- `SP0_INVALID`: 원본·자료·실행·양성·가짜·복구 조건 중 하나라도 실패

판정 우선순위는 `SP0 → SP4 → SP1 → SP2 → SP3`이다. `SP1`이면 새 구조 없이 상황 유사도와 사건
수를 늘리는 범위 검사를 등록한다. `SP2`면 결정형 열쇠 변환이 상황을 지운 지점을 분해한다.
`SP3`면 현재 열쇠 시점 상태를 넓히지 않고, 기존 상황 상태와 열쇠 상태를 함께 주소화하는 최소 표준
양성 비교를 먼저 수행한다. `SP4`면 주소 뒤 값 판독만 분해한다. 어떤 판정도 의식 증거가 아니다.
