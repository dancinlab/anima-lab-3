# GATE-CONTROL-1 — 문장 의미 기반 저장 선택 양성 비교

상태: 완료 · `GC0_INVALID`
등록일: 2026-08-12

## 질문과 범위

`GATE-1`은 글자 3개 묶음 벡터가 겹치지 않는 새 표현의 장기 중요도를 읽지 못해 무효였다. 이번
검사는 같은 자료와 같은 결정형 선택기를 유지하고, 입력 표현만 널리 쓰이는 다국어 문장 의미
벡터로 바꿨을 때 양성 비교가 성립하는지 확인한다. 실제 대화 저장 경로와 원본 보관 정책은
변경하지 않는다. 통과해도 일반 문장 분류 결과이며 Anima 고유 능력이나 의식 증거가 아니다.

## 고정 자료와 실행

- `GATE-1`의 `build_calibration()`과 `build_evaluation()`을 그대로 재사용한다.
- seed `1337`, `7331`에서 각각 보정 4,096문장과 평가 1,024회차를 사용한다.
- 의미 표현은 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`의 고정 revision
  `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`다.
- 표준 모델 사양대로 최대 128토큰, attention mask 평균 pooling, L2 정규화를 적용한다.
- 384차원 문장 벡터에 기존 사용자·응답 역할 2차원을 붙인다.
- 모델 가중치는 학습하지 않는다. `GATE-1`과 같은 `canonical_ridge`, ridge `0.001`만 보정
  자료에 맞추고 평가 전에 얼린다.
- 실행 환경은 Python 3.13, `torch==2.8.0`, `transformers==4.55.4`, CPU, batch 64로 고정한다.

## 비교와 판정

`semantic_gate`, 전체 저장, 정답 선택, 같은 저장량 무작위, 보정 표찰 뒤섞기, 기억 없음의 여섯
조건을 `GATE-1`과 같은 상위 3개 검색으로 비교한다. 자료 수·중복·분리, 모델 revision, 특징 폭,
유한값, 체크포인트 지문과 재실행 일치를 닫힌 판정기로 확인한다.

양성·가짜 비교가 유효하고 두 seed 모두 다음을 만족해야 통과한다.

- 중요 사실 저장률과 후속 질문 정답률 90% 이상
- 방해 문장 등록률 25% 이하
- 전체 저장 대비 검색 목록 크기 50% 이하
- 전체 저장보다 후속 질문 정답률이 2%p 넘게 낮지 않음
- 같은 저장량 무작위와 표찰 뒤섞기보다 후속 질문 정답률이 각각 25%p 이상 높음

판정은 다음과 같다.

- `GC1_SEMANTIC_CONTROL_VALID`: 두 자료 모두 통과하며 표준 의미 표현 양성 비교가 성립
- `GC2_SEMANTIC_CONTROL_LOSS`: 통제는 유효하지만 선택 또는 검색 기준 미달
- `GC0_INVALID`: 자료·모델·지문·결정성·양성·가짜·정보 없음 비교 중 하나라도 무효

`GC1`이면 글자 모양 표현이 `GATE-1`의 근본 원인이었음을 확정하고, 다음 `GATE-2`에서 더 다양한
실제 대화 표현으로 의미 선택을 검증한다. 이번 결과만으로 공용 저장 기본값은 바꾸지 않는다.
`GC2`이면 자동 중요도 분류를 보류하고 사용자의 명시적 저장과 후속 사용 뒤 승격 방식을 비교한다.
결과를 보기 전 이 문서와 README를 먼저 커밋하며 그 커밋을 실행 사양에 고정한다.

## 실행 결과

사전등록은 GitHub `main`의 `6a7f03c2e`에 고정했다. 등록한 모델 revision과 Python 3.13.13,
PyTorch 2.8.0, Transformers 4.55.4 CPU 환경에서 두 자료를 실행했다. 의미 벡터와 역할 표시를
합친 특징 폭은 386이며, 두 보정 해의 행렬 rank도 386이었다.

| 조건 | seed 1337 후속 질문 | seed 7331 후속 질문 | 검색 목록 비율 |
|---|---:|---:|---:|
| 의미 선택 | 100% | 100% | 13.02% / 32.14% |
| 전체 저장 | 99.90% | 100% | 100% |
| 정답 선택 | 100% | 100% | 12.50% |
| 같은 저장량 무작위 | 13.18% | 34.57% | 13.02% / 32.14% |
| 표찰 뒤섞기 | 99.90% | 0% | 99.94% / 56.64% |
| 기억 없음 | 0% | 0% | 0% |

정상 의미 선택은 두 자료 모두 중요 사실 저장률 100%를 보였고, 방해 문장 등록률은
`0.60% / 22.45%`였다. 따라서 등록한 정상 선택 기준과 같은 저장량 무작위 대비 25%p 차이는
모두 통과했다. 하지만 seed 1337의 표찰 뒤섞기 선택기는 평가 문장의 99.94%를 저장해 전체 저장과
같은 방식으로 후속 질문을 99.90% 맞혔다. 정상 선택과 가짜 선택의 저장량이 달라 가짜 비교가
선택기의 의미 판독이 아니라 전체 저장 효과를 재게 됐다.

## 판정과 다음 단계

사전 판정은 `GC0_INVALID`다. 정상 의미 선택 수치만 골라 양성 비교 성공으로 인용하지 않는다.
확정 가능한 내용은 “고정 문장 의미 표현은 두 자료의 정상 기준을 통과했지만, 표찰 뒤섞기 비교의
저장량이 통제되지 않아 실험 전체의 가짜 안전장치가 무너졌다”까지다. 문턱·문장 틀·모델·판정
기준은 결과 뒤에 바꾸지 않았고 실제 대화 저장 호출도 변경하지 않았다.

다음 `GATE-CONTROL-2`는 정상 의미 선택과 같은 회차별 저장 개수만 허용한 상태에서 뒤섞은 선택기
점수의 순위로 가짜 문장을 고른다. 이 한 가지 비교 결함만 고친 뒤 같은 정상 선택 결과가 재현되는지
다시 판정한다.

최초 결과 JSON SHA-256은
`0fb210fad73997ffeba29fe29a38ac59244c216686cd4a4764106426e61ebc47`, 판정 JSON은
`fc71e64fd10f8f534e4e9def1e7c22fd790406168534762901d505481e7092c7`이다. 독립 전체 재실행의 결과와
판정은 최초 파일과 바이트 단위로 같았다. HF 조직 보관소의 `gate-control1-semantic-write`
revision에 결과·판정·정상/가짜 체크포인트 네 개와 manifest를 커밋
`a0be2a1aed635160820163252aefc4f0f241e146`으로 올렸다. 새 임시 폴더로 다시 내려받아 manifest
6개 항목을 전수 확인했으며 manifest SHA-256은
`177c0090fb0b1c52f3a9b79c74c2cf463730f4f8f07749a0f2d648a242379302`다. 로컬 CPU에서만 실행했다.
