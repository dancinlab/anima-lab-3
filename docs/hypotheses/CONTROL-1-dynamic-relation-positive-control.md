# CONTROL-1 — 동적 관계 기억 양성 비교

상태: 완료 · `P2_TRAINING_PATH_INVALID`

## 질문

`VALIDITY-1`에서 실패한 표준 `GRU`가 관계를 기억하지 못한 것인지, 큰 언어 모델까지 함께
학습하는 기존 행동 경로가 양성 비교를 망가뜨린 것인지 분리한다. 새 뇌 기능이나 `QuantumC`는
추가하지 않는다.

## 과제

- 한 회차에 서로 다른 열쇠 두 개와 서로 다른 값 두 개를 무작위로 짝지어 차례로 보여준다.
- 짧은 방해 입력 뒤 두 열쇠 중 하나를 묻고, 해당 값을 고른다.
- 열쇠와 값은 각각 8종이며 회차마다 짝이 바뀐다. 특정 열쇠의 고정 답을 외워서는 풀 수 없다.
- 학습 회차와 평가 회차는 생성 seed와 회차 지문으로 분리하며 정확히 같은 회차는 허용하지 않는다.
- 평가 중에는 어떤 가중치도 바꾸지 않는다.

## 비교 조건

1. `gru`: 표준 `torch.nn.GRU`와 작은 직접 행동판. 기존 RELATION-1과 같은 96차원 상태 폭을 쓴다.
2. `vector_memory`: 기존 `trinity.VectorMemory`에 열쇠와 값을 저장하고 열쇠로 꺼내는 정확 기억 기준.
3. `no_memory`: 질문 열쇠만 보고 답하는 기억 없음 기준.
4. `shuffled_labels`: 정상 `GRU` 예측은 고정하고 평가 정답만 회차 간 뒤섞는 가짜 기준.

모든 조건은 같은 학습·평가 회차와 같은 두 seed `1337 / 7331`을 쓴다. 팔 순서가 난수나 자료를
바꾸지 않도록 자료 seed와 모델 seed를 따로 고정한다.

## 실행 사양

- 열쇠 8종, 값 8종, 회차당 관계 2개
- 저장 입력 2개, 16종 중 고른 방해 입력 2개, 질문 입력 1개
- 학습 회차 8,192개, 별도 검증 1,024개, 최종 평가 2,048개
- `GRU` 숨은 폭 96, 배치 128, 최대 2,000 step
- 저장 시점은 검증 정확도가 가장 높은 체크포인트로 고르되, 최종 평가는 한 번만 연다.
- 최적화 방식과 학습률은 단일 등록값으로 고정하고 결과를 본 뒤 조정하지 않는다.

## 무효 조건

- 학습·검증·평가 회차 지문이 하나라도 겹침
- 열쇠별·값별·질문 위치별 평가 빈도가 균형에서 1개 넘게 벗어남
- `vector_memory`가 100%가 아님
- 가짜 정답 또는 기억 없음 정확도가 25%를 넘음
- 결과에 NaN·무한값·누락 seed가 있음
- 저장한 체크포인트의 SHA-256 지문이 결과 영수증과 다름

## 판정

- `P1_POSITIVE_CONTROL_VALID`: 두 seed의 `GRU` 최종 평가가 각각 90% 이상이고 값별 재현율도
  모두 80% 이상이며 모든 무효 조건을 피함
- `P2_TRAINING_PATH_INVALID`: 정확 기억은 통과하지만 `GRU`가 위 기준을 통과하지 못함
- `P0_INVALID`: 자료 분리·균형·가짜 검사·정확 기억·파일 지문 중 하나라도 무효

`P1`일 때만 같은 회차별 관계 과제를 `QuantumC` 상태와 기존 기억 경로에 연결하는
`EPISODE-1`을 시작한다. 성공은 의식 증거가 아니라, 표준 기억층과 직접 행동판으로 동적 관계
과제를 배울 수 있다는 절차 검증이다.

## 결과

등록 사양을 로컬 CPU에서 두 seed 모두 실행했다. 자료 11,264회차는 각 split 안에서 모두
고유했고 학습·검증·평가 사이 같은 회차 지문은 0개였다. 값·질문 열쇠·질문 위치도 각 split에서
정확히 균형이었다.

| 조건 | seed 1337 | seed 7331 | 등록 기준 |
|---|---:|---:|---:|
| `GRU` 검증 | 85.9% | 81.9% | 저장 시점 선택용 |
| `GRU` 최종 평가 | 84.9% | 81.9% | 각각 ≥90% |
| `GRU` 값별 최저 재현율 | 73.4% | 69.1% | 각각 ≥80% |
| `vector_memory` | 100% | 100% | 100% |
| `no_memory` | 12.5% | 12.5% | ≤25% |
| `shuffled_labels` | 2.7% | 1.8% | ≤25% |

모든 무효 방지 통제는 통과했지만 `GRU` 두 seed가 등록 기준에 못 미쳐 판정은
`P2_TRAINING_PATH_INVALID`다. 정확 기억 기준이 100%이므로 자료 생성과 질문·정답 연결은
작동했다. 반면 얼린 체크포인트의 학습 자료 정확도는 95.1%/93.5%였고 새 평가 회차는
84.9%/81.9%였다. 질문이 첫 번째 저장값인지 두 번째 저장값인지에 따른 큰 공통 편향은 없었다.
따라서 현재 첫 문제는 기억 불가능이나 출력판 고장이 아니라, 고정된 8,192개 회차를 반복한
2,000-step 학습이 새 관계로 충분히 일반화되지 않은 것이다.

사전등록대로 결과를 본 뒤 학습 step·학습률·폭을 늘리지 않았으며 `EPISODE-1`은 계속 보류한다.
후속 양성 비교는 새 사양으로 별도 등록해야 한다. 가장 직접적인 후보는 같은 총 학습량에서 매
step 새 관계 회차를 생성해 고정 학습 집합 반복을 없애는 것이다.
