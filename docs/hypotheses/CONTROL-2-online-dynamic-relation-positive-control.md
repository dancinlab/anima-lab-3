# CONTROL-2 — 온라인 동적 관계 기억 양성 비교

상태: 완료 · `O2_ONLINE_TRAINING_INVALID`

## 질문

`CONTROL-1`의 표준 `GRU`가 새 관계 평가에서 84.9%/81.9%에 그친 원인이, 고정된 8,192개
학습 회차를 반복한 절차인지 확인한다. 모델 폭·최적화 방식·학습 횟수·평가 자료는 바꾸지 않고,
각 학습 예시를 한 번만 사용하는 온라인 생성 방식만 비교한다. 새 뇌 기능이나 `QuantumC`는
추가하지 않는다.

## 과제와 변경 변수

- 회차마다 서로 다른 두 `열쇠→값` 관계, 방해 입력 두 개, 질문 하나를 차례로 제시한다.
- 열쇠와 값은 각각 8종이고, 질문한 열쇠의 이번 회차 값을 고른다.
- 모델은 `CONTROL-1`과 같은 표준 `torch.nn.GRU`와 직접 행동판을 쓴다.
- 학습은 같은 2,000 step과 배치 128을 유지한다. 총 256,000개 학습 예시는 모두 고유하며
  한 번만 사용한다.
- 매 배치는 `질문 열쇠 8 × 정답 값 8 × 질문 위치 2 = 128` 조합을 정확히 한 번씩 포함한다.
- 두 모델 seed는 같은 순서의 학습 예시를 사용하고, 자료 난수와 모델 난수는 분리한다.
- 검증 1,024개와 최종 평가 2,048개는 `CONTROL-1`의 자료를 그대로 재사용한다. 온라인 학습
  예시는 이 고정 자료 및 서로 간에 지문이 겹치면 안 된다.
- 평가는 얼린 가중치로 수행하며 최종 평가 자료는 한 번만 연다.

## 고정 사양

- 모델 seed: `1337 / 7331`
- 온라인 자료 seed: `20260811`
- 열쇠 8종, 값 8종, 방해 입력 16종, 회차당 관계 2개, 방해 단계 2개
- `GRU` 숨은 폭 96, 배치 128, 최대 2,000 step
- `AdamW`, 학습률 0.003, weight decay 0.0001, gradient clip 1.0
- 50 step마다 고정 검증 자료를 재고, 검증 정확도가 가장 높은 시점을 저장
- 실행 장치: 로컬 CPU

## 비교 조건

1. `gru`: 온라인 회차로 학습한 표준 `GRU`와 직접 행동판
2. `vector_memory`: 회차 안의 정확한 열쇠·값 저장 기준
3. `no_memory`: 학습 중 열쇠별 값 빈도만 사용하고 회차 기억은 쓰지 않는 기준
4. `shuffled_labels`: 정상 예측은 고정하고 평가 정답만 한 칸 옮긴 가짜 기준

## 무효 조건

- 온라인 학습 예시가 256,000개가 아니거나 같은 지문이 하나라도 반복됨
- 온라인 학습과 고정 검증·평가 자료 사이 지문이 하나라도 겹침
- 배치별 또는 전체 열쇠·값·질문 위치 균형이 등록값과 다름
- 두 seed가 서로 다른 온라인 학습 순서를 사용함
- `vector_memory`가 100%가 아님
- 기억 없음 또는 가짜 정답 정확도가 25%를 넘음
- seed·체크포인트·결과가 누락되거나 숫자에 NaN·무한값이 있음
- 체크포인트 SHA-256 지문이 결과 영수증과 다름

## 판정

- `O1_ONLINE_CONTROL_VALID`: 두 seed의 `GRU` 최종 평가가 각각 90% 이상이고 값별 재현율도
  모두 80% 이상이며 모든 무효 조건을 피함
- `O2_ONLINE_TRAINING_INVALID`: 정확 기억과 가짜 통제는 유효하지만 `GRU`가 위 문턱을 통과하지 못함
- `O0_INVALID`: 자료 고유성·분리·균형·통제·파일 지문 중 하나라도 무효

`O1`이면 고정 자료 반복이 `CONTROL-1` 실패의 원인이었다고 보고, 같은 온라인 절차를
`EPISODE-1`의 표준 양성 비교로 사용한다. `O2`이면 자료 반복만으로 설명되지 않으므로
`EPISODE-1`을 계속 보류하고, 표준 기억층이 열쇠와 값을 묶는 데 필요한 최소 계산 구조를 별도
사전등록한다. 어느 결과도 의식의 증거로 해석하지 않는다.

## 결과

등록한 사양을 로컬 Apple Silicon CPU에서 두 seed 모두 실행했다. 두 실행은 같은 순서의 온라인
학습 지문 `5753b45d219d2245c5177cf27fcc9201dcbf2e7bddd5af460f16cf69909ba7a0`을
사용했다. 각 실행의 학습 회차 256,000개는 모두 고유했고, 고정 검증·평가 자료와 겹친 회차는
0개였다. 2,000개 배치 모두 질문 열쇠·정답 값·질문 위치가 정확히 균형이었다.

| 조건 | seed 1337 | seed 7331 | 등록 기준 |
|---|---:|---:|---:|
| `GRU` 검증 최고 | 56.3% | 52.9% | 저장 시점 선택용 |
| `GRU` 최종 평가 | 55.5% | 49.3% | 각각 ≥90% |
| `GRU` 값별 최저 재현율 | 18.8% | 13.7% | 각각 ≥80% |
| `vector_memory` | 100% | 100% | 100% |
| `no_memory` | 12.5% | 12.5% | ≤25% |
| `shuffled_labels` | 7.1% | 5.4% | ≤25% |

모든 무효 방지 통제는 통과했지만 표준 `GRU`가 등록 문턱을 넘지 못했으므로 판정은
`O2_ONLINE_TRAINING_INVALID`다. 고정된 학습 회차 반복을 없애도 새 관계 일반화가 회복되지
않았으므로 `CONTROL-1` 실패를 자료 반복 하나로 설명할 수 없다.

판정 뒤 수행한 위치 진단에서는 두 체크포인트 모두 예측값이 회차에 저장된 두 값 중 하나인 비율이
100%였다. 그러나 어느 저장 위치를 고르는지는 거의 반반이었고 질문 위치별 정확도도 안정적으로
갈리지 않았다. 이 진단은 판정 기준이 아니라 다음 실험을 고르는 참고값이다. 모델은 값 후보를
보존하지만 질문 열쇠와 맞는 값을 고르는 관계 선택을 배우지 못한 것으로 보인다.

사전등록대로 학습량·폭·학습률을 늘리지 않았으며 `EPISODE-1`은 계속 보류한다. 다음 양성 비교는
표준 `GRU`를 다시 조정하는 대신, 열쇠로 저장 항목을 직접 찾는 표준 주의집중 방식과 기존
`VectorMemory`를 같은 온라인 과제에서 비교해야 한다.
