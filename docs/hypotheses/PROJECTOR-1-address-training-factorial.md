# PROJECTOR-1 — 주소 변환 학습 seed 분해

상태: 사전등록

선행 결과: `SEEDMAP-1=SM1_SINGLE_FACTOR_CAUSAL`

## 질문

사건 4개 성능은 주소 변환 가중치만 바꿔도 양방향으로 뒤집혔다. 그러나 KEY-1의 주소 변환 seed는
다음 두 요소를 동시에 바꾼다.

- 1,024개 보정 회차의 `QuantumC` 상태를 만드는 엔진 seed 계열
- 주소 변환 가중치 초기화와 학습 묶음 추출 순서를 만드는 학습 seed

따라서 현재 결과만으로는 학습 자료의 내부 상태가 좋은 것인지, 같은 자료에서도 학습 난수가 좋은
해를 찾은 것인지 구분할 수 없다.

## 고정 조건

- KEY-1의 선형 `96→32` 주소 변환, 열쇠 원형 8개, 온도, AdamW, 학습률과 1,000회 학습
- KEY-1 검증 자료 1,024회차와 열쇠 표찰
- 보정 상태 seed `1337 / 7331`
- 가중치 초기화·학습 묶음 순서 seed `1337 / 7331`
- 2×2 주소 변환 네 개
- 원래 `(1337,1337)`, `(7331,7331)`은 보관된 KEY-1 가중치와 텐서 단위로 같아야 함
- 각 주소 변환을 SEEDMAP-1의 값 원형 seed 2개 × 엔진 시작 seed 2개에 모두 평가
- 사건 4개 1,536회차, 정상 자체 갱신 8회, 기존 정확 주소·내용 맞바꾸기·복구 통제 유지

새 주소 변환의 학습에는 행동 정답이나 사건 4개 평가 결과를 사용하지 않는다. 원래 KEY-1처럼
열쇠 정체성만 사용하며 결과를 본 뒤 학습 횟수·손실함수·seed를 추가하지 않는다.

## 통과와 원인 판정

각 주소 변환은 네 평가 조합 모두에서 다음을 충족해야 `ROBUST`로 센다.

- 주소 선택 90% 이상
- 최종 행동 90% 이상
- 값별 최저 재현율 75% 이상
- 내용 판독 90% 이상

2×2 주소 변환의 `ROBUST` 모양으로 판정한다.

- `PD1_CALIBRATION_STREAM_CAUSAL`: 같은 보정 상태 행끼리 결과가 같고 두 행이 서로 다름
- `PD2_TRAINING_RANDOMNESS_CAUSAL`: 같은 학습 난수 열끼리 결과가 같고 두 열이 서로 다름
- `PD3_EITHER_FACTOR_SUFFICIENT`: 실패 원래 조합에서 어느 한 요소만 바꿔도 둘 다 회복
- `PD4_BOTH_FACTORS_REQUIRED`: 실패 원래 조합에서 두 요소를 함께 바꿔야만 회복
- `PD5_FACTOR_INTERACTION_OR_MIXED`: 위 모양에 들지 않는 교차·혼합 결과
- `PD0_INVALID`: 원래 가중치 재현, 자료·실행 지문, 양성·가짜 통제 중 하나라도 깨짐

보정 상태가 원인이면 두 seed 상태를 합친 보정 자료를, 학습 난수가 원인이면 여러 초기값에 강건한
검색 목적함수를 다음 별도 실험에서 검증한다. 둘 중 하나를 확인하기 전에 가중치 선택이나 새 기억
구조를 공용 기본값으로 만들지 않는다. 어떤 판정도 의식 증거가 아니다.
