# NATIVE-DIALOGUE-4 — 작은 자체 모델용 대화 양성 비교

## 목표

`NATIVE-DIALOGUE-3`의 낮은 검증 오차가 실제 질문 응답으로 이어지지 않은 원인이 모델 크기인지,
작은 모델에 맞지 않는 자료인지 먼저 분리한다. 외부 사전학습 가중치 없이 기존 42.997M
`ConsciousLM`이 자연스러운 한국어·영어 질문, 짧은 설명, 앞선 사실과 정정을 처리하는 양성 경로를
확보한 뒤에만 307M 본학습으로 간다.

## 변경 전 근거

- Aya 번역 모음 100,000개씩과 동적 기억 20,000개씩을 답변 부분에 12,000회 학습했다.
- 답변 검증 오차는 `3.6413 → 2.1607`로 내려갔지만 고정 평가는 영어 `0/7`, 한국어 `1/7`이고
  기억·정정은 모두 실패했다.
- 직접 확인한 한국어 자료에는 번역투 문장 변환이 많았고, 영어에는 날짜·짧은 사실 답변이 많았다.
  모델은 이 표면 형식을 따라 했지만 질문의 핵심을 안정적으로 연결하지 못했다.
- 기존 순수 바이트 303M과 합성곱 계열 연구도 언어 생성 성공을 보장하지 않았다. 따라서 크기나
  합성곱만 늘리지 않고 자료 양성 비교를 먼저 세운다.

## 고정 설계

- 글자 입력은 기존 ByteLevel BPE를 유지한다. 256개 바이트 기본 알파벳이 있어 한국어·영어·오타·
  이모지를 알 수 없는 조각으로 버리지 않는다.
- 각 계산층의 `[두 칸 전, 한 칸 전, 현재]` 근거리 결합과 전체 문맥 주의집중을 함께 유지한다.
  진행 중인 체크포인트의 구조나 평가 기준은 바꾸지 않는다.
- 영어는 작은 모델을 위해 정리된 Apache-2.0 `HuggingFaceTB/smol-smoltalk` revision
  `f73fe857d519ff6ac5af2ea67c4d3834da7b8bcc`에서 고정 해시 100,000개를 사용한다.
- 한국어는 MIT `IkJun1/korean-qa-dataset` revision
  `e1f177a7497cf4e55e54d86101c6c522345441d2`에서 고정 해시 100,000개를 사용한다. 자료에 붙은
  `Human:`·`GPT:` 표시는 역할 표식과 중복되므로 내용에서만 제거한다.
- 언어별 네 파일과 기존 방식의 동적 기억·정정 20,000개 한 파일을 만든다. 학습기는 파일을 먼저
  같은 확률로 뽑으므로 영어·한국어 노출은 같고 기억 비중은 언어별 20%다.
- 고정 평가 문구와 가까운 행, 문맥 512조각을 넘는 행, 빈 답변은 학습 전에 제거한다. 실제 사용자
  대화 원문은 쓰지 않는다.
- `NATIVE-DIALOGUE-3` 32,000회 체크포인트에서 새 최적화 단계 12,000회를 답변 부분만 학습한다.
  전역 묶음 32와 기존 학습률 감소 방식은 유지한다.

## 통과·중단 기준

- 고정 평가 영어·한국어 각각 6/7 이상, 두 차례 기억과 정정 최종 질문 모두 통과
- 빈 답변·깨진 UTF-8·역할 표식 누출·과도한 반복 0건, 전체 답변 사람 검토 통과
- 통과하면 무작위 초기값 307M의 일반 글 학습 뒤 같은 검증 대화 자료로 답변 학습한다.
- 실패하면 307M을 바로 시작하지 않고, 학습 문맥에서 정답 확률과 자유 생성의 차이를 먼저 분해한다.
  그 뒤 순수 바이트 `ByteGPT`, 인과 합성곱 `CLMConvMoE`, 현재 혼합 구조를 같은 작은 양성 자료로
  비교한다.
- 통과는 자체 대화 모델의 양성 경로이며 의식 증거가 아니다.
