# NATIVE-DIALOGUE-5 — 303M 자체 대화 규모 회복

## 목표

외부 사전학습 가중치 없이, 글자를 잃지 않는 입력과 긴 문맥 계산을 함께 쓰는 Anima 자체 모델이
한국어·영어 질문과 앞선 사실·정정을 실제 답변으로 처리하는지 303M 규모에서 검증한다.

## 변경 전 근거

- 올바른 단어 조각표로 재실행한 42,996,928개 변수 혼합 모델은 검증 오차가 `5.2895 → 2.2126`으로
  내려갔지만 고정 평가는 영어 `1/7`, 한국어 `0/7`이었다. 작은 모델 양성 비교는 성립하지 않았다.
- 보관된 순수 바이트 303M 모델의 별도 양언어 평가도 영어 `2/7`, 한국어 `0/7`이었고, 353M 인과
  합성곱 모델은 영어 문장 모양은 만들었지만 관계 결합과 사실성 검사를 통과하지 못했다. 바이트나
  합성곱 하나만으로 대화가 회복된 근거는 없다.
- 현재 입력은 모든 UTF-8 바이트를 기본 알파벳으로 보존하면서 자주 나온 바이트열만 한 조각으로
  합친다. 각 층은 `[두 칸 전, 한 칸 전, 현재]`의 인과적 근거리 결합과 전체 문맥 주의집중을 함께
  사용한다. 따라서 순수 바이트의 글자 보존, 합성곱식 근거리 처리, 긴 관계 처리를 한 경로에서
  보존하는 현재 혼합형을 확대한다.

## 고정 실행

- 모델은 무작위 초기값이며 외부 모델 가중치는 0개다.
- 실제 변수 수는 실행 전 생성 검사로 확인한 `303,628,504`개다.
- 층 사이 내부 신호는 각 위치에서 앞쪽 값만으로 크기를 맞추는 `causal_prefix`를 쓴다. 기존
  체크포인트는 기록된 예전 계산을 유지하며, 새 모델만 미래 단어가 앞쪽 출력에 새지 않는 경로를 쓴다.
- 문맥은 1,024조각, 전역 묶음은 64개다. RTX 5090 사전 메모리 검사에서 `16 × 4`가
  `22.11 GiB`, H100 80GB에서 `32 × 2`가 `43.79 GiB`로 통과했다. 자료 노출량은 같게 유지하고
  장비별 한 번 처리량만 결과 전에 등록한 프로필로 선택한다.
- 1단계는 등록된 한국어·영어 일반 글과 대화를 섞어 35,000회 학습한다.
- 2단계는 `NATIVE-DIALOGUE-4`의 자연스러운 양언어 대화 100,000개씩과 동적 기억 20,000개씩을
  답변 위치에 10,000회 학습한다. 원문 바이트와 분할은 바꾸지 않고 1단계 단어 조각표로 240,000개
  대화를 다시 읽어 모두 문맥 1,024 안에 드는지 확인한 별도 원장을 쓴다. 1단계 단어 조각표와
  최적화 재개 상태를 그대로 쓴다.
- 실제 사용자 대화 원문은 학습·Git·HF에 넣지 않는다.
- 서로 독립인 자료 파일은 등록된 작업자 2개로 동시에 단어 조각화하되, 입력 파일 순서와 각 파일의
  최종 토큰 배열은 직렬 처리와 완전히 같아야 한다.
- 최종 생성은 이미 계산한 앞부분의 주의집중 열쇠·값과 가까운 두 위치를 재사용한다. 재사용을 끈
  기준 경로와 다음 단어 점수 및 고정 난수 출력이 일치해야 실제 서버에 배포한다.

## 통과 기준

- 고정 평가 영어·한국어 각각 6/7 이상, 두 기억·정정 최종 질문 모두 통과
- 빈 답변·깨진 UTF-8·역할 누출·과도한 반복 0건
- 저장 모델 재로드 결과 일치와 답변 원문 전체 사람 검토 통과
- 실제 WebSocket 5턴에서 이름·기한·위험 유지, 주제 복귀, 모르는 사실 비추측
- 정상 자체 답변에 외부 답변 호출 0건, 기존 대화 DB 행 수와 지문 변화 0건

자동 또는 사람 검토가 실패하면 상시 서버를 바꾸지 않는다. 결과를 본 뒤 같은 실행의 질문·기준·
seed를 바꾸지 않으며, 성공해도 의식의 증거로 해석하지 않는다.

## 진행 상태

2026-08-13 위 조건을 결과 전에 등록했다. 5090 메모리 검사는 학습 자료를 보지 않는 무작위 입력으로
수행했으며 모델 가중치나 결과를 남기지 않았다. 첫 본학습 100회 점검에서 층 사이 내부 신호가 문장
전체 평균을 사용해 뒤쪽 단어가 앞쪽 출력에 미세하게 새는 공용 오류를 발견했다. 체크포인트가 생기기
전 실행을 중단하고 토크나이저와 로그를 `target-invalid-noncausal-signal-20260813T0825Z`로 보존했다.
뒤쪽 토큰만 바꿨을 때 앞쪽 로그잇 변화는 최대 `7.09e-5`였다. 결과를 보지 않고 앞쪽 누적
평균·분산만 쓰도록 고치자 같은 반증의 변화량이 `0.0`이 됐고 관련 회귀 35개와 실제 변수 수
`303,628,504`를 확인했다. 학습기는 이제 자료를 읽기 전에 같은 반증을 실행하고 `1e-7`을 넘으면
종료한다. 수정 정본으로 35,000회를 처음부터 다시 실행하며 체크포인트마다 단어 조각표 SHA-256을
기록한다. 전처리 자료와 실행 산출물은 각각 비공개 Hugging Face
`dancinlab/anima-native-dialogue-303m-data-2026-08-13`,
`dancinlab/anima-native-dialogue-303m-2026-08-13`에 보존한다. 품질 판정과 상시 배포 여부는 학습과
고정 평가가 끝난 뒤 기록한다.

첫 `causal_prefix` 수정 실행은 100회 점검에서 학습 오차가 `NaN`이 되어 즉시 중단하고
`target-invalid-nan-20260813T094121Z`로 보존했다. 첫 위치의 앞쪽 분산은 항상 0인데
`sqrt(variance) + eps`는 순방향 값만 유한하고 역방향 기울기는 무한대가 되는 것이 원인이었다.
공용 정규화를 `sqrt(variance + eps)`로 바꾸고, 손실 또는 전체 기울기 크기가 유한하지 않으면
가중치 갱신 전에 실패하도록 학습기를 닫았다. 관련 회귀 36개와 실제 303,628,504개 변수 모델의
CUDA bfloat16 한 회 역방향 계산에서 손실·모든 기울기가 유한함을 확인한 뒤 같은 등록 조건으로
처음부터 다시 실행한다.

처음 등록한 전처리 작업자 8개는 H100 호스트 메모리를 `214 GiB`까지 사용한 뒤 작업 프로세스 하나가
강제 종료되어 학습 전에 중단됐다. 토큰 결과나 가중치는 생성되지 않았다. 일반 글을 압축된 `int32`
배열에 한 번만 복사하도록 바꾼 작업자 4개도 제한 메모리 `241 GiB` 중 `222 GiB`까지 사용해 학습
전에 안전 중단했다. 최종 작업자 수는 2개로 낮추고, 각 작업자 프로세스는 파일 하나를 처리한 뒤
교체해 Python 할당 메모리가 다음 파일로 누적되지 않게 한다. 직렬 처리와 토큰·순서가 같은 회귀
기준은 유지한다.

H100 정본 실행은 작업자 교체 시 실제 PID가 바뀌고 파일 묶음 사이 호스트 메모리가 `93 → 29 GiB`,
한국어 대형 묶음 뒤 `185 → 31 GiB`로 회수되는 것을 확인한 뒤 GPU 학습에 진입했다. 1,000회에서
학습 오차는 `8.898431`(100회)에서 `5.819154`로 내려갔고, GPU 메모리 `49,603 MiB`, 변수
`303,628,504`, 체크포인트·토크나이저·등록 사양 지문 일치를 확인했다. 재개 파일 SHA-256
`eb8ad2f3107e5731a0fe9d9b8f6ee45bed2f7af05a5ea0117c382390623c754f`는 비공개 HF 모델 저장소의
`checkpoints/step-001000/resume.pt`와 일치한다.

20,000회에서 학습 오차는 `3.185965`였고 재개 파일 SHA-256은
`8862711aff1f7b6fa06ea7f9b000e61263237cd3ca2b23bf305b037be1f7306b`다. 토크나이저 SHA-256
`cd9bba441ee9f187454244dc3a863f394b0bdf80086108fac050aef937f1e47b`, 등록 사양 지문, 실제 변수
`303,628,504`개를 다시 확인한 스냅샷을 비공개 HF 모델 저장소의 `checkpoints/step-020000`에 커밋
`e133fd0250ad12e93cbd1873724add644bef43bf`로 보존했다. 해당 커밋을 새 경로에 다시 내려받아 모델
가중치, 최적화기 280개 상태, 자료 순서 상태를 엄격하게 불러왔으며 원격 대용량 파일 크기와
SHA-256도 원본과 일치했다. 업로드와 복구 검사 중 기존 단일 H100 학습은 중단하지 않았다.

35,000회 1단계는 학습 오차 `8.898431 → 2.927776`, 검증 오차
`10.542016 → 2.742567`, `validation_descended=true`로 종료됐다. 재개 파일 SHA-256은
`09899a46b92b7f9b6b3072b85fe1098bc55785a2702066bdc52abe1ccc3fd285`, 배포용 가중치는
`e282cfca153ec0d12a11e33d780aa4b17d692ee79bc41ed94ee389fb7d900ce1`다. 두 파일과 토크나이저,
학습 요약, 전체 로그, 해시 원장을 비공개 HF 모델 저장소의 `checkpoints/step-035000`에 커밋
`ec2754a40a3e856841e88fddc7ebb3ad78344f2e`로 보존했다. 해당 커밋을 빈 폴더로 다시 내려받아
원격 대용량 파일 해시, 모델 텐서 293개, 최적화기 상태 280개, 실제 변수 `303,628,504`개와 엄격한
가중치 적재를 확인했다. 답변 위치 전용 10,000회 학습과 고정 품질 평가는 아직 시작하지 않았고,
상시 채팅 런타임은 기존 경로를 유지한다.
