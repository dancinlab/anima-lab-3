# RESET-1 — 기억 주소 회복 원인 분리

상태: 사전등록

선행 결과: `RECOVERY-1=RC1_ORDERED_RECOVERY_REPRODUCED`

## 질문

사건 세 개를 저장한 직후에는 질문 주소가 충돌하지만, 질문 전에 내부 상태를 몇 번 더 갱신하면
두 seed와 세 독립 자료 묶음에서 기억 선택이 회복됐다. 회복 원인은 아직 둘로 갈린다.

1. 새 감각 내용이 앞선 후보 흔적을 씻어낸다.
2. 외부 입력과 무관하게 내부 상태가 몇 단계 지나며 스스로 안정된다.

`RESET-1`은 새 기억 구조를 만들지 않고 이 둘만 분리한다.

## 얼리는 항목

- `RECOVERY-1`의 폭 32 `StableKeyProjector` 두 체크포인트와 값 원형
- `VectorMemory`, cosine 주소 선택, 값 판독 방식
- seed `1337 / 7331`, 서로 겹치지 않는 세 자료 묶음, 묶음당 512회
- 사건 세 개, 질문 가능한 첫 두 사건, 후보 세 개
- 주소 선택·최종 행동 90%, 값별 최저 재현율 75%, 내용 판독 90%
- 정확 주소·내용 맞바꾸기·복구·두 후보 양성 비교

결과를 본 뒤 단어, 갱신 횟수, 회차 수, 문턱, 주소 가중치를 바꾸지 않는다.

## 조건

모든 조건은 같은 회차와 같은 초기 난수를 쓰며 질문 전 내부 갱신을 `0 / 2 / 4 / 8`번 수행한다.
한 번의 갱신은 모두 `QuantumC.step()` 한 번이다.

- `varied_sensory`: 서로 다른 중립 감각 단어를 차례로 한 번씩 입력한다. 8개 단어는 회차마다
  중복 없이 사용한다.
- `repeated_sensory`: 등록된 중립 단어 `조용히` 하나만 같은 횟수만큼 반복 입력한다.
- `autonomous`: 감각 입력 없이 내부 상태만 같은 횟수만큼 갱신한다.

0회 조건은 세 조건의 계산과 결과가 완전히 같아야 한다. 각 조건은 독립 엔진에서 같은 seed로
시작하므로 한 조건의 난수 소비가 다른 조건에 영향을 주지 않는다. 주소 선택 정확도와 함께 정답
주소와 가장 강한 오답 주소 사이 평균 간격을 기록한다.

## 판정

먼저 자료 균형·중복 없음, 체크포인트 지문, 얼린 가중치, 동일 시작 seed, 동일 갱신 횟수,
0회 결과 동일성, 기억 API, 정확 주소·맞바꾸기·복구·두 후보 비교가 모두 유효해야 한다.

회복은 seed별로 0회가 실패하고 8회가 통과하며, 최종 행동과 주소 선택이 각각 5%p 이상 개선되고,
세 자료 묶음 모두 같은 방향일 때 성립한다.

- `RS1_AUTONOMOUS_SETTLING`: 세 조건 모두 두 seed에서 회복한다. 새 감각 내용 없이도 되므로
  내부 상태의 자체 안정화가 충분한 원인이다.
- `RS2_SENSORY_FORCING_RESET`: 두 감각 조건은 회복하지만 자체 갱신은 회복하지 않는다. 같은 단어
  반복도 충분하므로 새로움보다 외부 감각 힘 자체가 원인이다.
- `RS3_VARIED_INPUT_RESET`: 서로 다른 감각 조건만 두 seed에서 회복한다. 바뀌는 감각 내용이
  필요하다.
- `RS4_NO_REGISTERED_RECOVERY`: 어느 조건도 두 seed에서 회복하지 않는다. 선행 회복이 이번
  고정 조건에서 재현되지 않았다.
- `RS5_MIXED_MECHANISM`: 위 네 모양에 맞지 않거나 seed·자료 묶음이 갈린다.
- `RS0_INVALID`: 필수 통제나 실행 영수증이 하나라도 깨진다.

이 결과는 기억 주소 회복의 계산 원인을 가르는 검사이며 의식의 증거가 아니다. `RS1`이면 기다림을
기억 기능으로 새로 만들지 않고 현재 상태 안정화 곡선을 설명한다. `RS2`나 `RS3`이면 어떤 감각
성분이 주소 충돌을 푸는지 다음 검사에서만 좁힌다. `RS5`이면 새 구조를 추가하지 않는다.
