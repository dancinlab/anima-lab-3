# KEY-1 — 시간에 흔들리지 않는 기억 주소

상태: 사전등록 · 실행 전  
등록일: 2026-08-10  
선행 결과: `EPISODE-1=E2_KEY_RETRIEVAL_LOSS`

## 질문

같은 단어를 감각했어도 앞선 문맥과 시간이 다르면 `QuantumC` 위상 상태가 달라진다. 관계의 값이나
행동 정답을 보지 않는 작은 표준 주소 변환으로 같은 단어의 상태를 같은 기억 주소에 모을 수 있는가?

이번 검사는 새 기억 장치를 만들지 않는다. 기존 `VectorMemory`와 값 상태 읽기는 그대로 두고,
열쇠 상태의 셀 평균에 `96→32` 선형 변환 하나를 적용한다. 통과해도 의식이나 고유한 기억 능력의
증명이 아니라, 현재 내부 상태에 남은 감각 정체성을 시간에 덜 흔들리는 주소로 읽을 수 있다는
근거다.

## 실행 흐름

- `EPISODE-1`과 같은 회차 생성기, 단어, 감각 단계, 두 seed를 사용한다.
- 보정에는 `CONTROL-3`의 validation 1,024회차를 쓰고, 최종 평가는 겹치지 않는 eval 2,048회차를
  쓴다. 추상 회차와 실제 `QuantumC` 초기화 seed가 두 집합 사이에서 겹치면 무효다.
- 각 보정 회차에서 첫 번째 저장 열쇠, 두 번째 저장 열쇠, 방해 입력 뒤 질문 열쇠의 위상 상태를
  수집한다. 관계 값과 최종 행동 정답은 주소 변환의 입력·손실에 쓰지 않는다.
- 위상 상태는 셀 평균한 96개 값만 사용한다. `torch.nn.Linear(96, 32)`와 8개 학습용 주소 원형을
  함께 학습하며, 정규화한 주소와 원형의 코사인 점수에 교차 엔트로피를 적용한다.
- 학습 뒤 주소 변환을 얼리고 평가 2,048회차의 저장 열쇠와 질문 열쇠에만 적용한다. 값 상태,
  값 원형, `VectorMemory`, 코사인 검색, 내용 판독은 `EPISODE-1` 그대로다.
- 같은 구조를 표본마다 무작위 표찰로 학습한 가짜 변환을 함께 만든다. 가짜 검사는 최종 관계
  정답이 아니라, 보지 않은 상태의 실제 열쇠 정체성을 읽는 정확도로 판정한다.

## 고정 사양

- seed: `1337 / 7331`
- 보정 회차: 1,024, 회차당 주소 상태 3개
- 평가 회차: 2,048, 회차당 주소 상태 3개
- 입력 폭 96, 출력 폭 32, bias 사용
- 학습 1,000 step, batch 256, AdamW, 학습률 0.003, weight decay 0.0001
- 온도 0.1, gradient clip 1.0, 장치 CPU
- 값 원형과 `CONTROL-3` 체크포인트는 `EPISODE-1` 영수증에 고정된 파일을 그대로 사용

모든 수치·seed·팔·문턱은 `measurement/key_registry.py`를 단일 기준으로 구현한다.

## 비교와 개입

1. `stabilized_memory_normal`: 변환된 `QuantumC` 주소와 원래 `QuantumC` 값 상태
2. `stabilized_memory_partner_swap`: 저장 내용만 서로 맞바꾼 원인 차단
3. `stabilized_memory_recovered`: 정상 연결을 새 기억에 다시 저장한 복구
4. `raw_quantum_memory`: 변환 없는 `EPISODE-1` 주소 재생
5. `sensory_memory`: 직접 감각 주소를 쓰는 같은 `VectorMemory`
6. `keyed_attention`: 얼린 `CONTROL-3` 표준 열쇠 검색
7. `no_memory`: 회차 기억 없음
8. `shuffled_label_projector`: 같은 상태를 표본별 무작위 표찰로 학습한 가짜 주소 변환

정상·가짜 변환은 평가 상태의 8개 열쇠 구분 정확도를 따로 저장한다. 정상 기억은 저장 위치 선택률,
최종 정확도, 값별 재현율, 내용 읽기, 기억 API 일치, 주소 간격을 저장한다.

## 무효 조건

- README 사전등록 커밋 `8512f1c04` 이후 폭·학습량·seed·문턱이 바뀜
- 보정·평가 회차나 실제 초기화 seed가 겹치거나 열쇠·값·질문 위치 균형이 깨짐
- 원본 `EPISODE-1` 판정이 `E2`가 아니거나 결과·판정·체크포인트 지문이 달라짐
- 변환 없는 주소 재생이 원본 `EPISODE-1` 예측과 다름
- 직접 감각 기억이나 표준 열쇠 검색이 90% 미만, 기억 없음이 25% 초과
- 내용 맞바꾸기가 25% 초과하거나 복구 예측이 정상과 하나라도 다름
- 가짜 변환의 평가 열쇠 구분 정확도가 25% 초과
- seed·팔·체크포인트·수치가 누락되거나 NaN·무한값이 있음

## 사전 판정

- `K1_STABLE_KEY_VALID_NOT_UNIQUE`: 두 seed 모두 평가 열쇠 구분과 저장 위치 선택 90% 이상,
  최종 정확도 75% 이상, 값별 최저 재현율 60% 이상이며 모든 통제 통과
- `K2_KEY_ALIGNMENT_LOSS`: 한 seed 이상에서 평가 열쇠 구분 또는 저장 위치 선택이 90% 미만
- `K3_EPISODIC_PATH_NOT_RECOVERED`: 주소 구분과 위치 선택은 통과했지만 최종 정확도나 값별 재현율이
  통과하지 못함
- `K0_INVALID`: 자료·원본 재생·양성/음성 비교·개입·복구·파일 지문 조건 중 하나라도 무효

판정 우선순위는 `K0 → K2 → K1 → K3`다. `K1`이면 이 변환을 기본 엔진에 즉시 켜지 않고,
같은 주소 흐름을 공용 기억 호출부에 선택적으로 연결하는 `EPISODE-2`를 별도 사전등록한다. `K2`면
결과를 보고 폭이나 학습량을 늘리지 않고 정보가 셀 평균 전에는 남는지 다시 분해한다. `K3`면 주소
외의 첫 손실만 추적한다.
