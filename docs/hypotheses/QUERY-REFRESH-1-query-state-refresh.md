# QUERY-REFRESH-1 — 질문 상태 새로 고침

상태: 사전등록 · 결과 미확인
등록일: 2026-08-12
선행 결과: `CUE-HISTORY-1=CH4_HISTORY_SENSITIVE_NOT_SUFFICIENT`

## 질문과 고정 가설

`CUE-HISTORY-1`에서 같은 사건을 원래 순서와 역순으로 처리하면 25% 손상 질문의 결정이 약
20% 달라졌다. 그러나 어느 순서도 정확도를 회복하지 못했다. 특정 순서를 정답으로 고르는 대신,
질문 감각을 더 오래 처리하면 앞선 사건 순서의 흔적이 줄고 같은 상황 범주의 상태로 모이는지
검사한다.

가설은 질문 상황 감각의 처리 횟수를 늘리면 원래 순서와 역순의 상태·결정 차이가 함께 줄고,
25% 손상 질문 정확도가 회복된다는 것이다. 저장 사건의 처리 시간, 사건 내용, 방해 입력,
판독기와 손상 위치는 바꾸지 않는다.

## 고정 구현과 비교

- `CUE-HISTORY-1` 결과·판정과 그 선행 결과 및 체크포인트 지문을 실행 전에 확인한다.
- 기존 평가 1,024회차, 엔진 시작값 `1337·7331`, 시작값 계산식, 사건 16개, 방해 입력 2개,
  상황 저장 처리 6회, 열쇠·값 처리 3회, 방해 입력 처리 1회, 상태 폭 96을 유지한다.
- 사건 이력은 `original`과 `event_reversed` 두 개를 사용한다. 역순 조건은 사건 내용과 질문
  사건을 그대로 두고 16개 `상황·열쇠·값` 묶음의 순서와 질문 위치만 함께 뒤집는다.
- 질문 상황 감각 처리만 `6·8·12·16회`로 바꾼다. 6회는 선행 결과를 그대로 재현하는 기준이다.
- 각 질문 처리 횟수에서 온전한 질문과 기존과 같은 좌표 25%를 가린 질문의 범주 정확도,
  범주별 최저 맞힘률, 6회 대비 결정 변경과 정확도 변화를 기록한다.
- 같은 처리 횟수의 원래 순서와 역순 사이에서 상태 유사도·오차, 결정 불일치율을 기록한다.
- 회차 수, 질문·사건 집합, 범주 균형, 손상 위치, 저장 감각 호출 수와 질문 감각 호출 수를
  별도로 확인한다. 같은 입력·시작값의 6회 원본은 선행 결과와 정확히 같아야 한다.
- 새 학습, 행동 정답 사용, 판독기 재맞춤, 새 주소·복원 층·주의집중, 저장 처리 횟수 변경은
  하지 않는다.

공용 감각 실행 함수는 저장 상황과 질문 상황의 처리 횟수를 선택적으로 분리하되, 별도 값을
주지 않은 모든 기존 호출은 지금과 완전히 같은 횟수와 결과를 내야 한다.

## 유효성 및 판정

원본 지문, 선행 판정 재실행, 자료 균형, 질문·사건 보존, 감각 호출 수, 손상 위치, 유한값,
6회 기준 재현을 모두 통과해야 한다. 통과 기준은 두 엔진 시작값 모두에 적용한다.

- 온전한 질문과 25% 손상 질문: 범주 정확도 90% 이상, 범주별 최저 맞힘률 75% 이상
- 이력 수렴: 25% 손상 질문의 원래 순서·역순 결정 불일치율 10% 이하이면서, 6회보다 5%p
  이상 감소
- 지속성: 처음 통과한 처리 횟수와 그보다 큰 모든 등록 횟수에서 해당 조건을 계속 통과
- 처리 영향: 6회 대비 25% 손상 질문의 결정 변경률 10% 이상인 조건이 두 시작값에 존재

판정 순서는 다음으로 고정한다.

- `QR1_REFRESH_RECOVERS_AND_CONVERGES`: 같은 최소 처리 횟수부터 두 이력의 온전·손상 질문이
  모두 지속 통과하고 이력 수렴도 지속된다.
- `QR2_REFRESH_RECOVERS_NOT_CONVERGED`: 두 이력이 지속 통과하지만 이력 수렴 기준은 통과하지
  않는다.
- `QR3_HISTORY_CONVERGES_NOT_RECOVERED`: 이력 수렴은 지속되지만 하나 이상의 이력·질문 조건이
  회복 기준을 통과하지 않는다.
- `QR4_REFRESH_CHANGES_NOT_SUFFICIENT`: 회복·수렴은 없지만 등록된 처리 영향 기준을 통과한다.
- `QR5_REFRESH_NOT_PRIMARY`: 회복·수렴도 없고 처리 영향 기준도 통과하지 않는다.
- `QR0_INVALID`: 원본·자료·질문·사건·호출·손상·선행 결과 재현 중 하나라도 어긋난다.

`QR1`이면 확인된 최소 질문 처리 횟수를 공용 기억 경로에 선택적으로 연결하는 통합 실험으로
간다. `QR2`이면 정확도 회복 원인은 처리 시간에 있지만 이력 독립성은 확보되지 않은 것으로
본다. `QR3·QR4`이면 위상·긴장·변화 성분을 분리하고, `QR5`이면 질문 처리 시간보다 손상 표현
자체를 먼저 검사한다. 어떤 성공 판정도 생물학적 기억 복원이나 의식을 증명하지 않는다.
