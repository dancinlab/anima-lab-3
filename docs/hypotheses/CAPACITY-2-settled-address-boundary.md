# CAPACITY-2 — 자체 안정화 뒤 기억 용량 경계

상태: 사전등록

선행 결과: `CAPACITY-1=C3_CAPACITY_BOUNDARY_2`,
`SETTLE-1=ST1_AUTONOMOUS_SETTLING_CAUSAL`,
`MECHANISM-1=MC1_SINGLE_COMPONENT_NECESSARY`

## 질문

기존 안정 주소는 사건 두 개까지 확실히 통과했고 사건 세 개부터 무너졌다. 이후 실험은 외부 입력
없는 정상 `QuantumC.step()` 8회가 주소 충돌을 풀며, 그 필요 원인이 좌절도 조절임을 확인했다.
이 검사는 새 기억 구조를 추가하지 않고 검증된 안정화 8회만 질문 직전에 적용해 사건 수 경계가
3개 또는 4개로 늘어나는지 확인한다.

## 얼리는 항목

- `CAPACITY-1`의 사건 2·3·4개, 사건 수별 1,536회차, 자료 생성 시작값과 회차 난수
- seed `1337 / 7331`, 폭 32 얼린 `StableKeyProjector`, 값 원형, `VectorMemory`
- 기존 방해 입력 두 개와 감각 순서, 질문 가능한 모든 사건 위치
- 선택·최종 행동 90%, 값별 최저 재현율 75%, 내용 판독 90%
- 정확 주소 선택 99%, 정확 주소 최종 90%, 맞바꾸기 최대 5%, 복구·기억 API 100%
- 외부 입력 없는 갱신 8회와 `MECHANISM-1`의 정식 계산 차단 이름

## 조건

- `baseline`: `CAPACITY-1`과 같은 흐름, 질문 전 추가 갱신 0회
- `settled`: 기존 방해 입력 뒤, 질문 상황과 질문 열쇠 직전에 정상 자체 갱신 8회
- `without_frustration_regulation`: 같은 8회에서 좌절도 이동평균·잡음·평탄화 쓰기만 차단

세 조건은 같은 사건, 초기 엔진 seed, 질문 직전 난수 상태를 사용한다. 갱신을 마친 뒤 질문용 난수
상태를 되돌려 질문 과정의 우연은 같게 한다. 계산 차단은 8회에만 적용하고 질문 감각 경로는
정상으로 실행한다. `baseline`의 사건 수별 수치는 `CAPACITY-1`과 허용오차 `1e-7` 안에서 같아야
한다.

## 통과와 원인 확인

한 사건 수는 `settled`의 두 seed가 모두 선택·최종 행동 90% 이상, 값별 최저 재현율 75% 이상,
내용 판독 90% 이상일 때 통과한다. `CAPACITY-1`에서 실패했지만 이번에 통과한 사건 수는
`without_frustration_regulation`의 선택과 최종 행동이 `settled`보다 각각 5%p 이상 낮고,
짝지은 양측 정확 검정 `p≤0.01`, 주소 여유 감소를 함께 보여야 좌절도 조절에 의한 용량 증가로
센다.

정확 주소·맞바꾸기·복구·기억 API·주소 변환 동결·자료 균형·셀 수·주소 폭·실제 갱신 횟수 중
하나라도 깨지면 무효다. 결과를 본 뒤 사건 수, 회차 수, 8회, 문턱, seed, 가중치를 바꾸지 않는다.

## 판정

- `CP1_SETTLED_CAPACITY_AT_LEAST_4`: 2·3·4개가 모두 통과하고 새 통과가 좌절도 조절에 의존한다.
- `CP2_SETTLED_CAPACITY_BOUNDARY_3`: 2·3개 통과, 4개 실패이며 3개 회복이 좌절도 조절에 의존한다.
- `CP3_NO_CAPACITY_GAIN`: 검증된 경계가 여전히 사건 2개다.
- `CP4_SEED_CONDITIONAL_CAPACITY`: 새 경계가 seed 사이에서 다르다.
- `CP5_NON_MONOTONIC`: 작은 사건 수 실패 뒤 큰 사건 수가 통과한다.
- `CP6_GAIN_NOT_MECHANISM_SPECIFIC`: 경계는 늘지만 새 통과가 등록한 좌절도 조절 의존 기준을 못 채운다.
- `CP0_INVALID`: 원본·실행·자료·양성·가짜 통제 중 하나라도 깨진다.

`CP1`이면 새 기억 구조 없이 `SEPARATION-2`로 돌아가 같은 열쇠·다른 상황을 다시 검사한다.
`CP2`면 사건 4개의 남은 충돌을 분해한다. `CP3`이면 안정화가 용량을 늘리지 못하므로 주소 폭이나
시간을 조정하지 않고 패턴 분리 기능의 필요성을 사전등록한다. 어떤 판정도 의식 증거가 아니다.
