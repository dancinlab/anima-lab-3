# VALIDITY-1 — 행동 경로 분해 검사

상태: 사전등록 · 진행 중  
등록일: 2026-08-10  
선행 결과: `RELATION-1=R0_INVALID`

## 질문

표준 `GRU`도 실패한 `RELATION-1`에서 첫 정보 손실은 감각, 관계 계산, 작은 행동판, 기존 언어
출력 중 어디에서 발생했는가?

이번 검사는 `RELATION-1`의 구조·학습률·학습 횟수·난수를 바꾸지 않는다. 보관된 역할 학습 수리
체크포인트와 결과를 그대로 얼리고, 이미 계산된 공용 흐름의 중간값만 읽는다. 결과를 보고 기존
관계층을 세 번째로 조정하지 않는다.

## 고정한 자료와 원본

- 원본 실험: `relation1_hippocampal_role_content_binding_role_training_repair`
- seed: `1337 / 7331`
- 팔: `quantum_workspace_2 / quantum_relation / memory_relation / gru`
- 원본 결과: `measurement/relation_results.json`
- 원본 판정: `measurement/relation_verdict.json`

- 체크포인트 파일의 SHA-256은 원본 결과 영수증과 모두 같아야 한다.

평가 자료는 원본 등록 함수로 다시 만들며 단서·정답 균형과 원본 사양 지문이 달라지면 즉시
`V0_INVALID`다. 새 언어 모델이나 새 감각 엔진을 만들지 않는다.

## 고정한 측정 구간

1. **감각:** 두 모듈의 원본 상태에서 각 단서 번호를 별도로 읽는다.
2. **관계 계산:** 각 팔이 실제로 만든 `GRU` 마지막 상태, 관계 문맥 또는 공유 공간 상태에서 다섯
   정답을 읽는다.
3. **작은 직접 행동판:** 같은 최종 정규화 코드에 작은 선형 행동판만 붙여 정답을 읽는다. 언어
   모델은 통과하지 않는다.
4. **언어 출력:** 체크포인트의 기존 투사층과 고정 언어 모델이 A~E에 준 점수와 실제 선택을
   그대로 재생한다.

각 읽기 검사는 학습 자료로만 맞추고 분리된 평가 자료에서 채점한다. 정확도·정답별 재현율·5×5
혼동표를 저장한다. 정답을 32번 독립적으로 섞은 가짜 검사의 평균 정확도도 저장한다.

## 학습·실제 사용 방식 차이

`GraftActionChannel`은 학습 중 현재 묶음 평균을 빼지만 실제 사용에서는 누적 이동 평균을 뺀다.
동일한 원시 코드에 다음 두 계산을 모두 적용한다.

- `train_style`: 등록 학습 묶음 크기 8의 현재 평균 사용
- `runtime_style`: 체크포인트에 저장된 `population_mean` 사용

팔별·seed별 코드 차이와 직접 행동판 정확도 차이를 기록한다. `train_style`은 통과하고
`runtime_style`만 실패하면 공용 정규화 흐름의 문제로 판정한다. 저장 시점 선택은 새로 탐색하지
않고 원본 800단계 체크포인트 하나만 사용한다.

## 유효성 및 문턱

- 감각의 두 단서 읽기: 두 seed 모두 각각 90% 이상
- 관계 계산과 작은 직접 행동판: 두 seed 모두 80% 이상
- 언어 출력: 원본 등록 기준과 같이 두 seed 모두 80% 이상
- 가짜 정답 읽기 평균: 모든 구간 40% 이하
- 각 정답별 평가 표본 존재, 모든 수치 유한, 복구 계산 완전 일치
- A~E는 서로 다른 한 토큰이며 모든 정답에서 작은 행동판이 적어도 한 번 선택 가능해야 함

작은 행동판은 실패 위치 측정용이며 새 정식 행동 경로로 채택하지 않는다. 양성 비교인 `GRU`와
정확한 감각 기억인 `memory_relation`을 먼저 검사한다. 둘 다 관계 계산 구간에서 실패하면 이후
팔의 구조적 성공·실패를 해석하지 않는다.

## 사전 판정

- `V1_SENSE_LOSS`: 원본 감각 상태에서 단서 하나 이상이 90% 미만
- `V2_RELATION_LOSS`: 감각은 남지만 `GRU` 또는 관계 코드의 정답 읽기가 두 seed에서 80% 미만
- `V3_LANGUAGE_LOSS`: 실제 사용 방식의 직접 행동판은 80% 이상이지만 기존 언어 출력만 80% 미만
- `V4_PROTOCOL_LOSS`: 학습 방식 직접 행동판은 80% 이상이고 실제 사용 방식만 80% 미만
- `V5_PATH_VALID`: 감각·관계·직접 행동판·언어 출력이 모두 두 seed에서 문턱 통과
- `V0_INVALID`: 원본 결과·판정 재생, 사양, 자료 균형, 체크포인트 지문, 가짜 검사, 유한 수치,
  행동 토큰 중 하나라도 검증 실패

판정 우선순위는 `V0 → V1 → V4 → V2 → V3 → V5`다. 여러 팔이 다르게 실패하면 양성 비교
`GRU`의 첫 실패 지점을 전체 실험 판정으로 삼고 다른 팔은 참고값으로만 남긴다.

## 다음 단계

`V5_PATH_VALID`일 때만 `EPISODE-1`을 바로 시작한다. `V3`이면 언어 출력 경로를 분리해 고치고,
`V4`이면 공용 정규화의 학습·실제 사용 계산을 하나로 통일한 뒤 같은 검사를 다시 한다. `V1`이나
`V2`이면 관계 기억을 추가하지 않고 해당 첫 손실 구간만 수정한다.

성공해도 의식 증명이 아니다. 현재 행동 실험이 어느 지점까지 유효한지 확인하는 기반 검사다.
