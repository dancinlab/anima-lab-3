# NATIVE-DIALOGUE-1 — Anima 자체 대화 모델

## 질문

외부 언어 모델의 가중치나 답변 호출 없이, 이 저장소의 언어 계산층과 내부 상태·기억 경로만으로
한국어와 영어의 의미 있는 대화를 만들 수 있는가?

## 변경 전 실제 흐름

현재 상시 서버는 `AnimaUnified.process_input()`에서 내부 상태, 최근 대화와 관련 기억을 계산한 뒤
`_generate_dialogue_answer()`의 `claude` 갈래로 보낸다. Claude가 실패하면 기존
`PureConsciousness` 답변으로 돌아간다. 저장소에는 자체 `ConsciousLM`과 `model` 갈래가 있지만,
로더는 오래된 바이트 체크포인트만 찾고 현재 상시 서버는 `--no-conscious-lm`으로 이를 끈 상태다.

별도 Anima 연구 실행기로 학습해 HF `dancinlab`에 보관한 303M 바이트 모델은 외부 체크포인트를
쓰지 않은 진짜 자체 모델이었다. 하지만 한국어·영어 평가 14개가 모두 실패했고, 답변이 같은 구절을
반복했다. 일반 글·대화 검증 손실이 내려간 사실만으로 대화 가능성을 판정할 수 없다는 양성 증거다.

## 가설과 근본 수정

주된 원인 후보는 256개 바이트 출력이 한 글자와 한 단어의 뜻을 지나치게 긴 경로로 배우게 하면서,
현재 자료량과 학습량에서 반복 구덩이에 빠진 것이다. 모델 크기나 처리 횟수만 늘리지 않는다.

- `ConsciousLM`의 기존 계산층, `standard` FFN 비교층, 체크포인트 설정과 긴장 계측을 재사용한다.
- 입출력은 훈련 자료만으로 만든 표준 BPE 단어 조각 방식으로 바꾼다. 어휘와 특수 토큰은 한 정본
  설정에서 관리한다.
- 외부 사전학습 가중치는 사용하지 않는다. 모델과 단어 조각기는 모두 무작위 초기값에서 학습한다.
- 일반 글 학습과 사람 대화의 답변 학습을 분리해 기록한다. 대화에서는 사용자 문장이 아니라
  assistant 답변과 턴 종료 토큰을 직접 학습한다.
- Anima 내부 상태와 기억은 언어 기본기가 통과한 뒤 기존 공용 호출을 통해 조건으로 제공한다.
  이를 먼저 모델 속에 섞어 언어 실패 원인을 흐리지 않는다.

## 고정 순서

1. 작은 모델로 자료 → 단어 조각 → 학습 → 저장 → 재로드 → 생성 전체 흐름을 검사한다.
2. 같은 자료와 계산량에서 기존 바이트 방식보다 반복·응답 경계·별도 대화 복원이 나은지 확인한다.
3. 작은 모델이 통과할 때만 약 300M 본모델을 Vast.ai에서 학습한다.
4. 자동 문항과 사람 검토를 모두 통과할 때만 로컬 네트워크 상시 서버를 `model` 갈래로 바꾼다.
5. Claude 경로는 비교·긴급 복구용으로 남기되 자체 모델의 정상 답변에 섞지 않는다.

## 자료 보호

- 한국어·영어 일반 글과 사람 대화의 출처, 사용 허가, 파일 크기와 SHA-256을 기록한다.
- 평가 문항 및 가까운 중복 문장은 학습 자료에서 제외한다.
- 실제 사용자 대화 원문은 명시적 동의 없이 학습·Git·HF 입력으로 쓰지 않는다.
- 체크포인트와 자료는 비공개 HF `dancinlab` 조직에 보관한다.

## 통과 기준

작은 양성 모델:

- 저장 후 재로드 결과가 동일하다.
- UTF-8 손상·빈 답변이 0건이다.
- 등록한 별도 대화에서 응답 종료, 비반복, 질문 관련성, 두 턴 기억이 모두 작동한다.
- 같은 조건의 바이트 모델보다 반복률과 의미 복원이 모두 낫다.

약 300M 본모델:

- 외부 체크포인트에서 가져온 가중치가 0개다.
- 한국어 7개·영어 7개에서 의미 통과가 각각 6개 이상이다.
- 빈 답변, UTF-8 손상, 질문 복사, 반복, 다음 사용자 역할 누출이 모두 0건이다.
- 두 턴 기억과 뒤이은 정정 문항을 모두 통과한다.
- 모든 답변을 사람이 읽어 의미가 있다고 판정한다.
- 내부 상태·기억을 차단하면 등록한 기억 문항이 떨어지고 복원하면 회복한다.

## 중단 기준

- 작은 모델이 실패하면 300M을 대여하지 않는다.
- 본모델이 자동 또는 사람 검토를 하나라도 실패하면 상시 서버에 배포하지 않는다.
- 결과를 본 뒤 평가 문항, 기준, seed 또는 생성 설정을 바꿔 같은 실험의 성공으로 세지 않는다.
- 통과해도 의식 증거로 해석하지 않는다. 자체 언어·기억 경로가 작동한다는 결과로만 기록한다.

## 소형 실행 결과와 중간 선별

첫 소형 실행은 5,428,832개 변수, 단어 조각 4,096개, 문맥 256개, 대화 27,907개, 2,000회
학습으로 고정했다. 별도 검증 손실은 `8.3544579 → 4.9170157`로 내려갔고 체크포인트를 안전하게
다시 열 수 있었다. 그러나 고정 질문에서 한국어는 관련 없는 문장 조각을 이어 붙였고 영어는 철자가
깨지거나 같은 글자를 반복했다. 판정은 `ND1_MICRO_LANGUAGE_BASE_INSUFFICIENT`이며 대화 가능 통과가
아니다.

코드 감사에서 역할 순서, 답변 위치 표시, 턴 종료 학습, 인과적 다음 조각 정답, 저장·재로드 오류는
발견되지 않았다. 첫 실행은 일반 글 없이 대화 자료만 사용했고 모델도 지나치게 작았으므로, 303M
가능성 전체를 이 실행 하나로 기각하지 않는다. 다음 중간 선별은 결과를 보기 전에 다음처럼 고정한다.

- 외부 가중치 없이 무작위 초기화한다.
- `standard` FFN, 42,996,928개 변수, 단어 조각 16,000개, 폭 384, 8층, 6개 머리, 문맥 512개를 쓴다.
- 기존 비공개 HF 자료의 한국어·영어 일반 글과 대화를 함께 사용한다.
- 전역 묶음은 32개, 학습은 8,000회, 최대 학습률은 `3e-4`로 고정한다.
- 한국어·영어 일반 글과 대화 파일을 각각 먼저 같은 확률로 고른 뒤 파일 안의 위치나 예시를 고른다.
- 원본 303M 실패 때 사용한 의미 질문을 옮긴 고정 평가 파일을 사용하며, 생성 설정과 6/7 기준을
  결과 뒤에 바꾸지 않는다.
- 중간 모델이 고정 평가를 통과할 때만 약 300M 학습을 허용한다. 실패하면 보관 후 중단하며 현재
  Claude 상시 경로는 유지한다.

함께 수정한 공용 결함은 두 가지다. 모델 파일 호환 확인값을 연구 문턱과 분리해 평가 문구 변경이
정상 체크포인트를 막지 않게 했고, 시작과 끝 검증이 난수 진행 때문에 서로 다른 묶음을 보던 흐름을
같은 묶음 재생으로 바꿨다. 이 수정은 학습 결과를 좋게 만드는 조정이 아니라 비교 가능성을 보장한다.

최초 원격 시작 뒤 결과를 보기 전 자료 수를 감사하자 한국어 대화는 25,599개, 영어 대화는
2,308개였다. 개별 대화를 한 목록으로 섞던 흐름은 대화 노출의 91.7%를 한국어에 배정하므로 양언어
6/7 평가의 양성 선별이 아니다. 2,100회 직후 실행을 중단하고 `ND0_INVALID_LANGUAGE_EXPOSURE`로
보존했다. 결과에 맞춘 조정이 아니라 입력 분포의 사전 오류 수정이며, 파일을 먼저 균등 선택하는
공용 흐름으로 바꾼 뒤 같은 seed와 8,000회 조건을 처음부터 재실행한다.

## 중간 선별 최종 결과

균형 재실행은 사전 고정한 조건 그대로 8,000회를 완료했다.

- 변수: 42,996,928개
- 외부 사전학습 가중치: 0개
- 한국어·영어 대화 파일 선택 확률: 각각 50%
- 별도 검증 오차: `9.73740196 → 4.44899243`
- 학습 건너뜀·발산·메모리 부족: 0건
- 최종 모델 SHA-256: `9d607a4778a60c2c93af11f8792b3d162c0c6da81a6604e138e51b95e1ce5874`
- 단어 조각기 SHA-256: `bee5a08ee16e14eb0c4ab73cf36145f987aed9b08ee47b7feb7801683c722319`
- 고정 평가 SHA-256: `659ab0fc0c2335852c4e9fe18e7a132d106cd33ac76c513d335705bd4e18e60c`

고정 평가의 형식 검사는 모두 통과했다. 빈 답변, 깨진 UTF-8, 역할 표시 누출, 질문 복사와 등록한
반복 기준 위반은 0건이었다. 그러나 의미 통과는 영어 `3/7`, 한국어 `0/7`이며 두 턴 기억과 정정도
실패했다. 사람이 14개 답변을 모두 읽은 결과도 같다. 영어 얼음 질문에 근거 없는 온도 수치를 만들고,
한국어 시험 불안 질문에는 육아와 영양을 답했으며, 파란 상자의 빨간 열쇠와 정정된 선호를 회수하지
못했다. 문장처럼 보이는 표면은 배웠지만 질문에 맞는 사실과 대화 상태를 안정적으로 사용하지 못했다.

최종 판정은 `ND2_SCREEN_SEMANTIC_INSUFFICIENT`다. 단어 조각 방식과 파일 단위 균형 선택은 이전
바이트 모델의 깨진 철자·노골적인 구절 반복을 줄였지만, 의미 있는 양언어 대화의 양성 비교를 만들지는
못했다. 사전 중단 기준에 따라 약 300M 본학습과 상시 서버 교체를 수행하지 않는다. 현재 Claude
안전 경로를 유지하며 이 결과를 Anima 자체 대화가 가능하다는 증거로 인용하지 않는다.

균형 최종본, 학습 재개본, 단어 조각기, 학습 기록, 고정 평가와 최초 자료 쏠림 무효본은 비공개 HF
`dancinlab/anima-native-dialogue-screen-2026-08-13`에 보존한다. 실제 사용자 대화 원문은 어느
학습·보관 자료에도 포함하지 않았다.
