# CONTEXT-SETTLE-1 — 상황 전환 뒤 최소 안정화 횟수

상태: 완료 · `CT1_MINIMUM_SETTLING_FOUND`
등록일: 2026-08-11
선행 결과: `COMPONENT-2=CS2_COMPONENT_FIT_INVALID`

## 질문과 고정 가설

`COMPONENT-2`의 열쇠 성분은 모든 위치에서 통과했지만, 상황 성분은 새 상황 묶음의 첫 사건인
9·13번째에서 실패했다. 상황 단어는 현재 공용 감각 흐름에서 세 번 처리된 직후 읽힌다. 이번
검사는 직전 상황의 흔적을 지우는 데 세 번보다 많은 처리가 필요한지 확인한다.

가설은 새 상황을 충분히 반복 처리하면, 기존에 얼린 결정형 상황 주소 변환만으로도 현재 상황을
다시 구분할 수 있다는 것이다. 새 주소 층을 만들거나 변환을 다시 맞추지 않는다.

## 고정 설계

- `COMPONENT-2` 결과·판정·`stable_components.pt`의 지문을 확인하고 그 안의 상황 주소 변환을
  읽기 전용으로 사용한다.
- 원본 보정 512회차와 `COMPONENT-1·2`, `CONJUNCTION-2` 평가 자료와 겹치지 않는 새 512회차를
  사용한다.
- 엔진 시작값은 `1337·7331`, 사건 수는 16개, 위치는 1~16을 유지한다.
- 같은 사건과 같은 엔진 시작값을 처리 횟수 `3·4·6·9`에 짝지어 실행한다.
- 각 사건에서 상황 단어 처리 횟수만 바꾼다. 열쇠·값은 기존 3회, 방해 입력과 질문 전 처리는
  선행 실험과 같게 둔다.
- 상황 주소 변환의 가중치, 입력 폭 96, 출력 폭 32, 셀 평균 방식은 고정한다.
- 각 횟수·시작값·위치에서 전체 정확도와 상황 8종별 최저 맞힘률을 기록한다.
- 호출 횟수, 사건 시작값, 셀 수, 유한값, 변환 가중치 불변을 검사한다.
- 결과를 본 뒤 처리 횟수를 추가하거나 기준을 바꾸지 않는다.

## 유효성 및 판정

기본 3회에서 두 시작값 모두 9번째 또는 13번째의 정확도 90%나 상황별 최저 맞힘률 75%를
통과하지 못해야 선행 실패가 독립 자료에서 재현된 것으로 본다. 기본 3회가 이미 안정적이면
`CT3_BASELINE_ALREADY_STABLE`, 자료·호출·지문 검사가 하나라도 어긋나면 `CT0_INVALID`다.

각 후보 횟수는 두 시작값의 16개 모든 위치에서 정확도 90% 이상, 상황별 최저 맞힘률 75% 이상일
때만 통과한다. 등록된 순서에서 처음 통과한 값을 최소 안정화 횟수로 정한다.

- `CT1_MINIMUM_SETTLING_FOUND`: 4·6·9회 중 최소 통과 횟수가 존재한다.
- `CT2_NO_REGISTERED_SETTLING_RECOVERY`: 9회까지도 하나 이상의 위치가 실패한다.
- `CT3_BASELINE_ALREADY_STABLE`: 기본 3회가 선행 실패를 재현하지 않는다.
- `CT0_INVALID`: 자료 분리, 원본 지문, 상태 모양, 고정 변환, 호출 수 또는 수치 검사가 실패한다.

`CT1`이어도 감각 처리 시간을 늘린 일반 기억 주소 수리일 뿐 의식 증거는 아니다. `CT1`이면
다음 실험에서 찾은 최소 횟수를 공용 상황 처리 경로에 선택적으로 연결해 원래 결합 행동을
재검증한다. `CT2`면 반복 횟수 조정은 중단하고, 현재 상황과 직전 상황을 따로 읽는 최소 상태 전환
검사로 간다.

결과를 보기 전 이 문서와 README를 커밋하고 그 커밋을 실행 사양의
`preregistration_commit`으로 고정한다.

## 실행과 결과

사전등록 커밋은 `aa3330d6e`, 실행기 커밋은 `f3ae9ad15`다. 새 512회차는 선행 보정·평가 자료와
겹침이 0이었고 상황·열쇠·값, 질문 위치가 등록대로 균형이었다. 두 엔진 시작값과 네 처리 횟수는
각각 같은 512개 사건 시작값을 사용했다. 얼린 상황 주소 변환과 원본 체크포인트 지문은 실행 전후
같았다.

기본 3회는 9번째 전환 정확도 `74.22~76.17%`, 13번째 `40.82~41.60%`로 선행 실패를
재현했다. 4회는 각각 `86.91~87.11%`, `63.87~65.43%`로 개선됐지만 등록 문턱에는 못 미쳤다.

6회는 9번째가 두 시작값 모두 `98.24%`, 가장 어려운 13번째가 `92.77~92.97%`였고 그 위치의
상황별 최저 맞힘률도 `83.08~84.62%`였다. 나머지 위치까지 두 시작값에서 모두 통과했다. 9회는
13번째 정확도 `99.22%`, 최저 맞힘률 `94.34%`로 통과했지만 더 많은 처리를 요구한다.

## 판정과 다음 단계

판정은 `CT1_MINIMUM_SETTLING_FOUND`, 최소 안정화 횟수는 6회다. 직전 상황 흔적의 근본 원인은
새 상황을 세 번만 처리하고 너무 일찍 주소를 읽은 공용 감각 호출 조건이었다. 비선형 주소층이나
추가 주소 학습은 필요하지 않았다.

다음 `CONTEXT-SETTLE-2`는 기존 열쇠·값의 3회 처리는 유지하고, 상황 처리만 선택적으로 6회로
연결해 `CONJUNCTION-2`의 1,024회차 전체 행동을 다시 검사한다. 성공해도 일반 기억 통로의 시간
조정이며 의식 증거는 아니다.

결과·판정과 재사용한 얼린 상황·열쇠 체크포인트는 비공개 Hugging Face 조직 보관소
`dancinlab/anima-lab-research-archive`의 `context-settle1-transition` revision에 보존했다. Hugging
Face 커밋은 `d55a3ccbec0d157b4d4758c767bce942d1ba3618`, manifest SHA-256은
`c825b7a84af6cf21959acaa1046f116ee6f9b776f086dc23804a71c74bdc467e`다. 원격으로 다시 내려받은
세 항목의 지문이 모두 원본과 일치했다.
