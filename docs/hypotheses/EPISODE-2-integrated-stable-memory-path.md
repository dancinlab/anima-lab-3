# EPISODE-2 — 안정 주소의 공용 기억 경로 연결

상태: 완료 · `E2I_PATH_RECOVERED_NOT_UNIQUE`
등록일: 2026-08-10  
선행 결과: `KEY-1=K1_STABLE_KEY_VALID_NOT_UNIQUE`

## 질문

`KEY-1`에서 검증한 시간 안정 주소를 기존 공용 기억 호출부에 선택적으로 연결했을 때, 원시
`QuantumC` 상태의 저장부터 검색과 최종 행동까지 같은 회복이 유지되는가?

이번 검사는 새 주소를 학습하거나 새 기억 장치를 만들지 않는다. `KEY-1`의 seed별 얼린 주소
변환과 기존 `VectorMemory`를 그대로 쓴다. 차이는 주소 변환을 실험 실행기 바깥에서 미리 적용하지
않고, 공용 `VectorMemory.store/retrieve`가 선택형 `key_transform`을 통해 한 번 적용한다는 점뿐이다.
통과해도 일반 기억보다 고유하거나 의식의 증거라는 뜻은 아니다.

## 공용 흐름 변경

- `VectorMemory` 생성자에 기본값 `None`인 선택형 `key_transform`을 추가한다.
- 변환이 없으면 기존 저장·검색 계산과 반환값이 바이트 수준으로 유지되어야 한다.
- 변환이 있으면 저장 열쇠와 검색 질문을 같은 함수로 각각 한 번 변환한다. 저장 내용은 바꾸지 않는다.
- 변환 결과는 한 줄의 유한한 실수 벡터여야 하며, 빈 값·NaN·무한값·저장 주소 폭 불일치는 즉시
  오류로 중단한다.
- `QuantumC`, 값 상태, `StableKeyProjector`, `VectorMemory`의 코사인 검색, 값 원형과 행동 판독은
  바꾸지 않는다.

## 실행 흐름

- `KEY-1` 결과·판정·두 주소 체크포인트와 `EPISODE-1` 값 원형 체크포인트의 SHA-256 파일 지문을
  먼저 확인한다.
- `KEY-1`과 같은 겹치지 않는 평가 2,048회차와 실제 엔진 seed를 사용한다. 새 학습은 없다.
- 원시 열쇠 상태 두 개를 `VectorMemory.store`에 넘기고 원시 질문 상태를 `retrieve(top_k=1)`에
  넘긴다. 공용 기억 내부에서만 얼린 주소 변환을 적용한다.
- 반환된 원래 값 상태를 `EPISODE-1` 값 원형으로 읽고 8개 행동 중 하나를 선택한다.
- 각 seed에서 예측, 선택 위치, 내용 읽기, 기억 API 일치, 주소 간격과 변환 호출 횟수를 기록한다.

## 고정 사양

- seed: `1337 / 7331`
- 평가 회차: seed별 2,048
- 주소 변환: `KEY-1`의 seed별 `StableKeyProjector.projection`, 출력 폭 32, 평가 중 얼림
- 기억: 기존 `VectorMemory(capacity=2)`, cosine top-1
- 값 상태·원형·단어·감각 단계·자료 분할: `EPISODE-1`과 동일
- 장치: CPU

모든 수치·seed·팔·문턱은 구현 단계의 `measurement/episode2_registry.py`를 단일 기준으로 고정한다.
그 파일의 `preregistration_commit`은 이 문서를 먼저 고정한 Git 커밋을 가리켜야 한다.

## 비교와 개입

1. `integrated_stable_normal`: 공용 기억 내부에서 얼린 안정 주소를 적용
2. `integrated_stable_partner_swap`: 저장 내용만 서로 맞바꿔 관계 원인을 차단
3. `integrated_stable_recovered`: 정상 연결을 새 기억에 다시 저장해 복구
4. `manual_stable_reference`: `KEY-1`처럼 바깥에서 주소를 미리 바꾼 기준 재생
5. `transform_disabled`: 같은 공용 기억에서 변환을 끈 `EPISODE-1` 원본 재생
6. `sensory_memory`: 직접 감각 주소를 쓰는 같은 기억 장치
7. `keyed_attention`: 얼린 표준 열쇠 검색
8. `no_memory`: 회차 기억 없음

## 무효 조건

- 사전등록 커밋 뒤 seed·회차·폭·학습량·팔·문턱을 결과에 맞춰 바꿈
- `KEY-1` 판정이 `K1`이 아니거나 결과·판정·주소/값 체크포인트 지문이 달라짐
- 새 학습이 일어나거나 얼린 주소 가중치가 평가 전후 달라짐
- 공용 기억의 변환 없음 동작이 기존 단위 검사 또는 `EPISODE-1` 재생과 달라짐
- 공용 내부 변환이 저장 두 번·검색 한 번 이외의 횟수로 호출되거나 저장 내용을 바꿈
- `manual_stable_reference`가 `KEY-1` 정상 팔과 한 회차라도 다름. 공용
  `integrated_stable_normal`만 이 기준과 다르면 무효가 아니라 아래 `E2I_MEMORY_INTEGRATION_LOSS`로
  판정한다.
- 직접 감각 기억·표준 열쇠 검색 90% 미만, 기억 없음 25% 초과
- 내용 맞바꾸기 25% 초과, 복구 예측이 정상과 하나라도 다름
- seed·팔·체크포인트·수치가 누락되거나 NaN·무한값이 있음

## 사전 판정

- `E2I_PATH_RECOVERED_NOT_UNIQUE`: 두 seed 모두 저장 위치 90% 이상, 최종 정확도 75% 이상,
  값별 최저 재현율 60% 이상이고 공용 흐름·기준 재생·개입·복구 통제가 모두 통과
- `E2I_MEMORY_INTEGRATION_LOSS`: `KEY-1` 기준 재생은 통과하지만 공용 내부 변환의 저장 위치가
  한 seed 이상 90% 미만이거나 기준 예측과 다름
- `E2I_BEHAVIOR_LOSS`: 저장 위치는 두 seed 모두 통과하지만 최종 정확도 또는 값별 재현율이 미달
- `E2I0_INVALID`: 원본·파일 지문·얼림·기본 호환·비교·개입·복구·호출 횟수 조건 중 하나라도 무효

판정 우선순위는 `E2I0 → E2I_MEMORY → E2I_PATH → E2I_BEHAVIOR`다. `E2I_PATH`면 안정 주소를
선택형 공용 기능으로 유지하고, 다음에는 닮은 사건끼리 섞이는지 보는 `SEPARATION-1`을 별도
사전등록한다. `E2I_MEMORY`면 새 구조를 추가하지 않고 공용 변환의 입력 모양과 적용 횟수만 추적한다.
`E2I_BEHAVIOR`면 주소 뒤 값 상태→행동 구간의 첫 손실만 분해한다.

## 판정과 다음 단계

판정은 `E2I_PATH_RECOVERED_NOT_UNIQUE`다. 안정 주소는 실험기 바깥의 임시 처리에 머물지 않고,
원시 내부 상태를 받는 공용 저장·검색 호출부에서도 같은 관계 기억과 행동을 보존했다. 변환 결과가
빈 값이거나 한 줄이 아니거나 유한하지 않거나 저장 주소 폭과 다르면 즉시 중단하도록 했다. 변환을
지정하지 않은 기존 호출은 그대로 유지한다.

이 결과는 일반 직접 기억과 표준 열쇠 검색보다 고유하지 않고 의식 증거도 아니다. 다음은 주소를
더 바꾸는 것이 아니라, 안정 주소를 가진 닮은 사건들이 서로 섞이지 않는지 검사하는
`SEPARATION-1`이다.
