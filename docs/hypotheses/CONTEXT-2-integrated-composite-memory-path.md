# CONTEXT-2 — 합성 주소의 공용 기억 경로 연결

상태: 사전등록  
등록일: 2026-08-11  
선행 결과: `CONTEXT-1=CX1_CONTEXT_KEY_VALID_NOT_UNIQUE`

## 질문

`CONTEXT-1`에서 검증한 상황+열쇠 합성 주소를 장치 밖에서 미리 계산하지 않고, 원시 상황 상태와
원시 열쇠 상태를 기존 공용 기억의 `store/retrieve`에 넘겨도 같은 사건을 찾고 같은 행동을 하는가?

현재 `VectorMemory`는 선택형 `key_transform`이 있어도 입력을 단일 텐서로 제한한다. 이 때문에
상황 상태와 열쇠 상태를 함께 받는 검증된 주소 변환을 공용 호출부에서 사용할 수 없다. 이번에는
기억 검색, 값 상태, 주소 가중치나 감각 흐름을 바꾸지 않고 이 입력 경계만 최소 확장한다.

## 고정 흐름

- `CONTEXT-1`의 평가 자료, 네 평가 조합, 감각 순서, 자체 갱신 8회, 값 원형을 그대로 쓴다.
- `CONTEXT-1`에서 저장한 폭 32 상황 변환과 `CANONICAL-2` 폭 32 열쇠 변환을 다시 맞추지 않고
  체크포인트에서 얼려 읽는다.
- `VectorMemory.store((상황 상태, 열쇠 상태), 값 상태)`와
  `retrieve((질문 상황 상태, 질문 열쇠 상태), top_k=1)`를 공용 호출로 사용한다.
- 선택형 변환은 두 원시 상태를 각각 기존 변환에 한 번 통과시킨 뒤 같은 비중으로 이어 붙인다.
- 변환을 지정하지 않은 기존 `VectorMemory`의 단일 텐서 저장·검색 동작은 바꾸지 않는다.
- 각 원시 상태는 텐서 2개, 특징 폭 96, 셀 수 2~48, 유한값이어야 한다. 입력 목록이나 튜플은
  변환이 있을 때만 허용하며 빈 입력, 텐서가 아닌 항목, 폭·유한값 오류는 즉시 거부한다.
- 평가 중 학습, 주소 다시 맞춤, 결과를 본 뒤 문턱 조정은 하지 않는다. 장치는 CPU다.

## 비교 조건

1. 공용 `VectorMemory` 안에서 합성 주소를 계산하는 정상 조건
2. 장치 밖에서 같은 주소를 계산한 `CONTEXT-1` 기준
3. 공용 변환의 상황 부분만 가린 조건
4. 정확한 `상황+열쇠` 주소 양성 비교
5. 정확 주소의 저장 내용을 한 칸 돌린 가짜 비교
6. 정상 내용을 새 공용 기억에 다시 저장한 복구 비교

모든 조건에서 저장 위치 선택, 최종 행동, 값별 재현율, 저장 내용 판독, 기억 API와 직접 cosine
선택의 일치, 주소 여유를 기록한다. 정상 공용 경로에는 회차마다 저장 4회와 검색 1회가 있어야 하며,
각 호출에서 변환은 정확히 한 번만 실행되어야 한다.

## 유효 조건과 문턱

- 선행 `CONTEXT-1` 결과·판정·상황 체크포인트와 두 열쇠·값 원형 체크포인트의 SHA-256 지문 일치
- 평가 자료와 네 평가 조합이 선행 실험과 완전 일치
- 정상 공용 경로: 선택·최종 행동 각각 90% 이상, 값별 최저 재현율 75% 이상, 내용 판독 90% 이상
- 장치 밖 기준과 정상 공용 경로: 예측·선택 100% 일치
- 상황 부분 차단: 최종 행동 35% 이하
- 정확 주소: 선택 99%, 최종 행동 90%, 값별 최저 재현율 75% 이상
- 내용 한 칸 돌리기: 최종 행동 5% 이하
- 복구 예측과 정상 공용 경로 예측: 100% 일치
- 기억 API와 직접 cosine 선택: 100% 일치
- 호출마다 두 입력 항목, 저장 4회·검색 1회, 변환 5회, 주소 폭 64
- 상황·열쇠 변환은 평가 전후 모두 얼린 상태이고 가중치가 완전히 같음

원본 지문, 입력 모양, 호출 횟수, 주소 폭, 자료 균형, 네 조합, 양성·가짜·복구 조건, 필수 수치 중
하나라도 어긋나면 무효다.

## 사전 판정

- `CX2I_PATH_RECOVERED_NOT_UNIQUE`: 네 조합의 정상 공용 경로와 모든 통제가 통과
- `CX2I_MEMORY_PATH_LOSS`: 장치 밖 기준은 통과하지만 공용 경로 선택이 하나 이상 실패하거나 기준과 불일치
- `CX2I_VALUE_READOUT_LOSS`: 공용 경로 선택은 통과하지만 값 판독이나 최종 행동이 하나 이상 실패
- `CX2I0_INVALID`: 선행 자료·입력·실행·양성·가짜·복구 조건 중 하나라도 실패

판정 우선순위는 `CX2I0 → CX2I_MEMORY_PATH_LOSS → CX2I_VALUE_READOUT_LOSS → CX2I_PATH_RECOVERED_NOT_UNIQUE`다.
통과하면 다음 실험은 상황 하나나 열쇠 하나만으로 풀 수 없고 두 부분의 쌍이 모두 필요한
`CONJUNCTION-1`이다. 실패하면 공용 기억의 첫 불일치 지점만 고친다. 어떤 판정도 의식 증거가 아니다.
