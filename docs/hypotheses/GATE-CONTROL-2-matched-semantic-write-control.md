# GATE-CONTROL-2 — 저장량 일치 의미 선택 양성 비교

상태: 완료 · `GCM1_MATCHED_SEMANTIC_CONTROL_VALID`

## 질문

`GATE-CONTROL-1`의 정상 의미 선택은 두 독립 자료에서 중요 사실과 후속 질문을 모두 100% 보존했다.
그러나 표찰을 뒤섞은 선택기는 회차별 저장량을 통제하지 않아 한 자료에서 거의 모든 문장을 저장했고,
전체 저장과 같은 방식으로 후속 질문을 맞혔다. 정상 선택과 가짜 선택의 저장량을 정확히 같게 만들면
고정 문장 의미 표현의 장기 기억 선택 효과가 성립하는가?

이 검사는 일반 문장 의미 표현의 양성 비교다. Anima 고유 기능이나 의식을 검사하지 않는다.

## 고정 사양

- `GATE-CONTROL-1`의 `build_calibration()`과 `build_evaluation()`을 변경 없이 재사용한다.
- seed `1337`, `7331`, 보정 4,096문장, 평가 1,024회차, 회차당 후보 8개를 유지한다.
- 의미 표현은 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` revision
  `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`를 CPU에서 사용한다.
- 최대 128토큰, attention mask 평균, L2 정규화, 384차원 문장 표현과 역할 2차원을 유지한다.
- `canonical_ridge`, ridge `0.001`, Python 3.13, `torch==2.8.0`,
  `transformers==4.55.4`를 유지한다.
- 정상 선택기의 점수·문턱과 표찰 뒤섞기 선택기의 점수를 평가 전에 고정한다.
- 실제 대화 저장 호출과 기본값은 변경하지 않는다.

## 유일한 변경과 비교 조건

정상 의미 선택은 기존 문턱을 그대로 사용한다. 저장량 일치 가짜는 표찰을 뒤섞어 맞춘 선택기의
문장별 점수를 내림차순으로 정렬하되, 각 회차에서 정상 선택이 저장한 개수만큼만 고른다. 점수가
같으면 회차 안 원래 문장 위치가 앞선 것을 먼저 고른다. 따라서 다음이 모두 같아야 한다.

- 회차별 정상 선택과 저장량 일치 가짜의 저장 개수
- 전체 정상 선택과 저장량 일치 가짜의 저장 개수
- 정상 선택과 기존 같은 저장량 무작위의 회차별 저장 개수

비교 조건은 정상 의미 선택, 전체 저장, 정답 선택, 같은 저장량 무작위, 저장량 일치 가짜, 기억 없음의
여섯 가지다. 상위 3개 검색, 자료 감사, 모델 revision, 특징 폭, 유한값, 체크포인트 지문을 닫힌
판정기로 확인한다.

## 사전 판정

양성·정보 없음 비교가 유효하고 두 seed 모두 다음을 만족해야 한다.

- 정상 의미 선택의 중요 사실 저장률과 후속 질문 정답률 90% 이상
- 정상 의미 선택의 방해 문장 저장률 25% 이하
- 정상 의미 선택의 검색 목록이 전체 저장의 50% 이하
- 전체 저장보다 후속 질문 정답률이 2%p 넘게 낮지 않음
- 같은 저장량 무작위보다 후속 질문 정답률이 25%p 이상 높음
- 저장량 일치 가짜보다 후속 질문 정답률이 25%p 이상 높음
- 정답 선택과 전체 저장의 후속 질문 정답률 95% 이상, 기억 없음 5% 이하

판정은 다음과 같다.

- `GCM1_MATCHED_SEMANTIC_CONTROL_VALID`: 저장량 통제가 유효하고 두 seed의 정상 선택이 모두 통과
- `GCM2_MATCHED_SEMANTIC_CONTROL_LOSS`: 통제는 유효하지만 정상 선택 또는 가짜 차이 기준 미달
- `GCM0_INVALID`: 자료·환경·모델·저장량·양성·정보 없음·지문·결정성 중 하나라도 무효

`GCM1`이면 `GATE-1`의 첫 원인이 글자 모양 표현이었음을 양성 비교 수준에서 확정한다. 다음 단계는
실제 대화의 더 다양한 표현과 주제 이동을 분리한 `GATE-2`다. 이번 결과만으로 공용 대화 저장 방식을
바꾸지 않는다. `GCM2`이면 자동 중요도 선택을 보류하고 사용자의 명시적 저장과 후속 사용 뒤 승격을
비교한다. 결과를 보기 전에 README와 이 문서를 GitHub `main`에 먼저 고정한다.

## 실행 결과

사전등록은 GitHub `main`의 `9c7dda4a6`에 고정했다. 등록한 Python 3.13.13, PyTorch 2.8.0,
Transformers 4.55.4 CPU 환경에서 두 자료를 실행했다. 정상과 저장량 일치 가짜의 회차별 저장 개수는
1,024회차 모두 같았고 전체 저장 수도 각각 `1,067 / 2,633`으로 일치했다. 같은 저장량 무작위도
같은 회차별 개수를 사용했다.

| 조건 | seed 1337 후속 질문 | seed 7331 후속 질문 | 검색 목록 비율 |
|---|---:|---:|---:|
| 정상 의미 선택 | 100% | 100% | 13.02% / 32.14% |
| 전체 저장 | 99.90% | 100% | 100% |
| 정답 선택 | 100% | 100% | 12.50% |
| 같은 저장량 무작위 | 13.18% | 34.57% | 13.02% / 32.14% |
| 저장량 일치 가짜 | 0.49% | 0% | 13.02% / 32.14% |
| 기억 없음 | 0% | 0% | 0% |

정상 선택의 중요 사실 저장률은 두 자료 모두 100%, 방해 문장 저장률은 `0.60% / 22.45%`였다.
저장량 일치 가짜의 중요 사실 저장률은 `0.49% / 0%`였다. 정상 선택은 두 가짜 비교보다 후속 질문을
각각 25%p 넘게 잘 맞혔고, 정상 선택·검색 크기·전체 저장·정답 선택·기억 없음 기준도 모두 통과했다.

## 판정과 범위

사전 판정은 `GCM1_MATCHED_SEMANTIC_CONTROL_VALID`다. `GATE-CONTROL-1`을 무효로 만든 저장량
통제 결함을 고친 뒤에도 정상 의미 선택의 결과가 유지됐으므로, 고정 표준 문장 의미 표현은 이 통제
자료에서 장기 기억에 넣을 사실을 단순 저장량 효과와 구분해 골랐다. 이는 일반 문장 의미 분류의
양성 비교이며 Anima 고유 기능, 주관적 이해 또는 의식의 증거가 아니다. 문장 틀이 통제돼 있어 실제
대화의 다양한 말투와 주제 이동에도 그대로 성립한다고 아직 말할 수 없다. 실제 대화 저장 호출과
기본값은 변경하지 않았다. 다음은 더 다양한 대화 표현에서 중요한 사실을 고르는 `GATE-2`다.

체크포인트 디렉토리 이름을 제외한 결과와 판정이 완전히 같았고 네 체크포인트 지문도 같았다. HF 조직
