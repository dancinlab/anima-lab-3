# GATE-RETRIEVAL-CONTROL-2 — 주제 주소·내용 분리 검색 양성 비교

상태: 사전등록 · 실행 전
등록일: 2026-08-12

## 질문과 범위

`GATE-RETRIEVAL-CONTROL-1`은 질문과 후보의 전체 문장 의미 표현을 곧바로 비교했지만 정답 사실을
다른 회차 질문과 구분하지 못했다. 이번 검사는 기존 공용 기억의 열쇠·내용 분리 원칙을 재사용해,
회차 주제로 후보를 먼저 찾고 그 안에서 문장 중요도 점수로 사실을 읽으면 표준 양성 검색 경로가
성립하는지만 묻는다.

이는 자료 생성기가 알고 있는 주제 표찰을 사용하는 검색 통제 실험이다. 실제 대화에서 주제를
추출하는 능력, Anima 고유 기능, 주관적 이해 또는 의식을 검사하지 않는다. 실제 사용자 대화와 공용
기억 기본값도 변경하지 않는다.

## 고정 자료와 검색 흐름

- `GATE-2`와 같은 seed `1337`, `7331`, 평가 1,024회차와 회차당 후보 8개를 그대로 사용한다.
- 사실 종류, 위치 `1·3·5·7`, 회차당 주제 이동 3회, 문장 틀과 임시 식별 문자열을 바꾸지 않는다.
- 후보의 주제 주소는 자료 생성 시 이미 정해진 `핵심주제` 또는 `보조주제` 표찰에서 결정형 글자
  3개 묶음 벡터로 만든다. 질문 주소는 해당 회차의 `핵심주제` 표찰로 만든다.
- 주소 유사도 상위 2개 후보만 읽기 목록에 둔다. 같은 주소 점수에서는 후보 위치가 빠른 순서로
  고정한다.
- 내용 점수는 `GATE-2`에서 등록한 고정 다국어 문장 의미 표현과 결정형 ridge 분류 방식으로
  보정 자료에서 다시 계산한다. 결과를 보기 전에 고정한 seed별 보정 자료만 사용한다.
- 최종 순위는 주소로 고른 두 후보 안에서 내용 점수가 높은 순서이며, 동점은 후보 위치 순서다.
- Python 3.13, `torch==2.8.0`, `transformers==4.55.4`, CPU와 고정 모델 revision을 유지한다.

## 고정 비교

- `split_topic_content`: 정상 주제 주소로 후보 2개를 찾고 정상 내용 점수로 순위화
- `topic_only`: 같은 후보 2개를 주소 점수와 위치만으로 순위화
- `content_only`: 주소 분리 없이 `GATE-RETRIEVAL-CONTROL-1`의 전체 문장 의미 검색
- `shuffled_topic`: 질문 주제 주소를 다음 회차 주소와 맞바꾼 가짜 비교
- `shuffled_content`: 정상 주소 후보 안에서 내용 점수를 다음 회차와 맞바꾼 가짜 비교
- `oracle_memory`: 정답 사실만 남긴 양성 비교
- `no_memory`: 검색 후보가 없는 정보 없음 비교

각 조건은 상위 1개와 상위 3개 정답률, 사실 종류별·위치별 정답률, 정답 순위와 결과 지문을
기록한다. 자료·모델·환경·지문·유한값·결정성이 다르면 닫힌 판정기가 무효 처리한다.

## 사전 판정

두 seed 모두 다음 조건을 만족해야 한다.

- 정상 분리 검색 상위 3개 정답률 95% 이상
- 정상 분리 검색 상위 1개 정답률 90% 이상
- 사실 네 종류와 위치 네 곳의 상위 1개 정답률 각각 85% 이상
- 정답 사실만 남긴 비교 상위 3개 99% 이상, 기억 없음 5% 이하
- 주제 맞바꾸기 상위 3개 35% 이하
- 내용 맞바꾸기 상위 1개 60% 이하
- 정상 분리 검색이 내용 맞바꾸기보다 상위 1개 정답률 30%p 이상 높음
- `topic_only` 상위 1개 10% 이하이면서 상위 3개 95% 이상

판정은 다음과 같다.

- `GRC2A_SPLIT_RETRIEVAL_VALID`: 모든 통제와 두 seed의 전체·종류·위치 기준 통과
- `GRC2B_CONTENT_RANKING_LOSS`: 주소·양성 통제는 유효하지만 정상 내용 순위 기준 미달
- `GRC2C_TOPIC_ADDRESS_LOSS`: 정상 주소의 상위 3개 또는 주제 맞바꾸기 통제 실패
- `GRC2_0_INVALID`: 자료·모델·환경·지문·결정성·양성·정보 없음 비교 중 하나라도 무효

`GRC2A`여도 실제 대화 기본값은 바꾸지 않는다. 다음에는 같은 검색 경로 위에서 `GATE-2`의 저장
선택 결과를 별도 사전등록해 다시 판정한다. 다른 판정이면 결과를 보고 후보 수, 문장, 모델, 학습량
또는 기준을 조정하지 않고 처음 실패한 주소 또는 내용 단계만 후속 검사한다.

결과를 보기 전에 README와 이 문서를 GitHub `main`에 먼저 고정하고 그 커밋을 실행 사양의
`preregistration_commit`으로 사용한다.
