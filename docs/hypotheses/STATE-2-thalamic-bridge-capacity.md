# STATE-2 — 연결 다리의 폭이 감각 정보 손실의 원인인가

## 사전등록

STATE-1에서 감각 정보는 `QuantumC` 위상과 전체 상태에 32단계까지 남았지만, 공용
`ThalamicBridge`가 셀별 96차원 상태를 8차원으로 바꾼 뒤 약해졌다. 첫 개선은 엔진·감각 입력·셀
평균·최종 게이트를 그대로 두고 연결 다리의 중간 폭만 비교한다. 조건의 단일 원장은
`measurement/bridge_capacity_registry.py`다.

중간 폭 `8, 16, 32, 48, 96`을 STATE-1과 같은 네 상황, 방해 단어, 48셀, 감각 3단계, 지연
`0, 1, 2, 4, 8, 16, 32`, 독립 seed `1337, 7331`에서 비교한다. 각 폭은 같은 seed로 초기화하며
8차원 조건은 STATE-1 기준 조건을 재현해야 한다. 직접 감각은 90%, 위상·전체 상태와 다리의 셀별
코드·평균 코드·최종 게이트는 75% 이상이어야 한다. 정답을 32번 뒤섞은 가짜 검사의 평균은 40%
이하여야 한다. 두 seed와 모든 지연을 통과한 최소 폭만 후보로 인정한다.

- `C0_INVALID`: 조건·두 seed·폭·지연·채널이 빠졌거나 직접 감각·위상·전체 상태 비교군이 실패
- `C1_NO_WIDTH_RECOVERY`: 어느 폭에서도 셀별 다리 코드가 전 구간을 통과하지 못함
- `C2_TRANSFORM_RECOVERED_POOLING_LOSS`: 폭 확대로 셀별 코드는 회복하지만 평균 뒤에는 실패
- `C3_GATE_TRANSFORM_LOSS`: 평균까지 통과하지만 최종 게이트에서 실패
- `C4_FULL_PATH_RECOVERY`: 최종 게이트까지 통과하는 최소 폭을 찾음

`C4`일 때만 공용 연결 다리의 기본 폭을 바꾸고 행동 인과 검사를 처음부터 다시 실행한다. `C2`면
폭 확대를 배포하지 않고, 기존 주석에 설계된 학습 가능한 셀 선택을 평균과 같은 초기값에서 별도
사전등록한다. 이 실험은 읽을 수 있는 정보량을 비교할 뿐 의식이나 행동 원인성을 판정하지 않는다.
