# ADDRESS-CENTER-2 — 상황 범주 중심의 공용 기억 경로 연결

상태: 사전등록
등록일: 2026-08-11
선행 결과: `ADDRESS-MARGIN-1=AM1_WITHIN_CLASS_MARGIN_LOSS`

## 질문과 고정 가설

`ADDRESS-MARGIN-1`은 상황·열쇠 범주를 99%대로 읽으면서도 연속 합성 주소의 기억 선택은
`80.96~82.03%`에 머무는 문제를 확인했다. 상황 성분만 예측 범주의 고정 중심으로 바꾸면
`93.85~94.34%`로 회복해 두 성분을 모두 바꾸는 것보다 조금 높았다.

이번 실험은 이 최소 수정을 외부 계산이 아닌 공용 `CompositeStateTransform → VectorMemory`
호출에 연결했을 때 같은 회복이 유지되는지 검사한다. 상황 범주 중심은 표준 분류·검색에서도
사용할 수 있는 대표 주소이며, Anima 고유 기능으로 가정하지 않는다.

## 고정 구현과 설계

- `ADDRESS-MARGIN-1` 결과·판정과 재사용하는 상황·열쇠·값 변환의 파일 지문을 먼저 확인한다.
- 기존 `CompositeStateTransform`에 기본값이 꺼진 `center_context` 선택 기능 하나만 추가한다.
- 기능을 켜면 얼린 상황 변환이 예측한 범주의 정규화된 원형을 상황 주소로 사용한다.
- 열쇠는 기존 연속 주소를 유지한다. 두 성분의 폭 32, 합성 폭 64와 같은 가중치는 바꾸지 않는다.
- 상황은 6회, 열쇠·값은 3회 처리하며 자료 1,024회차와 네 원형/엔진 시작값 조합을 유지한다.
- 값은 기존 `VALUE-2` 변환을 거치고 기억 저장·검색은 공용 `VectorMemory.store/retrieve`만 쓴다.
- 변환을 다시 맞추거나 새 층·학습·처리 횟수·거리 함수를 추가하지 않는다.

평가 조건은 다음으로 고정한다.

- `integrated_context_center`: 공용 변환에서 상황 중심 기능을 켠 정상 조건
- `integrated_center_disabled`: 같은 공용 변환에서 기능을 끈 원인 차단 조건
- `integrated_context_masked`: 상황 성분 전체를 가린 필수 정보 비교
- `integrated_context_center_recovered`: 차단 뒤 다시 켠 복구 조건
- `exact_context_key_control`: 실제 범주의 정확 주소를 직접 준 양성 비교
- `exact_context_key_partner_swap`: 저장 내용만 한 칸 바꾼 가짜 비교

정상 조건은 `ADDRESS-MARGIN-1`의 `context_centered` 조건과 사건별 예측·선택이 100% 같아야 한다.
차단 조건은 같은 선행 실험의 `continuous_frozen` 조건과 100% 같아야 하며, 복구 조건은 정상과
완전히 같아야 한다. 기존 기본 호출의 출력은 수정 전과 같아야 한다.

## 유효성 및 판정

모든 원본 지문, 자료 구성, 상태 모양, 처리 호출 수, 공용 변환 호출 수와 주소 폭이 등록값과
맞아야 한다. 상황·열쇠·값 변환은 실행 전후 바뀌지 않아야 한다. 정확 주소 비교는 기억 선택
99% 이상, 행동 90% 이상, 값별 최저 맞힘률 75% 이상이어야 한다. 상황 차단은 선택·행동 35%
이하, 내용 맞바꾸기는 행동 5% 이하여야 한다.

네 평가 조합 모두에서 다음을 만족해야 정상 통합으로 본다.

- 상황 중심 정상·복구의 기억 선택과 최종 행동 각각 90% 이상
- 값별 최저 맞힘률 75% 이상
- 기능 차단의 기억 선택 85% 이하
- 정상과 차단의 기억 선택 차이 8%p 이상
- 공용 기억 API가 고른 위치와 직접 코사인 계산이 고른 위치 100% 일치

판정은 다음 순서를 따른다.

- `AC1_CONTEXT_CENTER_INTEGRATED_NOT_UNIQUE`: 정상·복구·인과 차이와 모든 통제가 통과한다.
- `AC2_INTEGRATED_CENTER_PATH_LOSS`: 선행 중심 비교는 유효하지만 공용 정상 경로가 90%를 못 넘는다.
- `AC3_CENTER_NOT_CAUSAL`: 정상 성능은 통과하지만 차단 손실이나 최소 8%p 차이가 재현되지 않는다.
- `AC0_INVALID`: 원본·자료·호출·모양·고정 변환·선행 결과 일치·양성 또는 가짜 비교가 어긋난다.

`AC1`이면 이 기능은 상황이 포함된 합성 기억 주소에서만 선택해 사용할 수 있는 검증된 공용
기능으로 보존한다. 일반 단일 열쇠 기억과 기존 체크포인트·호출에는 적용하지 않는다. `AC2`면
외부 비교와 공용 호출의 첫 차이를 추적하고, `AC3`이면 기능을 기본 활성화하지 않는다.

성공해도 일반 기억 검색의 주소 안정성을 고친다는 뜻이며, Anima·해마·의식에 고유한 증거가
아니다.

결과를 보기 전 이 문서와 README를 커밋하고, 그 커밋을 실행 사양의
`preregistration_commit`으로 고정한다.
