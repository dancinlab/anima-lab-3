# GATE-3 — 의미 기반 대화 기억 저장·검색 통합

상태: 사전등록
등록일: 2026-08-12

## 질문과 범위

`GATE-2`는 다양한 말투와 세 번의 주제 이동에서 장기 보관할 문장을 고르는 단계와 오래된 글자
검색을 한꺼번에 검사했다. 한 자료에서는 모든 문장을 저장해도 검색이 양성 기준을 넘지 못해, 저장
선택 자체를 판단할 수 없었다. 이후 `GATE-RETRIEVAL-CONTROL-3·4`는 사실 위치와 회차 주소 누출을
없애고, 회차·주제 주소가 고른 후보 안에서 문장 내용 점수가 올바른 기억을 고르는 실제 원인임을
확인했다.

이번 실험은 새 모델이나 새 자료를 만들지 않는다. `GATE-2`의 의미 기반 저장 선택과 검증된 분리
검색을 한 공용 흐름으로 연결해, 다양한 표현에서 필요한 사실만 남기고 나중에 다시 찾는지 묻는다.
저장되지 않은 원문을 삭제하지 않으며, 실제 사용자 대화의 보관·검색 기본값도 결과 전에 바꾸지
않는다.

이는 일반 대화 기억 기능 검사다. Anima 고유 기능, 주관적 이해 또는 의식을 검사하지 않는다.

## 고정 자료와 흐름

- seed `1337`, `7331`, 평가 1,024회차, 회차당 후보 8개, 보정 문장 4,096개를 사용한다.
- 사실은 선호·약속·목표·사용자 정보 네 종류이며, 인사·추임새·일시 선호·미확정 계획 등 방해 문장
  일곱 종류와 섞는다. 보정과 평가는 문장 틀·이름·값이 겹치지 않는다.
- 사실 위치는 `GATE-RETRIEVAL-CONTROL-3`처럼 0~7번에 정확히 균형 배치한다.
- 저장 선택은 `GATE-2`와 같은 고정 다국어 문장 의미 모델 revision, 결정형 ridge 맞춤, 같은
  문턱을 사용한다. 가짜 선택은 회차별 저장 개수를 정상 선택과 같게 맞춘다.
- 검색은 64차원 회차·주제 주소로 저장된 후보 중 같은 주제 후보를 최대 두 개 찾고, 후보에 붙은
  의미 중요도 점수로 순위를 정한다. 동점이면 후보 위치가 앞선 문장을 먼저 고른다.
- 저장되지 않은 후보는 검색 순위에 들어갈 수 없다. 저장 후보가 없으면 빈 결과를 반환한다.
- Python 3.13, `torch==2.8.0`, `transformers==4.55.4`, CPU와 고정 모델 revision을 유지한다.

## 고정 비교와 감사

- `semantic_integrated`: 정상 의미 선택 뒤 분리 검색
- `store_all_integrated`: 모든 문장을 저장한 검색 양성 비교
- `oracle_integrated`: 정답 사실만 저장한 양성 비교
- `matched_random_integrated`: 정상과 회차별 저장량이 같은 무작위 선택
- `matched_shuffled_integrated`: 뒤섞은 표찰로 맞춘 점수 중 정상과 회차별 저장량이 같은 선택
- `no_memory`: 아무 문장도 저장하지 않은 정보 없음 비교

각 조건은 사실 저장률, 방해 저장률, 전체 대비 검색 목록 크기, 상위 1개·3개 정답률, 저장된 사실의
조건부 검색 성공률, 사실 종류별·8개 위치별 정답률을 기록한다. 자료 균형, 보정·평가 비중복, 모델
revision, 선택 체크포인트, 선택 지문, 회차별 저장량 일치, 검색 순위가 저장 후보의 부분집합인지,
결정성을 함께 감사한다.

## 사전 판정

먼저 두 seed 모두 다음 양성·가짜 조건을 만족해야 한다.

- 모든 문장 저장 상위 1개 90% 이상, 상위 3개 95% 이상
- 정답 사실만 저장 상위 1개·3개 99% 이상
- 기억 없음 상위 1개·3개 5% 이하
- 정상과 무작위·가짜 선택의 회차별 저장 개수가 정확히 같음
- 정상 상위 1개가 두 가짜 조건보다 각각 25%p 이상 높음
- 모든 검색 순위가 실제 저장된 후보만 포함하고, 저장 후보가 없는 회차는 빈 결과임

양성·가짜 조건이 유효할 때 두 seed 모두 아래를 만족하면 통합 성공이다.

- 사실 저장률 90% 이상
- 방해 문장 저장률 25% 이하, 각 방해 종류 50% 이하
- 검색 목록 크기가 전체 문장의 50% 이하
- 최종 상위 1개와 3개 정답률 90% 이상
- 사실이 저장된 회차의 상위 1개 정답률 95% 이상
- 사실 네 종류와 8개 위치별 상위 1개가 각각 85% 이상
- 모든 문장 저장과 비교한 상위 1개 하락이 5%p 이하

판정은 다음과 같다.

- `G3A_INTEGRATED_DIALOGUE_MEMORY_VALID_NOT_UNIQUE`: 두 seed 모두 통합 기준 통과
- `G3B_WRITE_SELECTION_LOSS`: 검색 양성·가짜·조건부 검색은 유효하지만 사실 저장 또는 종류·위치
  기준 실패
- `G3C_RETRIEVAL_LOSS`: 사실 저장 기준은 통과했지만 조건부 검색 또는 최종 검색 기준 실패
- `G3_0_INVALID`: 자료·모델·환경·지문·저장량 일치·결정성·양성·가짜·정보 없음 감사 중 하나라도 실패

`G3A`여도 일반 문장 의미 분류와 검색의 성공일 뿐 의식 증거가 아니다. 그때만 별도 배포 검사에서
원본 보관을 유지한 채 장기 검색 목록에 선택 기능을 켤지 판단한다. `G3B`면 검색은 고정하고 말투별
저장 실패를 분해한다. `G3C`면 저장 선택은 고정하고 검색에서 처음 실패한 공용 단계를 조사한다.
결과를 본 뒤 모델·문장·후보 수·주소 차원·문턱을 조정하지 않는다.

결과를 보기 전에 README와 이 문서를 GitHub `main`에 먼저 고정하고 그 커밋을 실행 사양의
`preregistration_commit`으로 사용한다.
