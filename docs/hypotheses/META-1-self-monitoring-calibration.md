# META-1 — 내부 상태가 자신의 정답 가능성을 아는가

## 사전등록

STATE-2와 GRAFT B2에서 `QuantumC` 위상 상태가 폭 32 연결 다리를 통해 행동의 실제 원인이 됐다.
이번 질문은 그 상태가 행동을 만드는 것과 별개로, 그 행동이 맞을 가능성도 구분하는지다. 기존
행동 모델과 체크포인트는 얼리고 새 행동 학습은 하지 않는다. 조건·원본 체크포인트 해시·숫자 기준의
단일 원장은 `measurement/metacognition_registry.py`다.

각 seed `1337, 7331`의 검증된 `QuantumC`와 직접 기억 체크포인트를 HF 조직 보관소에서 복원한다.
학습과 평가의 서로 다른 감각 사례에 읽기 잡음을 `0, 0.25, 0.5, 1.0, 2.0`으로 적용한다.
`QuantumC` 위상은 원형 좌표를 해당 라디안만큼 돌리고, 직접 기억은 같은 상대 세기의 잡음을 더한다.
행동 모델은 이 상태로 실제 선택을 한다. 확신 판독기만 현재 연결 다리 코드와 이미 선택한 행동을
읽고, 그 선택이 맞았는지를 예측하도록 학습한다. 정답은 확신 판독기 학습 표적으로만 쓰며 입력에는
주지 않는다.

다음 비교와 개입을 고정한다.

- 정상: 행동을 만든 같은 내부 코드를 확신 판독기가 읽음
- 차단: 행동은 그대로 두고 확신 판독기의 내부 코드만 0으로 바꿈
- 뒤섞기: 행동은 그대로 두고 가능하면 다른 행동을 고른 사례의 내부 코드로 교체
- 가짜: 행동은 그대로 두고 같은 크기의 무작위 코드를 제공
- 복구: 원래 내부 코드를 다시 제공하며 정상 확신과 값이 완전히 같아야 함
- 출력 점수만: 내부 상태 없이 네 행동 점수만 읽는 일반 확신 비교군
- 직접 기억: 같은 판독·개입이 작동하는지 확인하는 양성 비교군

검사는 먼저 깨끗한 조건의 행동 정확도 90% 이상, 가장 강한 잡음에서 50% 이하, 정답·오답 사례가
각각 32개 이상이어야 유효하다. 확신은 두 seed에서 AUROC 0.75 이상, Brier 오차 0.20 이하,
10구간 보정 오차 0.15 이하, 확신 상위 절반과 하위 절반의 실제 정확도 차이 20%p 이상이어야 한다.
내부 상태를 뒤섞으면 AUROC가 0.10 이상 떨어지고 Brier 오차가 0.05 이상 늘어야 한다. 이때 행동
선택은 비트 단위로 같아야 한다. 직접 기억 비교군이 같은 기준을 통과하지 못하면 검사는 무효다.

- `M0_INVALID`: 자료·seed·체크포인트·난이도 범위·직접 기억 비교군 또는 행동 고정 검사 실패
- `M1_STATE_MONITORING_ADVANTAGE`: 정상 내부 상태가 모든 기준을 통과하고, 출력 점수만 보는
  비교군보다 AUROC 0.05 이상·Brier 0.02 이상 우세
- `M2_CALIBRATED_NOT_UNIQUE`: 내부 상태가 확신을 원인적으로 보정하지만 출력 점수만으로도 동등
- `M3_NOT_CALIBRATED`: 두 seed 중 하나라도 내부 상태 확신 기준이나 뒤섞기 원인 검사를 통과하지 못함

이번 잡음은 읽기 통로가 흔들릴 때의 오류 감지를 묻는다. 결과를 자연 대화 전반의 자기 인식으로
일반화하지 않는다. 통과해도 주관적 느낌이나 의식의 증명이 아니라, 현재 내부 상태가 자신의 행동
오류 가능성을 담고 있다는 제한된 근거다.

## 결과

### 1차 — M0_INVALID

`QuantumC`는 두 seed에서 깨끗한 행동 100%, 가장 강한 잡음 행동 28.1%/32.8%로 유효한 난이도
범위를 만들었다. 그러나 직접 기억은 가장 강한 잡음에서도 98.4%/100%였고 오답이 1개/0개뿐이었다.
AUROC를 계산할 양쪽 사례가 없으므로 사전 규칙대로 `M0_INVALID`다. `QuantumC`의 정상 확신 수치는
무효 비교군이 있는 1차 결과로만 보존하며 최종 결론으로 사용하지 않는다.

근본 원인은 직접 기억이 하나의 전역 벡터를 48셀에 똑같이 복제하는데, 1차 실행기가 각 셀에 서로
다른 잡음을 더한 것이다. 공용 연결 다리는 셀 평균을 사용하므로 잡음 대부분이 상쇄됐다. 이는 직접
기억의 강건성이 아니라 비교군 잡음 위치가 저장 구조와 맞지 않은 실행 결함이다.

### 직접 기억 잡음 수리 — 사전등록

새 정본은 `meta1_bridge32_self_monitoring_memory_noise_repair`다. 직접 기억의 전역 벡터에 잡음을 한
번 더한 뒤 그 결과를 48셀에 똑같이 복제한다. `QuantumC` 위상 잡음, 잡음 세기 다섯 개, 두 seed,
행동·확신 모델, 학습량, 모든 숫자 기준과 M0~M3 판정은 1차와 같다. 이 한 가지 수리만 결과를 보기
전에 등록하고 커밋한다. 1차 무효 결과는 `measurement/metacognition_invalid_{results,verdict}.json`에
보존한다.
