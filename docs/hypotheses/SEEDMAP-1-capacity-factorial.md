# SEEDMAP-1 — 사건 4개 seed 분기 위치 교차

상태: 사전등록

선행 결과: `CAPACITY-2=CP4_SEED_CONDITIONAL_CAPACITY`

## 질문

정상 안정화 뒤 사건 4개 주소 선택은 두 seed 모두 90%를 넘었지만 최종 행동은 seed 1337만
88.09%로 실패하고 seed 7331은 92.77%로 통과했다. 주소 변환 가중치, 값 상태를 읽는 원형,
회차별 엔진 시작값이 같은 seed 이름으로 묶여 있어 어느 요소가 분기를 만드는지 아직 모른다.

## 고정 조건

- `CAPACITY-2`의 사건 4개 1,536회차, 감각 순서, 정상 자체 갱신 8회
- 주소 변환 seed `1337 / 7331`
- 값 판독 원형 seed `1337 / 7331`
- 엔진 회차 시작값 계열 `1337 / 7331`
- 2×2×2의 여덟 조합을 모두 실행
- 선택·최종 행동 90%, 값별 최저 재현율 75%, 내용 판독 90%
- 정확 주소·내용 맞바꾸기·복구·기억 API와 질문 난수 고정

두 원래 조합 `(1337,1337,1337)`과 `(7331,7331,7331)`은 `CAPACITY-2` 사건 4개 결과를
허용오차 `1e-7` 안에서 재현해야 한다. 교차 요소는 새로 학습하지 않고 보관된 얼린 체크포인트만
바꾼다.

## 단일 교환 판정

실패 기준점 `(1337,1337,1337)`에서 한 요소만 7331로 바꾼 세 조합과, 성공 기준점
`(7331,7331,7331)`에서 같은 요소만 1337로 바꾼 세 조합을 직접 비교한다.

- 주소 변환 원인: 선택과 최종 행동이 양방향으로 각각 2%p 이상 움직이고 짝검정 `p≤0.01`이며
  실패↔통과가 뒤집힘
- 엔진 시작값 원인: 선택과 최종 행동에 같은 기준 적용
- 값 원형 원인: 내용 판독과 최종 행동에 같은 기준 적용

한 방향만 뒤집히거나 2%p·유의성 기준을 못 채우면 단일 원인으로 세지 않는다. 나머지 두 완전
교차 조합은 상호작용을 확인하는 데만 쓰며 결과를 본 뒤 특정 조합을 추가하지 않는다.

## 판정

- `SM1_SINGLE_FACTOR_CAUSAL`: 정확히 한 요소가 양방향 단일 교환 기준을 충족
- `SM2_MULTIPLE_FACTORS_CAUSAL`: 둘 이상 요소가 기준을 충족
- `SM3_ASYMMETRIC_FACTOR_EFFECT`: 단일 요소 효과가 한 방향에서만 성립
- `SM4_FACTOR_INTERACTION`: 단일 교환은 원인이 아니지만 완전 교차에서 결과가 달라짐
- `SM5_NO_FACTOR_EFFECT`: 여덟 조합이 분기를 설명하지 못함
- `SM0_INVALID`: 원래 조합 재현이나 실행·양성·가짜 통제가 깨짐

단일 원인이 확인되면 해당 공용 흐름만 수정할지 별도 사전등록한다. 상호작용이면 기능을 추가하지
않고 두 요소 조합을 독립 자료로 재현한다. 어떤 판정도 의식 증거가 아니다.
