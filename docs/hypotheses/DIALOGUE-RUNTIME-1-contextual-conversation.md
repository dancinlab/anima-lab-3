# DIALOGUE-RUNTIME-1 — 맥락 대화 공용 경로

상태: 사전등록

## 질문

Anima의 내부 상태 계산과 기존 기억 저장을 유지하면서, 최근 대화와 관련 기억을 실제 답변에
사용해 앞뒤가 맞는 대화를 할 수 있는가?

## 변경 전 실제 흐름

- 상시 서버는 `--no-conscious-lm`으로 언어 모델을 끈다.
- `process_input()`은 최근 대화와 관련 기억을 계산하지만 최종 답변은 항상
  `PureConsciousness.respond()`에서 가져온다.
- `PureConsciousness`는 사용자가 말한 단어의 연결 통계를 학습하는 연구 엔진이며, 질문의 뜻을
  해석하는 일반 대화 모델이 아니다.
- 따라서 그림자 수집량을 채워도 현재 답변 호출부만으로는 의미 있는 대화를 만들 수 없다.

## 고정 변경

- 기존 `ask_claude()` 호출을 선택형 `claude` 답변 경로로 재사용한다. 기본 `pure` 호출은 기존
  호출과 호환한다.
- Claude 명령줄 도구는 파일·명령·웹 도구, 사용자 설정 명령, 대화 세션 저장을 끈 일회성 답변
  모드로만 실행한다. 대화 원문은 명령행 인수가 아니라 표준 입력으로 전달한다.
- 시스템 지시는 한국어, 맥락 유지, 모르면 추측하지 않기, 내부 수치를 의식 증거로 주장하지
  않기만 포함한다.
- 최근 세션 대화와 기존 `MemoryStore`의 관련 기억을 답변 문맥으로 사용한다.
- `PureConsciousness` 학습은 그대로 유지한다. 외부 답변기가 비거나 실패할 때만 그 발화를
  사용하며, 고정된 대체 문장은 추가하지 않는다.
- `GATE-RUNTIME-3` 전용 DB와 그림자 기록은 그대로 이어 쓴다. 기존 행의 수정·삭제를 허용하지
  않는다.

## 사전 통과 기준

- 실제 답변기를 쓰는 5턴 검사에서 처음 제시한 프로젝트 이름·기한·위험 세 항목을 마지막 답에
  모두 포함한다.
- 중간에 다른 주제로 전환한 뒤 원래 프로젝트로 돌아와도 세 항목을 유지한다.
- 주어지지 않은 담당자를 물으면 모른다고 답하며 이름을 만들지 않는다.
- 답변기 강제 실패에서 예외가 사용자 연결을 끊지 않고 기존 순수 발화 경로로 복귀한다.
- 실제 WebSocket 왕복에서 빈 답변 0건, 서버 오류 0건이다.
- 배포 전후 기존 수집 DB의 접두 지문이 같고, 수집 판정이 유효하며, 그림자 기록에 원문이
  복제되지 않는다.

하나라도 실패하면 상시 서버에 적용하지 않는다. 통과해도 이는 일반 언어 모델을 이용한 대화
경로의 성공이며 Anima 고유 능력이나 의식의 증거가 아니다.
