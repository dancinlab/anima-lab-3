# GATE-RETRIEVAL-CONTROL-4 — 회차 순서 독립 내용 점수 교환

상태: 완료 — `GRC4A_CONTENT_ALIGNMENT_CAUSAL`
등록일: 2026-08-12

## 질문과 범위

`GATE-RETRIEVAL-CONTROL-3`은 회차 주소와 후보 위치 누출을 제거했고 정상 검색은 거의 100%였지만,
내용 점수를 바로 다음 회차와 바꾼 비교도 80% 이상을 유지했다. 생성 순서상 사실 종류와 위치가
이웃 회차에 반복돼, 이 비교는 내용 점수가 정답 후보에 붙어 있어야 하는지를 독립적으로 검사하지
못했다.

이번 검사는 검색 모델·자료·주소·후보 수·점수·기준을 바꾸지 않는다. 주소가 고른 같은 두 후보
안에서 **두 내용 점수의 자리만 서로 바꿨을 때** 정답 선택이 무너지고, 다시 한 번 바꾸면 원래
결과가 정확히 돌아오는지만 묻는다. 교환 규칙은 정답 표찰, 사실 종류, 후보 문장, 회차 순서를 읽지
않는다.

이는 고정 문장 의미 점수가 후보 선택의 실제 원인인지 확인하는 일반 검색 통제다. Anima 고유 기능,
대화 이해, 주관적 경험 또는 의식을 검사하지 않으며 실제 사용자 대화의 저장·검색 기본값도 바꾸지
않는다.

## 고정 자료와 흐름

- `GATE-RETRIEVAL-CONTROL-3`과 같은 seed `1337`, `7331`, 평가 1,024회차, 회차당 후보 8개,
  보정 자료 4,096개, 사실 네 종류와 8개 사실 위치를 사용한다.
- 같은 고정 다국어 문장 의미 모델 revision, 결정형 ridge 맞춤, 64차원 회차·주제 주소와 주소 상위
  2개 후보를 그대로 재사용한다.
- `within_pool_content_swap`은 각 회차의 주소 후보 두 개가 가진 내용 점수만 맞바꾼다. 후보 목록,
  주소 점수, 나머지 여섯 점수와 모든 문장은 바꾸지 않는다.
- `restored_content`는 같은 교환 함수를 두 번 적용한 결과다. 정상 내용 점수·순위·측정 지문과 정확히
  같아야 한다.
- Python 3.13, `torch==2.8.0`, `transformers==4.55.4`, CPU와 기존 고정 모델 revision을
  유지한다.

## 고정 비교와 감사

- `balanced_split`: 정상 회차·주제 주소와 정상 내용 점수
- `topic_only`: 같은 두 후보를 주소 점수와 위치만으로 정렬
- `within_pool_content_swap`: 같은 후보 둘의 내용 점수 자리만 한 번 교환
- `restored_content`: 같은 점수 교환을 두 번 적용
- `shuffled_episode_address`: 다음 회차 주소를 사용한 기존 주소 가짜 비교
- `legacy_next_episode_content`: 다음 회차 내용 점수를 사용한 기존 진단 비교. 판정 기준에는 사용하지
  않는다.
- `oracle_memory`: 정답 사실만 남긴 양성 비교
- `no_memory`: 후보가 없는 정보 없음 비교

결과에는 주소 후보 목록 지문, 정상·교환·복원 점수 지문, 회차별 점수 다중집합 보존 여부, 교환된
회차 수, 자료·모델·환경 감사를 기록한다. 후보가 정확히 두 개가 아니거나, 한 번 교환에서 두 후보
밖의 값이 달라지거나, 두 번 교환이 정상 점수와 비트 단위로 같지 않으면 무효다.

## 사전 판정

두 seed 모두 다음을 만족해야 한다.

- 정상 검색 상위 3개 95% 이상, 상위 1개 90% 이상
- 사실 네 종류와 8개 위치의 정상 상위 1개가 각각 85% 이상
- 주제만 사용한 상위 1개 45~55%, 상위 3개 95% 이상
- 다음 회차 주소를 쓴 상위 3개 35% 이하
- 한 번 점수 교환한 상위 1개 10% 이하
- 정상 상위 1개와 한 번 교환의 차이 80%p 이상
- 두 번 교환한 순위·점수·측정값·지문이 정상과 정확히 같음
- 정답 사실만 남긴 비교 상위 3개 99% 이상, 기억 없음 5% 이하
- 정상 주소 후보 목록의 정답 포함률 99% 이상
- 모든 회차에서 점수 다중집합이 보존되고 정확히 두 후보의 점수만 맞바뀜

판정은 다음과 같다.

- `GRC4A_CONTENT_ALIGNMENT_CAUSAL`: 주소와 양성 통제가 유효하고 점수 교환·복원 기준 모두 통과
- `GRC4B_CONTENT_ALIGNMENT_NOT_CAUSAL`: 주소와 양성 통제는 유효하지만 점수 교환 뒤에도 정답
  선택이 유지됨
- `GRC4C_EPISODE_ADDRESS_LOSS`: 정상 또는 다음 회차 주소 통제 실패
- `GRC4_0_INVALID`: 자료·모델·환경·지문·결정성·교환 보존·복원·양성·정보 없음 중 하나라도 실패

`GRC4A`면 표준 검색 양성 경로가 유효하다고 확정하고, 다음 별도 사전등록에서만 `GATE-2`의 의미
기반 저장 선택과 이 검색을 합친다. 다른 판정이면 결과를 본 뒤 모델·문장·후보 수·주소 차원·기준을
조정하지 않고 처음 실패한 공용 단계만 조사한다. 어느 결과도 실제 대화 기본값에 자동 적용하지
않는다.

결과를 보기 전에 README와 이 문서를 GitHub `main`에 먼저 고정하고 그 커밋을 실행 사양의
`preregistration_commit`으로 사용한다.

## 판정과 다음 단계

사전 판정은 `GRC4A_CONTENT_ALIGNMENT_CAUSAL`이다. 주소가 고른 후보 둘 중 어느 문장이 사실인지
결정한 원인은 후보에 붙은 내용 점수였다. 직전 `GRC3B`는 내용 검색의 실패가 아니라, 사실 종류와
위치가 이웃 회차에서 반복되는 생성 순서에 다음 회차 점수 비교가 묶인 통제 설계의 실패였다.

이 결과는 고정 문장 의미 분류기와 인공 회차 주소를 사용하는 일반 검색 양성 비교다. Anima가 문장을
주관적으로 이해한다거나 의식적으로 기억한다는 근거가 아니며 실제 대화의 저장·검색 기본값은
바꾸지 않았다. 다음은 별도 사전등록할 `GATE-3`에서 `GATE-CONTROL-2`로 검증한 의미 기반 저장
선택과 이번 검색을 합쳐, 다양한 실제 대화 표현에서도 필요한 사실만 저장하고 다시 찾는지 검사한다.
