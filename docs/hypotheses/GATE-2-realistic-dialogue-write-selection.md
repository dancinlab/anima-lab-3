# GATE-2 — 다양한 대화와 주제 이동의 장기 기억 선택

상태: 사전등록
등록일: 2026-08-12

## 질문과 범위

`GATE-CONTROL-2`는 고정된 문장 의미 표현이 통제된 문장 틀에서 중요한 사실을 같은 저장량의
가짜 비교보다 잘 골랐음을 확인했다. 아직 실제 대화에 가까운 여러 말투, 일시적인 선호·계획처럼
사실과 닮은 방해 문장, 한 회차 안의 주제 이동에서도 같은 선택이 유지되는지는 확인하지 않았다.
이번 질문은 이 세 변화가 함께 있을 때도 나중에 필요한 사실만 장기 검색 목록에 남길 수 있는가다.

이 검사는 일반 문장 의미 분류와 기억 검색 기능을 검사한다. Anima 고유 기능, 주관적 이해 또는
의식을 검사하지 않는다. 사용자가 명시적으로 저장한 기억은 자동 선택 대상이 아니며, 모든 원문은
판정과 관계없이 원본 보관소와 최근 대화에 남긴다.

## 고정 자료

- seed `1337`, `7331`, 보정 4,096문장, 평가 1,024회차를 사용한다.
- 한 평가 회차는 오래 유지할 사실 한 문장과 방해 문장 일곱 개, 뒤의 질문 하나로 구성한다.
- 사실은 선호·약속·목표·사용자 정보 네 종류를 같은 수로 배치한다.
- 방해 문장은 인사·추임새·현재 관찰·일시 선호·미확정 계획·주제 질문·응답 확인 일곱 종류다.
- 보정과 평가에는 종류별로 서로 겹치지 않는 여러 문장 틀을 사용한다. 주제와 값 문자열도 겹치지
  않으며, 완성된 원문 중복은 허용하지 않는다.
- 각 평가 회차는 서로 다른 세 보조 주제를 거치고, 중요한 사실의 위치는 `1·3·5·7`번째에 같은
  수로 배치한다. 문장 순서는 섞지 않아 실제 대화의 시간 순서를 보존한다.
- 일시 선호와 미확정 계획은 사실 문장과 비슷한 말투를 쓰되 각각 `오늘만·지금은`,
  `생각 중·아직 미정`처럼 장기 사실이 아님을 문장 안에 명시한다.
- 질문은 중요한 사실의 주제를 포함하며, 검색 상위 3개 안에 해당 사실이 있는지를 센다.
- 자료 생성 규칙과 문장 목록의 지문, 종류·위치·역할·주제 이동 균형을 결과에 기록한다.

이 자료는 개인정보가 들어간 실제 사용자 기록이 아니라, 실제 대화형 표현을 사람이 작성해 고정한
합성 자료다. 결과를 보고 문장이나 표찰을 바꾸지 않는다.

## 고정 선택기와 비교

`GATE-CONTROL-2`와 같은
`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` revision
`e8f8c211226b894fcb81acc59f3b34ba3efd5f42`, 최대 128토큰, attention mask 평균,
L2 정규화, 역할 2차원, `canonical_ridge`와 ridge `0.001`을 사용한다. Python 3.13,
`torch==2.8.0`, `transformers==4.55.4`, CPU 실행도 유지한다. 보정 자료로 정상 선택기와 표찰을
뒤섞은 가짜 선택기를 한 번 맞춘 뒤 평가 전에 가중치와 문턱을 얼린다.

비교 조건은 다음 여섯 가지다.

- `semantic_gate`: 얼린 문장 의미 선택
- `store_all`: 모든 문장을 검색 목록에 등록
- `oracle_gate`: 중요한 사실만 등록하는 양성 비교
- `matched_random`: 정상 선택과 회차별 저장량이 같은 무작위 선택
- `matched_shuffled_gate`: 뒤섞은 표찰 점수 중 정상 선택과 같은 개수만 고른 가짜 선택
- `no_memory`: 아무 문장도 등록하지 않는 정보 없음 비교

같은 저장량 비교는 `GATE-CONTROL-2`의 점수 순위와 후보 위치 오름차순 동률 처리 방식을 그대로
사용한다. 회차별·전체 저장 수가 정상 선택과 다르면 결과는 무효다. 실제 대화 저장 호출과 기본값은
실험 판정 전에는 변경하지 않는다.

## 사전 판정

자료·환경·모델 revision·특징 폭·유한값·체크포인트·결정성·저장량 일치를 닫힌 판정기로
확인한다. 두 seed 모두 다음 조건을 만족해야 한다.

- 정상 선택의 중요 사실 저장률과 전체 후속 질문 정답률 90% 이상
- 사실 네 종류별 후속 질문 정답률 각각 85% 이상
- 사실 위치 `1·3·5·7`별 후속 질문 정답률 각각 85% 이상
- 정상 선택의 전체 방해 문장 저장률 25% 이하, 각 방해 종류 저장률 50% 이하
- 정상 선택의 검색 목록이 전체 저장의 50% 이하
- 전체 저장보다 후속 질문 정답률이 2%p 넘게 낮지 않음
- 같은 저장량 무작위와 저장량 일치 가짜보다 각각 25%p 이상 높은 후속 질문 정답률
- 정답 선택과 전체 저장의 후속 질문 정답률 95% 이상, 기억 없음 5% 이하

판정은 다음과 같다.

- `G2R1_REALISTIC_WRITE_VALID_NOT_UNIQUE`: 모든 통제와 두 seed의 전체·종류·위치 기준 통과
- `G2R2_STYLE_OR_SHIFT_LOSS`: 통제는 유효하지만 정상 선택의 전체·종류·위치 기준 중 하나 미달
- `G2R0_INVALID`: 자료·환경·모델·저장량·양성·가짜·정보 없음·지문·결정성 중 하나라도 무효

`G2R1`이면 원문 보존과 명시적 기억 우회를 유지한 채, 검증된 선택기를 공용 기억 저장 API의
선택 가능한 검색 등록 단계로 연결한다. 안전한 실패 시에는 모든 원문을 검색 목록에 넣는 기존
동작으로 돌아가야 한다. 실제 기본값 전환은 통합 회귀 검사에서 기존 기억 복원과 명시적 저장이
모두 유지될 때만 수행한다. `G2R2`이면 결과를 보고 문턱이나 표현 목록을 조정하지 않고 처음 무너진
사실 종류·위치·방해 종류만 후속 검사한다.

`preregistration_commit`으로 사용한다.
