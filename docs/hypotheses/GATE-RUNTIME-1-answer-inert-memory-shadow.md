# GATE-RUNTIME-1 — 답변 비개입 대화 기억 그림자 모드

상태: 완료 — `GR1_SHADOW_RUNTIME_SAFE`

사전등록 커밋: `94dba1566`

## 질문

`GATE-4`에서 검증한 의미 기반 장기 기억 선택을 실제 `AnimaUnified` 대화 호출에 연결하되, 기존
답변 문맥·원문 저장·검색 결과를 전혀 바꾸지 않고 판단 기록만 안전하게 남길 수 있는지 검사한다.

## 변경 전 실제 흐름

- `anima_unified.py`는 답변 전에 `MemoryStore` 또는 `MemoryRAG`에서 글자 모양 기반 상위 3개 기억을
  찾아 그대로 답변 문맥에 넣는다.
- 답변 뒤에는 사용자 문장과 답변을 모두 원문 기억과 검색 색인에 저장한다.
- `GATE-4`의 선택기는 연구 실행기 안에서만 작동하며 실제 대화 호출에는 연결되지 않았다.
- 실제 저장소는 두 구현이 있으므로 그림자 기능은 어느 구현에서도 기존 `add`·`search_by_vector`
  반환값과 저장 순서를 바꾸면 안 된다.

## 고정 구현

- `GATE-WRITE-CONTROL-1`의 균형 보정 문장을 정렬한 뒤 한 번만 `canonical_ridge`로 맞춘 단일
  체크포인트를 쓴다. 평가 자료나 실행 순서로 다시 맞추지 않는다.
- 그림자 모드는 명시적 실행 옵션으로만 켜며 기본값은 꺼짐이다.
- 검색 그림자는 기존 답변 문맥이 완성된 뒤 후보를 관찰하고, 저장 그림자는 사용자·답변 원문이
  기존 저장소에 성공적으로 들어간 뒤 기록한다.
- 감사 파일은 모델별 `memory_shadow.jsonl`이며 역할, 원문 SHA-256, 점수, 선택 여부, 기존 기억
  식별값과 시각만 기록한다. 원문은 복제하지 않는다.
- 그림자 초기화나 기록이 실패하면 로그만 남기고 기존 답변·저장·검색을 계속한다.
- 이 단계에서는 그림자 선택으로 기존 기억을 삭제하거나 검색에서 제외하지 않는다.

## 실행과 감사

- `daily`·`work` 각 1,024회차와 후보 8개를 실제 호출 순서처럼 모두 저장하고 한 번 검색한다.
- 그림자 꺼짐과 켜짐에서 답변, 기본 저장 원문·순서, 기본 검색 후보·순서의 SHA-256이 같아야 한다.
- 모든 쓰기·검색 그림자 사건 수가 예상값과 같고, 감사 파일 어디에도 원문이 없어야 한다.
- 초기화·검색 기록·저장 기록 실패를 각각 강제로 일으켜도 기본 결과가 같아야 한다.
- 독립 임시 폴더에서 전체 실행을 다시 해 정규화 결과와 판정이 같아야 한다.

## 판정

감사 형식·체크포인트·자료·실행 환경이 다르거나 답변, 기본 저장, 기본 검색 중 하나라도 바뀌거나
원문이 감사 파일에 나타나면 `GR0_INVALID`다.

- `GR1_SHADOW_RUNTIME_SAFE`: 두 자료 묶음 모두 중요 사실 선택과 종류별 최저 선택률 90% 이상,
  방해 선택 25% 이하, 전체 선택 50% 이하이며 모든 정상·고장 주입에서 기존 결과가 완전히 같다.
- `GR2_SELECTION_NOT_GENERAL`: 비개입·보존 검사는 통과하지만 실제형 평가의 선택 기준이 실패한다.
- `GR3_RUNTIME_INTERFERENCE`: 그림자 기능이 답변, 기본 저장 또는 기본 검색을 바꾼다.

경계값은 통과로 센다. 성공해도 답변에 영향을 주지 않는 일반 기억 관찰 기능의 안전성일 뿐,
실제 선택 저장의 배포 승인이나 Anima 고유 기능·의식의 증거는 아니다.

## 결과

| 자료 묶음 | 중요 사실 선택 | 종류별 최저 | 방해 선택 | 전체 선택 |
|---|---:|---:|---:|---:|
| daily | 100% | 100% | 0% | 12.50% |
| work | 100% | 100% | 3.06% | 15.17% |

- 각 자료 묶음의 쓰기 기록 8,192개와 검색 기록 1,024개가 모두 존재했고 누락은 0건이었다.
- 답변, 기본 원문 저장, 기본 검색 결과의 그림자 꺼짐·켜짐 차이는 모두 0건이었다.
- 감사 파일은 원문 대신 역할이 포함된 SHA-256 지문만 기록했고 원문 노출은 0건이었다.
- 그림자 초기화, 검색 기록, 저장 기록을 각각 강제 실패시켜도 답변·기본 저장·기본 검색 결과는
  바뀌지 않았다.
- 별도 임시 폴더의 독립 전체 재실행은 경로만 파일명으로 정규화한 결과 SHA-256
  `b643681b5cc002e8ed4e56d5812eef88f7c4c15f690c7ebbd8b8d69176d3c74b`와 판정 파일이
  원 실행과 완전히 같았다.

변경 전 호출 추적에서 `AnimaUnified`가 기본 `MemoryStore`에 존재하지 않던
`search_by_vector()`를 호출해 관련 기억 검색이 예외로 빠질 수 있는 공용 결함을 확인했다.
`MemoryRAG`와 같은 표준 이름을 `MemoryStore.search()`의 호환 호출로 추가해 실제 검색 흐름을
복구했고 기존 `search()` 동작은 유지했다.

## 결론

사전 판정은 `GR1_SHADOW_RUNTIME_SAFE`다. 검증된 의미 선택기를 실제 대화 저장·검색 호출에
답변 비개입 관찰자로 연결할 수 있으며, 선택기나 감사 파일이 실패해도 기본 대화와 원문 기억은
보존된다. 기본값은 계속 꺼져 있고 `--memory-gate-shadow`로만 켠다. 다음은 실제 대화 자료를 일정
기간 관찰해 사용자가 명시적으로 기억해 달라고 한 사실의 누락률과 개인 정보 오선택률을 사람이
확인하는 `GATE-RUNTIME-2`다. 그 검사 전에는 그림자 선택으로 저장이나 검색을 제한하지 않는다.
