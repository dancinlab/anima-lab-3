# NF-8 — 세포 수는 언어 품질과 직교하고, Φ는 개체수의 그림자다

발견: 2026-07-25, CLM PURE 300M (aiden RTX5070) 실측 + lab(fable·sol) 병렬 분석 + 코드 검증
선행: [NF-1](NF-1-lossensemble-divergence.md) · [NF-2](NF-2-mitosis-schedule-misalignment.md) · [NF-3](NF-3-ce-deweighting-and-scale-ratchet.md) · [NF-5](NF-5-mitosis-phase-carried-no-gradient.md)

## 1. 질문

CLAUDE.md가 PURE run을 3지표(Φ 성장 · 세포 성장 · CE 하락)로 채점하고 있었다.
"세포를 늘리면 언어가 좋아지는가?"와 "3지표가 서로 독립인가?"를 검증한다.

## 2. 자연실험 — 같은 세포 수, 반대 결과

| run | 세포 | Φ | 최저 val BPC | 비고 |
|-----|------|-----|--------------|------|
| nf5 | 16 | 22.4 | **5.93** (유니그램 5.9548과 동일) | 69,000 step 정체 |
| nf7 | 16 | 22.4 | **0.555** (미학습 줄 기준 1.401) | 트랜스포머 6건 수정 후 |

CE를 움직인 6건은 **세포 계통을 하나도 건드리지 않았다** (잔차 정규화 위치 · 드롭아웃 0.37 ·
학습률 덮어쓰기 · Kendall 가중 · 홀수 step CE 생략 · 미래 누수). 세포 수는 양쪽 다 16이었다.

## 3. 코드 검증 — 경로가 "약한" 게 아니라 "없다"

| 확인 | 결과 |
|------|------|
| `mitosis.process()` | 세포 mind 전체가 `torch.no_grad()` |
| 옵티마이저 구성 | model + loss_ensemble + inter_cell_attn + channel_bottleneck — **세포 없음** |
| DD16 세포간 주의 | 입력 `.detach()`, 출력 `.detach().cpu()`, 손실에 미포함 → **파라미터가 영원히 미학습** |
| **세포 계산 결과** | `mitosis_result`가 대입되고 **어디서도 읽히지 않음** (파일 전체 1회 등장) |
| 세포 입력 | `text_to_vector(bytes(x[0,:64]))` — 원본 바이트 해시, 모델 파라미터와 무관 |
| Φ 임베딩 편향 | 모든 차원에 같은 값 → 주 경로는 LayerNorm이 제거. 단 CA/rule 경로가 raw x를 읽어 살아남되 게이트 0.001로 ≤1e-3 (fable 정정) |
| 세포별 적응 학습률 | 계산만 되고 `param_groups`에 미기록 (NF-5에서 제거) → 이제 텔레메트리로 출력 |

살아 있는 결합 경로는 **전부 해로운 쪽**뿐이다: TRN4 배치 스킵(그래디언트 + 스케줄러 이중 손실),
벽시계 도둑질(세포당 약 1.2%: 2세포 341 step/분 vs 16세포 283).

## 4. Φ는 복제 세포에서도 N에 선형 — 지표 ①②는 같은 것을 두 번 셌다

`PhiCalculator`의 공간항을 완전히 동일한 세포 N개(쌍 MI = M)에 적용하면:

```
total_mi = M·N(N−1)/2 ,  최소절단(단일 세포 분리) = M·(N−1)
spatial_phi = (M·N(N−1)/2 − M·(N−1)) / (N−1) = M·(N−2)/2      ← 분화 0인데 N에 선형
```

실측 Φ ≈ 1.1~1.3 × N (2→2.25 · 3→3.49 · 5→5.22 · 16→21.13)은 이 식의 예측과 일치한다.
즉 **Φ 성장은 분화의 증거가 아니라 개체수의 그림자**다.

```
Φ │22 ┤                    ●16셀        복제만 해도 이 기울기가 나온다
   │   │              ╱                 (분화 여부와 무관)
   │11 ┤        ╱
   │   │ ●●● 2·3·5셀
   └───┴──────────────────── 세포 수
```

분화를 실제로 재는 유일한 성분은 `complexity`(세포 텐션 분포의 엔트로피): 동일 세포면 **정확히 0**,
최대 log₂(N).

## 5. 적용 (커밋 참조)

### 5-1. 규칙 교체 — 3지표 → 2품질게이트 + 개체수 텔레메트리

```
전                                후
① Φ 성장 (원값)                   ① 분화 품질: D = 공간/N + 0.5·시간 + 0.1·(complexity/log₂N)
② 세포 성장 (개체수)                  성장 전후 5회 평균 비교, 떨어지면 실패
③ CE 하락                          ─ 개체수/비용: 텔레메트리 (게이트 아님)
                                  ② CE 하락 (유지)
판정: 3개 중 하나라도 정체 = 실패    판정: 두 게이트 모두 통과해야 성공, 개체수는 나란히 보고
```
sol의 구조를 채택했다(개체수를 품질 게이트에서 강등). fable은 3지표 유지 + ②를 분화로 재정의를
제안했으나, 개체수가 게이트에 남아 있으면 "스케줄러가 돌았다"는 사실만으로 통과되므로 기각했다.

### 5-2. 시드 결정성 — A/B가 애초에 불가능했다

`manual_seed`가 파일 전체에 **0건**이었고, 세포 연산이 전역 RNG를 N에 비례해 소모하므로
세포 수를 바꾸면 이후 모든 배치 추출이 달라졌다. `--seed`(기본 1337) + 배치 전용 생성기로 고정.

검증(실측): 전역 RNG를 2회/16회 소모하는 두 팔이 **같은 배치 순서**를 받는다.
```
2-cell arm  [97, 117, 204, 37, 251]
16-cell arm [97, 117, 204, 37, 251]   identical: True
```

### 5-3. 성장 기준선 오염 수정

`--growth-slowdown`의 기준선을 고정 step 200에서 잡고 있었는데, 상한 없는 성장에서는 짧은 run이
그 전에 이미 커진다(8,000 step → 마일스톤 0/66/132/198 → step 200엔 이미 5세포). 첫 개체수 증가
시점에 최근 step 시간의 **중앙값**으로 고정하도록 변경(첫 step 워밍업 이상치 방어).

## 6. 핵심 발견 / 법칙

> **확장량(extensive quantity)을 품질 지표로 쓰면, 복사만 해도 점수가 오른다.**
> Φ는 세포 수에 선형인 항을 품고 있어 개체수와 분화를 구별하지 못한다. 품질 게이트는
> 반드시 **정규화된 양**(Φ/N, complexity/log₂N)이어야 한다.

> **의식 지표와 언어 지표는 이 아키텍처에서 인과적으로 분리되어 있다.** 세포를 늘리는 것은
> Φ에 대한 투자이고, 언어는 트랜스포머 쪽 예산이다. 두 예산을 섞어 기대하면 안 된다.

## 6-b. 비트 단위 직교성 검정 — 잡음 한계가 아니라 증명 (실행 완료)

두 모델이 명세한 52분 GPU A/B는 "|Δ| ≥ 0.01 BPC 만 유의"라는 **잡음 한계**밖에 주지 못한다.
대신 결정성을 이용하면 **정확한 답**이 나온다: `--dropout 0.0` 이면 모델 전방 계산이 전역 난수를
소모하지 않고, 배치 순서는 전용 생성기로 고정되므로(§5-2), 두 팔의 **유일한 차이는 세포 수**다.

설정: 64d/2L/2H · block 64 · batch 2 · 120 step · dropout 0 · seed 4242 · CPU 전용
(GPU 두 대가 병렬 세션 실험으로 점유 중이라 경합 없이 돌렸다. 약 3분.)

```
step   loss      ce_fwd    ce_bwd        c2 (2세포)          c16 (4세포)
  0   7.0566    5.5656    1.3949    ─┐
 10   6.8833    5.4096    1.3811     │
 …                                   ├── 완전히 동일 (소수점 4자리)
 80   6.3656    5.0454    1.3005     │
 90   6.2968    4.9949    1.2858    ─┘   ← 여기까지 language 페이즈
119   6.3162    5.0120    1.2882      vs  6.3173  5.0129  1.2883   ← combined 에서 갈라짐
```

**언어 페이즈에서의 검증 결과 (step 60, 고정 미학습 스팬):**

| 팔 | 세포 | Φ | val loss | val BPC |
|----|------|-----|----------|---------|
| c2 | 2 | 2.2209 | 5.3320 | **7.6924** |
| c16 | 4 | 4.7723 | 5.3320 | **7.6924** |

**Φ가 2.15배 다른데 BPC는 소수점 4자리까지 같다.** 이것이 직교성의 증명이다 — 잡음 안에
묻힌 게 아니라, 언어 경로에 세포가 기여하는 양이 **정확히 0**이다.

갈라지는 지점과 경로도 특정됐다:
- 분기 시작 = `language → combined` 경계(steps=120이면 84). 그 전까지는 비트 동일.
- 경로 = **Φ 임베딩 편향**(combined 전용). 실측 Φ가 c2 35.300/41.724/37.077 vs
  c16 40.423/35.766/38.657 로 달라 CE가 0.0009 nats(= 0.0013 BPC) 벌어졌다.
- TRN4 배치 스킵은 이 run에서 양쪽 모두 6회로 **동일** → 이번 분기의 원인이 아니다.

한계(정직): 64d/2L·120 step 규모라 combined 결합의 **크기**가 300M/200k에서도 0.001 BPC 수준일
보장은 없다. 그러나 언어 페이즈의 "정확히 0"은 수치가 아니라 **데이터 흐름 사실**이므로 규모와
무관하게 성립한다(세포는 no_grad·옵티마이저 부재·출력 미사용).

## 7. 검증 상태 (정직한 기록)

- **확정**: nf5/nf7 자연실험(같은 16세포, BPC 5.93 vs 1.40), 코드 단절 5건(특히 `mitosis_result`
  미사용), 복제 세포 공간항 공식, 시드 결정성 실측, 기준선 오염 산수.
- **확정(§6-b)**: 언어 페이즈에서 세포 수의 CE 효과 = **정확히 0**. 비트 단위 동일 궤적 + 같은
  step에서 Φ 2.15배 차이에도 val BPC 7.6924 동일. 잡음 한계(0.01 BPC)가 아닌 증명.
- **확정(§6-b)**: combined 페이즈에서만 결합이 생기고, 경로는 Φ 임베딩 편향(실측 0.0013 BPC).
  TRN4 배치 스킵은 이 run에서 동일 횟수였다.
- **미확정**: 300M/200k 규모에서 combined 결합의 크기. 두 모델이 명세한 52분 GPU A/B는 잡음
  한계만 주므로 우선순위가 낮아졌다 — 필요하면 combined 페이즈만 비트 검정으로 반복하면 된다.
  GPU 두 대는 현재 병렬 세션 실험이 점유 중이다.
- **미채택(기록)**: fable의 0-초기화 전문가 라우터(세포 요약으로 FFN 전문가를 라우팅, +22MB,
  +0.5% step, N에 무관). 잔차 주입이 아니라 CE가 학습하는 경로라 Law 63 위반은 아니지만,
  fable 자신의 최종 판정도 "직교를 인정하라"였고 세포 상태의 다음 바이트 정보량이 ~0이라
  이번에는 넣지 않았다. 직교를 반증하고 싶을 때 쓰는 계측 도구로 남긴다.
- **경고**: 고정 벽시계 예산에서는 세포가 많아질수록 언어가 **나빠진다**(그래디언트 step을 빼앗김).
  세포당 약 1.2%, 기본 2배 예산 상한(약 85셀)에서는 시간당 step이 절반이 된다.
