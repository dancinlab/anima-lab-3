# CONTROL-3 — 열쇠 기반 주의집중 양성 비교

상태: 완료 · `A1_KEYED_ATTENTION_VALID`

## 질문

`CONTROL-2`의 표준 `GRU`는 회차에 저장된 두 값 중 하나를 항상 골랐지만, 질문한 열쇠에 맞는
값을 안정적으로 선택하지 못했다. 같은 온라인 자료와 평가에서 열쇠를 저장 열쇠와 직접 비교하는
표준 주의집중 방식은 새 관계를 배울 수 있는지 확인한다. `QuantumC`나 새 뇌 기능은 넣지 않는다.

## 과제와 변경 변수

- `CONTROL-2`와 같은 회차별 두 `열쇠→값` 관계, 방해 입력 두 개, 질문 하나를 사용한다.
- 학습 자료는 같은 규칙으로 매 step 새로 생성하며 총 256,000개를 중복 없이 한 번씩 쓴다.
- 검증 1,024개와 최종 평가 2,048개는 `CONTROL-1·2`와 같은 고정 자료를 재사용한다.
- 바꾸는 것은 기억 계산 하나다. 표준 `GRU` 대신 질문 열쇠를 질의, 저장 열쇠를 검색 대상,
  저장 값을 검색 결과로 넣는 `torch.nn.MultiheadAttention`을 쓴다.
- 질문과 저장 열쇠는 같은 학습 가능한 열쇠표를 공유한다. 값은 별도 값표를 거쳐 직접 행동판으로
  읽는다. 위치나 정답표를 따로 제공하지 않는다.
- 방해 입력은 관계 저장 항목이 아니므로 검색 대상에 넣지 않되, 자료 지문과 시간 간격에는 그대로
  남긴다. 이는 열쇠 기반 기억이 관련 저장 항목만 유지하는 구조 차이다.
- 평가는 얼린 가중치로 수행하며 최종 평가 자료는 한 번만 연다.

## 고정 사양

- 모델 seed: `1337 / 7331`
- 온라인 자료 seed: `20260811`
- 열쇠 8종, 값 8종, 방해 입력 16종, 회차당 관계 2개, 방해 단계 2개
- 상태 폭 96, 주의집중 머리 4개, dropout 0, 배치 128, 최대 2,000 step
- `AdamW`, 학습률 0.003, weight decay 0.0001, gradient clip 1.0
- 50 step마다 고정 검증 자료를 재고, 검증 정확도가 가장 높은 시점을 저장
- 실행 장치: 로컬 CPU

## 비교 조건

1. `attention`: 온라인 회차로 학습한 표준 다중 주의집중층과 직접 행동판
2. `vector_memory`: 회차 안의 정확한 열쇠·값 저장 기준
3. `no_memory`: 학습 중 열쇠별 값 빈도만 사용하고 회차 기억은 쓰지 않는 기준
4. `shuffled_labels`: 정상 예측은 고정하고 평가 정답만 한 칸 옮긴 가짜 기준

## 무효 조건

- 온라인 학습 예시가 256,000개가 아니거나 같은 지문이 하나라도 반복됨
- 온라인 학습과 고정 검증·평가 자료 사이 지문이 하나라도 겹침
- 배치별 또는 전체 열쇠·값·질문 위치 균형이 등록값과 다름
- 두 seed가 서로 다른 온라인 학습 순서를 사용함
- 모델이 등록하지 않은 입력이나 정답 정보를 받음
- `vector_memory`가 100%가 아님
- 기억 없음 또는 가짜 정답 정확도가 25%를 넘음
- seed·체크포인트·결과가 누락되거나 숫자에 NaN·무한값이 있음
- 체크포인트 SHA-256 지문이 결과 영수증과 다름

## 판정

- `A1_KEYED_ATTENTION_VALID`: 두 seed의 `attention` 최종 정확도가 각각 90% 이상이고 값별
  재현율도 모두 80% 이상이며 모든 무효 조건을 피함
- `A2_ATTENTION_PATH_INVALID`: 정확 기억과 가짜 통제는 유효하지만 주의집중층이 위 문턱을 통과하지 못함
- `A0_INVALID`: 자료 고유성·분리·균형·입력·통제·파일 지문 중 하나라도 무효

`A1`이면 이 과제의 표준 양성 비교를 `GRU`가 아니라 열쇠 기반 주의집중으로 확정하고,
`EPISODE-1`에서 같은 검색 계산을 일반 비교로 사용한다. 이는 `QuantumC`가 통과했다는 뜻이
아니며 의식 증거도 아니다. `A2`이면 과제 표현이나 행동판까지 다시 분해하고 `EPISODE-1`은 계속
보류한다. 어느 결과에서도 등록한 학습량·폭·학습률을 뒤늦게 바꾸지 않는다.

## 결과

등록한 사양을 로컬 Apple Silicon CPU에서 두 seed 모두 실행했다. 두 실행은 같은 순서의 온라인
학습 지문 `5753b45d219d2245c5177cf27fcc9201dcbf2e7bddd5af460f16cf69909ba7a0`을
사용했다. 각 실행의 학습 회차 256,000개는 모두 고유했고 고정 검증·평가 자료와 겹친 회차는
0개였다. 2,000개 배치 모두 질문 열쇠·정답 값·질문 위치가 정확히 균형이었다.

| 조건 | seed 1337 | seed 7331 | 등록 기준 |
|---|---:|---:|---:|
| 주의집중 검증 최고 | 100% | 100% | 저장 시점 선택용 |
| 주의집중 최종 평가 | 100% | 100% | 각각 ≥90% |
| 값별 최저 재현율 | 100% | 100% | 각각 ≥80% |
| 질문 열쇠 항목 평균 비중 | 99.72% | 99.81% | 진단값 |
| 질문 열쇠 항목 최저 비중 | 97.70% | 95.94% | 진단값 |
| `vector_memory` | 100% | 100% | 100% |
| `no_memory` | 12.5% | 12.5% | ≤25% |
| `shuffled_labels` | 0% | 0% | ≤25% |

두 seed 모두 첫 검증 시점인 step 50에서 100%에 도달했고, 등록한 2,000 step을 끝까지 수행했다.
모든 무효 방지 통제와 체크포인트 지문 검사를 통과했으므로 판정은
`A1_KEYED_ATTENTION_VALID`다.

`CONTROL-2`의 실패는 값 후보 자체를 잃은 문제가 아니라, 순차 상태 하나에서 질문 열쇠에 맞는
저장 위치를 선택하지 못한 문제였다. 같은 자료에서 표준 열쇠 검색은 이를 안정적으로 해결했다.
따라서 동적 관계 기억의 표준 양성 비교를 `GRU`에서 열쇠 기반 주의집중으로 교체하고,
`EPISODE-1`을 이 비교군과 함께 진행할 수 있다. 이 결과는 `QuantumC`나 의식의 증거가 아니다.
