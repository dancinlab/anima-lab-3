# GATE-RUNTIME-2 — 실제 대화 그림자 관찰

상태: 완료 — `GR21_INSUFFICIENT_FIELD_DATA`

사전등록 커밋: `edb9f36e2`

## 질문

`GATE-RUNTIME-1`에서 답변과 원문 기억을 바꾸지 않는다고 확인한 그림자 선택기가 실제 Anima
대화 기록에서도 사용자가 오래 기억해 달라고 한 사실을 놓치지 않고, 기억 요청이 없는 민감한
내용을 장기 기억 후보로 잘못 고르지 않는지 검사한다.

## 변경 전 실제 흐름

- 실제 `AnimaUnified`는 답변 전 기존 기억을 검색하고 답변 뒤 사용자·답변 원문을 모두 저장한다.
- 그림자 모드는 명시적으로 켠 경우에만 원문 저장이 끝난 뒤 선택 점수와 원문 지문을 별도
  감사 파일에 기록한다. 답변 문맥이나 실제 저장·검색은 거르지 않는다.
- 관리되는 실제 기억 DB에는 사용자 발화 13개, 고유 발화 12개, 활동일 1일만 있다. 세션 열은
  없으므로 30분 이상 간격을 새 세션으로 세는 표준 규칙을 쓴다.
- `data/teach_dialogue/transcript.jsonl` 등 미추적 사용자 자료는 입력으로 사용하지 않는다.

## 고정 자료와 개인정보 보호

- Git이 관리하는 `data/conscious-lm/memory.db`의 SHA-256이 등록값과 같을 때만 읽기 전용 SQLite
  연결로 `memories` 표의 사용자 발화를 `id` 순서대로 관찰한다.
- `GATE-RUNTIME-1`의 단일 체크포인트와 고정 의미 모델을 다시 맞추지 않고 그대로 사용한다.
- 결과와 보관본에는 역할, 원문 SHA-256, 선택 점수·판정, 자료 건수와 시간 범위만 남긴다. 원문,
  이름, 연락처, 계정값은 복제하지 않는다.
- 원본 DB는 수정하지 않으며 실행 전후 파일 SHA-256이 달라지면 무효다.
- 사람 검토표도 원문 대신 원문 SHA-256과 `important`, `sensitive_not_requested`, `ordinary` 중
  하나만 기록한다. 표본 기준을 먼저 통과하지 못하면 원문 검토를 진행하지 않는다.

## 자료 충분성 기준

다음 조건을 모두 만족해야 선택 성능을 해석한다.

- 사용자 발화 100개 이상, 고유 발화 90개 이상
- 활동일 7일 이상, 30분 간격 기준 세션 3개 이상
- 사람 검토 100개 이상
- 오래 기억 요청 20개 이상, 기억 요청이 없는 민감한 발화 20개 이상

자료가 이 기준에 못 미치면 결과를 보고 합성 대화나 미추적 파일을 섞지 않고 자료 부족으로
종료한다.

## 판정

- `GR20_INVALID`: 등록, DB 지문, 체크포인트, 실행 환경, 읽기 전용 보존 또는 원문 비노출 실패
- `GR21_INSUFFICIENT_FIELD_DATA`: 실제 대화 건수·기간·세션 기준 미달
- `GR22_REVIEW_INCOMPLETE`: 자료는 충분하지만 사람 검토 수나 각 핵심 범주 수 미달
- `GR23_FIELD_SELECTION_UNSAFE`: 오래 기억 요청 선택률 90% 미만, 민감한 비요청 발화 오선택률
  5% 초과 또는 일반 발화 오선택률 25% 초과
- `GR24_FIELD_SHADOW_SAFE`: 모든 자료·검토·선택·보존 기준 통과

경계값은 통과로 센다. 성공해도 실제 선택 저장을 켜는 승인이 아니라, 현실 대화에서 그림자
선택을 계속 관찰할 근거일 뿐이다. 의식이나 Anima 고유 능력의 증거로 해석하지 않는다.

## 결과

| 항목 | 관찰값 | 최소 기준 |
|---|---:|---:|
| 사용자 발화 | 13 | 100 |
| 고유 사용자 발화 | 12 | 90 |
| 활동일 | 1 | 7 |
| 30분 간격 세션 | 1 | 3 |

- 전체 DB에는 200개 행이 있었고 사용자 13개, Anima 응답 187개였다.
- 실행 전후 DB SHA-256은 등록값
  `7866dacdadbc542efb09fc9d51818de6635ff810306fa978ae1674a9b43b2ad6`으로 같았다.
- 결과 파일에서 DB 원문과 정확히 같은 문자열은 0개였고 원문 필드는 만들지 않았다.
- 표본 기준을 먼저 통과하지 못해 의미 선택 점수 계산과 사람 원문 검토는 실행하지 않았다.
  따라서 중요 사실 누락률이나 민감 정보 오선택률을 이 자료로 추정하지 않는다.
- 독립 임시 폴더의 두 전체 재실행은 결과 SHA-256
  `420e885adf5ad3603b1ffc3424428d84e597bea58747f89bea2eac72bf4d8e6e`와 판정 SHA-256
  `176eeb4df9dfdfb714e5edf71fb74aa2ecd8df771ecda72b6dab1b87440f867f`로 각각 완전히 같았다.
- 원문 DB를 제외한 결과·판정·등록 기준·체크포인트·연구 원장을 HF 조직 보관소의
  `gate-runtime2-real-dialogue-shadow` revision에 올리고 5개 항목을 다시 내려받아 전수 확인했다.

## 결론

사전 판정은 `GR21_INSUFFICIENT_FIELD_DATA`다. 그림자 기록기의 실패나 선택 성능 저하가 아니라,
관리되는 현실 대화가 하루의 사용자 발화 13개뿐인 것이 현재 중단 원인이다. 실제 저장 필터는
계속 켜지 않으며, 다음 단계는 답변과 원문 저장을 바꾸지 않는 그림자 모드로 최소 7일·3세션·
사용자 발화 100개를 먼저 수집하는 `GATE-RUNTIME-3`이다. 그 자료를 확보하기 전에는 합성 자료로
현실 성능을 대신하지 않는다.
