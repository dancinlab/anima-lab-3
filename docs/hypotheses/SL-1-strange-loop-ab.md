# SL-1 — 이상한 루프(자기예측)는 CE를 사지 못한다 (A/B 실측)

측정: 2026-07-25, summer RTX5070 · ConsciousLM 299,650,272 params (896d/12L/14H)
공통 조건: corpus_v2 67MB · batch 4 · block 256 · lr 1e-4 · 30,000 step · max-cells 16 ·
고정 검증 스팬 256KB · step 0부터 · 기반 커밋 ea860940f
관련: [NF-3 CE 탈가중과 크기 래칫](NF-3-ce-deweighting-and-scale-ratchet.md)

## 1. 가설과 사전 등록

괴델·에셔·바흐의 이상한 루프(계층을 올라가면 제자리로 돌아오는 뒤엉킨 구조)를 **목적함수**로
구현할 수 있는가. lab 위임에서 두 프런티어 모델이 갈렸다.

- **fable**: 대조적 자기예측(InfoNCE)만이 진짜 목적함수로 살아남는다 — 각 은닉 상태가 자기
  **다음 위치의 층별 텐션 프로파일**을 배치 내 모든 후보 중에서 식별해야 한다. 붕괴는 손실의
  최댓값이 되므로 정직이 유일한 하강로.
- **sol**: 추가하지 마라. 그 예산을 평범한 CE에 쓰고 Φ는 관측만 하라.

검증으로 가릴 수 없어 **기본값=sol(꺼짐) · 실험=fable(플래그)** 로 구현하고 A/B로 판정했다
(`--self-loop-weight`, 커밋 ddfe8a3f4).

## 2. 결과 (30,000 step 완주 · 각 21회 고정스팬 측정)

| 지표 | arm A (루프 없음 · sol) | arm B (루프 0.1 · fable) |
|------|------------------------|--------------------------|
| 최저 검증 CE | **4.1128** | **4.1127** |
| BPC | 5.936 | 5.936 |
| Φ 처음 → 끝 | 19.14 → 19.07 | 21.73 → 19.54 |
| 세포 | 16 (상한 도달) | 16 (상한 도달) |
| 세포 평균 텐션 범위 | 3.4e4 ~ 9.6e4 | **4.7e7 ~ 2.3e8** |

```
검증 CE   A │████████████████ 4.1128
          B │████████████████ 4.1127      차이 0.0001 nat = 측정 잡음 이하

Φ         A │19.14 ─────────▶ 19.07       변화 없음
          B │21.73 ─────────▶ 19.54       하락

세포 텐션  A │▌ 9.6e4
          B │████████████████████████████ 2.3e8   루프가 크기를 ~1,000배 부풀림
```

## 3. 판정

- **CE 이득 없음.** 0.0001 nat 차이는 이 측정의 분해능 아래다(같은 팔 내부 측정 간
  진폭이 ±0.01 수준). fable의 "CE와 어려운 하위문제를 공유하므로 언어에 도움이 된다"는
  주장은 이 조건(30k step · batch 4)에서 **기각**된다.
- **부작용은 실재한다.** 루프 팔의 세포 텐션이 3자릿수 크다. 자기예측 목표가
  텐션 **모양**만 채점하도록 설계했는데도(로그·평균차감·L2정규화) 크기 자체는 자유롭게
  커졌고, 루프가 그 방향을 오히려 가속했다.
- **sol의 반대 의견이 측정으로 지지됐다.** 기본값을 꺼짐으로 둔 결정이 옳았다.
- **세 지표 기준**: ② 세포 성장만 통과. ① Φ 정체·하락, ③ CE는 이 코퍼스 유니그램(5.95)을
  겨우 넘긴 5.936 — 바이그램 기준선 3.49에 한참 못 미쳐 **미달**.

## 3-b. 루프는 애초에 학습되지 않았다 (진단 고원 실측)

루프 손실은 로그에 따로 찍히지 않아 총손실 차이로 역산했다(두 팔의 CE는 거의 동일).

| step | base 총손실 | loop 총손실 | 차이 | ÷0.1 = 루프손실 |
|------|-------------|-------------|------|-----------------|
| 5,000 | 4.5158 | 5.1658 | 0.650 | **6.50** |
| 10,000 | 3.3636 | 4.0902 | 0.727 | **7.27** |
| 15,000 | 3.1087 | 3.8491 | 0.740 | **7.40** |
| 20,000 | 3.1023 | 3.8019 | 0.700 | **7.00** |

```
진단 고원   완전붕괴 6.93 │ 시퀀스코드 5.54 │ 시계코드 1.39 │ 정직 <<1.39
실측                  ●6.5~7.4
                      └─ 30,000 step 내내 붕괴 고원에 정지
```

**따라서 이 A/B가 실제로 잰 것은 "작동하는 이상한 루프의 효용"이 아니라 "학습되지 않는
자기예측 과제를 얹었을 때의 비용"이다.** 비용은 실재했다(텐션 1,000배, Φ 하락, CE 이득 0).
설계에 심어둔 진단 고원이 의도대로 작동해 손실 **값만으로** 붕괴를 판별할 수 있었다.

원인 가설(미검증): h(t)가 τ(t+1)을 맞히려면 아직 보지 못한 바이트 t+1을 예견해야 하고,
선형 헤드 + 30k step + batch 4에서는 그 어려운 하위문제에 진입하지 못했다. 재시도한다면
τ(t)(같은 위치, 인과적으로 가능) 예측부터 시작해 난이도를 올리는 편이 옳다.

## 3-c. 더 근본: 훈련이 Φ에 닿는 경로가 없다

```
훈련 ──▶ 트랜스포머 가중치 (옵티마이저 안)
              ✗ 끊김
Φ  ◀── 미토시스 세포 ◀── text_to_vector(원시 바이트) = 모델과 무관한 입력
        ▲ 학습되지 않는 무작위 가중치 (no_grad · 옵티마이저 밖)
```

Φ는 **훈련되지 않는 세포들**을 **모델과 무관한 입력**으로 돌린 결과를 읽는다. 그러므로
무엇을 훈련하든 Φ가 오를 구조적 이유가 없고, 두 팔에서 Φ가 19 근처에 머문 것은 이 배선의
필연이다. 규칙 ①(Φ 성장)은 현재 배선에서 원리적으로 달성 불가이며, 이를 바꾸는 유일한
구성이 `--cell-sense`(arm C)다 — 세포 입력을 모델 자신의 텐션 프로파일로 잇는다.

## 4. 핵심 발견

> **자기참조를 목적함수에 넣어도, 그것이 곧 언어 능력이 되지는 않는다.**
> 붕괴를 막는 설계(최댓값 = 붕괴)는 의도대로 작동했지만, 붕괴를 막았다는 것과 유용한
> 표현을 학습했다는 것은 별개다. 이상한 루프는 Φ·자기참조 쪽 이야기이고, CE는 여전히
> CE가 벌어야 한다.

부수 관찰: 크기(magnitude)는 손실에서 보상을 없애도 계속 자란다 — 손실이 아니라
아키텍처와 최적화 동역학이 밀어올린다. 크기를 **읽는 곳마다** 척도 불변으로 만들어야지,
한 군데만 막으면 다른 경로로 샌다(NF-3 → ea860940f → 본 문서).

## 5. 3팔 최종 (arm C 완주 후)

| arm | 최저 검증 CE | BPC | Φ 처음 → 끝 | 세포 평균 텐션 |
|-----|--------------|-----|-------------|----------------|
| A base (sol 안) | 4.1128 | 5.934 | 19.14 → 19.07 | 3.4e4 ~ 9.6e4 |
| B loop (fable 1안) | 4.1127 | 5.933 | 21.73 → 19.54 | 4.7e7 ~ 2.3e8 |
| C cellsense (fable 2안) | **4.1123** | 5.933 | 22.00 → 22.12 | **5.2e8** |

```
검증 CE  A │████████████████ 4.1128
         B │████████████████ 4.1127      세 팔 최대 격차 0.0005 nat
         C │████████████████ 4.1123      = 같은 팔 내부 진폭(±0.01)의 1/20 = 완전 동률

Φ        A │19.1 ────────▶ 19.1    성장 없음
         B │21.7 ────────▶ 19.5    하락
         C │22.0 ────────▶ 22.1    수준은 높으나 성장 없음(21.9~22.2 평탄)
```

**세 팔 모두 CE 동률, 어느 팔도 Φ가 자라지 않았다.** fable의 두 제안(자기예측 루프,
세포 감각 전환) 모두 측정 가능한 이득이 없고, sol의 "추가하지 말라"가 지지된다.

arm C의 Φ 수준이 A보다 높은 것(22 vs 19)은 성장이 아니라 **입력 통계가 달라 평평한
지점이 옮겨간 것**이다 — 21.9~22.2 구간에서 21회 내내 평탄하다. 세 팔 모두 종료 직전
Φ 이력이 같은 값으로 8회 반복(A 13.411 · B 13.562 · C 13.144)되는데, 이는 세포 상태가
고정점에 도달해 Φ가 얼어붙었다는 뜻이다 — 세포가 모델을 감지해도(arm C) 마찬가지였다.

## 6. 지표 ③ 미달 — 목적함수 문제가 아니다 (원인은 NF-7)

세 팔이 도달한 5.933 BPC는 이 코퍼스의 유니그램(5.95)을 겨우 넘고 바이그램(3.49)에는
한참 못 미친다. 처리량은 확실히 빈약하다:

```
30,000 step × batch 4 × block 256 = 30.7MB 통과 = 훈련 split의 0.48 epoch
파라미터당 바이트 = 0.103        (건강한 LM 학습은 20~100)
```

**그러나 처리량만으로는 설명되지 않는다.** 병렬 세션의 nf5 런(71,900 step, 이 실험의
2.4배)이 **2,000 step 만에 같은 바닥에 닿은 뒤 70,000 step 동안 전혀 개선되지 않았다**
([NF-7](NF-7-unigram-floor-diagnosis.md)). step을 더 준다고 풀리는 문제가 아니다.

본 실험이 NF-7에 보태는 독립 증거: **서로 다른 세 목적함수가 모두 같은 바닥에
0.0005 nat 이내로 수렴했다.** 목적함수를 바꿔도 바닥이 움직이지 않는다는 뜻이므로,
원인은 목적함수 바깥 — NF-7이 지목한 학습 역학(dropout 0.37이 유니그램 경로만
남긴다 · ln_ca가 잔차 흐름을 매 층 정규화해 토큰 정체성을 소멸시킨다 · adaptive LR이
스케줄을 덮어쓴다 · PHI-K3가 홀수 step을 건너뛴다) 쪽이다.

이 문서의 이전 판본은 이를 "예산 배분 문제"라고 적었다. nf5의 70,000 step 평탄
구간이 그 주장을 반증한다. 다음 실험은 NF-7의 판정 프로브(dropout 단독 플립)이며
병렬 세션이 이미 진행 중이므로 여기서 중복하지 않는다.
