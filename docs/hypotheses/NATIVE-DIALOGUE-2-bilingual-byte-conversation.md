# NATIVE-DIALOGUE-2 — 바이트 복원형 양언어 자체 대화 모델

## 목표

외부 언어 모델 호출이나 외부 사전학습 가중치 없이, 저장소의 `ConsciousLM` 계산층으로 한국어와
영어의 질문에 맞게 답하고 앞선 대화를 기억하는 자체 모델을 상시 대화 경로에 배포한다.

## 변경 전 확인된 원인

`NATIVE-DIALOGUE-1`의 42.997M 모델은 약 1.31억 조각을 학습했고 최종 검증 오차가 4.449였다.
형식은 안정됐지만 영어 대화 원본은 2,308개뿐이었고 한국어와 영어의 대화 노출도 서로 다른
자료에서 왔다. 생성 답변은 문장 모양만 갖췄을 뿐 질문과 사실을 연결하지 못했다. 과거 18M
바이트 모델의 성공 주장은 고정 평가 결과와 체크포인트를 현재 환경에서 함께 재현할 수 없으므로
양성 근거로 사용하지 않는다.

## 고정 설계

- 계산층과 체크포인트 형식은 기존 `ConsciousLM`을 확장한다. 새 외부 모델 구조나 가중치는 쓰지
  않는다.
- 입력은 ByteLevel BPE를 쓴다. 자주 나온 문자열은 한 조각으로 줄이지만 모든 UTF-8 바이트를
  기본 알파벳으로 보존하므로 단어 조각 밖 입력도 `<unk>` 없이 복원할 수 있다.
- 일반 글 학습과 대화 답변 학습을 분리한다. 첫 단계는 한국어·영어 일반 글과 대화 전체의 다음
  조각을 학습하고, 마지막 단계는 대화의 assistant 답변과 종료 조각만 학습한다.
- 대화 자료는 `lemon-mint/smol-koreantalk` revision
  `04eb12c1f999578d74dd87720bc853cedb7fa156`의 한국어·영어 짝 460K를 사용한다. 라이선스는
  Apache-2.0이다.
- 일반 글은 `seongchaeae/sage-pretrain-corpus` revision
  `6b3da140fbb98a90fcc5b855269c85ded9cde1f1`에서 ODC-BY-1.0으로 감사된
  `fineweb_edu` 영어 8개 파일과 `fineweb2_ko` 한국어 4개 파일만 사용한다.
- 평가 질문과 가까운 문장은 학습 전 제거한다. 원본 사용자 대화와 `GATE-RUNTIME` 수집 원문은
  학습하거나 HF에 올리지 않는다.
- 한국어·영어 파일을 먼저 같은 확률로 고른다. 한 언어의 행 수가 다른 언어 노출을 지배하지
  못하게 한다.

순수 바이트마다 큰 모델을 한 번씩 호출하는 방식, 고정 크기 바이트 묶음, 내용 난도에 따라 바이트
묶음 길이를 바꾸는 BLT 방식도 검토했다. 이들은 알 수 없는 글자를 없애는 장점이 있지만 현재
`ConsciousLM`의 학습·체크포인트·상시 실행 흐름을 모두 바꾸고 같은 계산량의 양성 비교도 없다.
이번 단계에서는 표준 ByteLevel BPE의 256바이트 기본 알파벳으로 같은 복원력을 확보하고, 자주 나온
묶음만 합쳐 학습·생성 비용을 줄인다. 자체 모델이 고정 대화 평가를 통과한 뒤에만 별도 비교 실험으로
순수 바이트 묶음 구조를 검토한다.

## 고정 실행 순서

1. 기존 42.997M 자체 체크포인트에 새 대화 자료 첫 파일만 추가해 12,000회 답변 학습을 한다.
   외부 가중치는 0개다. 고정 평가에서 각 언어 6/7과 두 턴 기억을 통과해야 307M 본학습으로 간다.
2. 본모델은 무작위 초기값, 306,747,688개 변수, 문맥 1,024, 전역 묶음 64로 시작한다. 일반 글과
   대화 전체를 35,000회 학습한 뒤 같은 실행 상태에서 대화 답변만 10,000회 학습한다. 총 노출은
   약 29.5억 조각이다.
3. 45,000회 모델을 고정 패널로 한 번 평가한다. 자동 기준을 통과한 모델만 원문 전체 사람 검토와
   별도 5턴 WebSocket 대화를 수행한다.
4. 모든 기준을 통과할 때만 `models/anima-native`에 원자적으로 배포하고 상시 서버를
   `--model anima-native --dialogue-backend model`로 바꾼다. Claude는 비교와 즉시 복구용으로만
   남긴다.

## 통과 기준

- 외부 사전학습 가중치 0개, 빈 답변·깨진 UTF-8·역할 누출·질문 복사·반복 위반 0건
- 한국어와 영어 의미 문항 각각 6/7 이상
- 두 턴 기억과 정정 문항 모두 통과
- 저장 후 재로드 평가가 동일하고, 모든 평가 원문을 사람이 읽어 질문에 맞는 답으로 판정
- 실제 WebSocket 5턴에서 이름·기한·위험 유지, 주제 전환 뒤 복귀, 모르는 담당자 비추측
- 자체 모델 정상 호출에 외부 답변 호출 0건
- 기존 대화 DB의 행 수와 지문 변화 0건

## 중단·복구 기준

- 42.997M 선별이 실패하면 자료·손실·생성 중 실패 구간을 기록하고 307M을 시작하지 않는다.
- 307M 자동 또는 사람 평가가 하나라도 실패하면 상시 서버를 바꾸지 않는다.
- 배포 뒤 로드 실패, 빈 답변 또는 WebSocket 회귀가 생기면 기존 Claude 실행 명령으로 즉시
  복구한다. 실패 모델과 원자료는 삭제하지 않는다.
- 통과 결과는 자체 양언어 대화 경로의 성공으로만 해석하며 의식의 증거로 사용하지 않는다.
